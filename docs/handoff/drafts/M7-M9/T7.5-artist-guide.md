# T7.5 — Artist guide: `docs/artist-guide.md`, its figures, and the script that regenerates them
Milestone: M7 · Depends on: T7.4 (and through it T7.1-T7.3 and all of M3-M5) · Parallel-safe: no (reads the shared
render caches and adds native renders to `.cache`)

## Goal
After this card:
- `docs/artist-guide.md` tells a Blender artist what every Painterly knob does, in which unit, with which measured
  effect and from which source; what each preset sets; why Blender's default 1000 W light clips; and the known limits
  (renders below 400 px, edge aliasing at small jitter, and the rest listed in Appendix D).
- `docs/artist-guide/` holds the guide's 15 figures (PNG, each at most 1 MiB) and `figures.json`, their provenance.
  Every figure is rendered from one of two sources: the experiments' own oracle renders, which the guide's numbers were
  measured on, or the native core (`_painterly`).
- `tools/make_artist_guide.py` regenerates every figure deterministically (`figures`) and every generated block of the
  guide (`tables`): figure embeds and captions, a fact line and the tooltip under every knob heading, and the knob,
  preset, jitter and evidence tables. Defaults, ranges, labels and tooltips come only from
  `_painterly.integrator_sockets()`, preset contents only from the shipped preset files, so the guide never restates a
  `PainterlyIntegrator` default by hand (the single source of truth, T3.13).
- `tests/docs/test_artist_guide.py` fails as soon as a generated block is stale, the guide's structure drifts from the
  sockets, or a figure differs from `figures.json`. `tests/blender/test_artist_guide_labels.py` checks the guide's
  labels of the hand-written properties against Blender's RNA.

The script and the tests are given verbatim (Appendices A-C). The guide's prose is written by the agent into the
skeleton of Appendix D, under the writing rules of Step 7; Opus reviews it.

## Opus decisions (fixed for this card)
1. **Two image sources, no Blender renders.**
   - **Experiment renders**: pair 0 of a configuration of experiments 001, 002, 003 or 006, loaded through
     `painterly_analysis.experiment` from the shared oracle cache. These are the renders the cited numbers were measured
     on. On the built-in scene the native core equals the oracle bit for bit (T3.16), so they are also Painterly renders.
   - **Native renders**: `_painterly` renders of the built-in scene (`sync/reference.py`'s `build_smallpaint_scene`,
     T4.3), for what no experiment rendered: Lane Stagger, Spiral Rotation, Phase Lock Bits, the jitter doses and the
     presets.
   - The stand-in for a Blender scene is the built-in scene with only the light ghosted (`ghost="lights"`): experiment
     002 H5 calls lights-only ghosting "the Blender look", and T5.4 judges the Blender path against exactly this
     configuration. Figures rendered through Blender would need the installed extension and minutes per frame (T7.4).
2. **One size and one pass count.** Native panels: 400 px (SPEC §9, the experiments' size) and `FIGURE_PASSES = 128`,
   the passes of an experiment pair (two 64-pass halves, `metrics.measure`'s `ab8`), so native and experiment panels
   compare at equal passes. The passes figure is the exception: one half render at each pass count. Every image is
   SPEC §7's display mapping (`io.smallpaint_display`), which Display Referred output reproduces under the Standard view.
3. **Native knobs.** A native panel builds the built-in scene, which applies the reference knobs (T4.3), then sets only
   the knobs the panel names. Every other knob, `seed` included, stays at its socket default. A panel at a socket's
   default value sets no knob, so it reuses the common render.
4. **Single source of truth.** The guide states socket defaults, ranges, labels and tooltips only inside generated
   blocks. Preset contents come from the preset files and `presets.PRESET_SOCKETS` (read with `ast`, no `bpy`). Units
   come from `UNITS`, which must name every socket (experiment 006, Decision 1: always name the unit).
5. **Evidence.** Prose quotes numbers only from final experiments (index status `final`; their Results and
   Conclusion) and from the SPEC. Experiments numbered at run time (lane-stagger, camera-motion, jitter-dose-response,
   scale-limits, noise-locking, cpu-throughput) are found by slug, never by a hard-coded number. For one that is not
   final, the prose uses a fixed sentence (Step 7). The structure check rejects a prose link to a non-final
   experiment.
6. **This card changes nothing it documents.** If a socket text, default, preset or panel disagrees with the guide's
   sources, the agent reports it and does not edit `src/`.

## Interface

### Regenerating (the guide's last section shows these commands)
```
make build                                                            # _painterly in build/dev
.venv/bin/python tools/make_artist_guide.py figures                   # repeat until exit 0; 3 = renders remain
.venv/bin/python tools/make_artist_guide.py tables                    # rewrite the generated blocks
.venv/bin/python tools/make_artist_guide.py tables --check            # change nothing; exit 1 on any problem
```
- `figures [--out-dir DIR] [--budget SECONDS] [--oracle-build-dir DIR] [--native-cache-dir DIR] [--core-build-dir DIR]
  [--threads N]`. Defaults: `docs/artist-guide`, 540 s, `.cache/oracle-build`, `$PAINTERLY_CACHE` (or `.cache`)
  + `/artist-guide-renders`, `build/dev`, 0 (one thread per CPU; the output is identical for any count, SPEC §3).
  Relative paths are resolved against the repository root. `figures` first renders what is missing: experiment
  renders through `run_jobs` (cache `$PAINTERLY_CACHE/renders`, or `.cache/renders`), then native renders into the
  native cache. No render starts once the budget has passed. Then it prints `completed=<n> remaining=<m>`; while
  `m > 0` it exits 3 and writes no figure. With nothing missing, it writes every figure and `figures.json`, deletes any
  other `fig_*.png` in the output directory and prints one line per figure: `<name>: <width> x <height> px, <bytes>
  bytes`. Exit 2: a missing oracle binary or `_painterly`, with the fix in the message.
- `tables [--check] [--core-build-dir DIR]` reads `docs/artist-guide/figures.json`, the sockets, the presets, `ui.py`
  and `experiments/README.md`. Without `--check` it rewrites the generated blocks of `docs/artist-guide.md`. Both modes
  print every problem (`check_structure`, `check_figures`, and with `--check` a stale block) and exit 1 if there is one.

### Generated blocks
A generated block is two marker lines and the text between them, which `tables` owns:
```
<!-- BEGIN GENERATED <id> -->
...
<!-- END GENERATED <id> -->
```
| id | content | where |
|---|---|---|
| `figure:<file>` (15) | the image and a caption listing each panel's label and source, with clip fractions where the figure reports them | the figure's section (and knob subsection), table below |
| `knob:<socket>` (one per socket) | `` `name` · panel path · type · default · range · unit `` and `> Tooltip: <description>` | under that knob's heading |
| `jitter-pixels` | jitter doses as fractions of the side, image-plane units, and the largest shift in px at 400, 1920 and 3840 px | Units |
| `preset-table` | per preset: what it sets and which scene; the knobs reset before every preset and the knobs presets never change | Presets |
| `knob-table` | every socket: panel, label, identifier, type, default, range, unit | Knob reference |
| `evidence` | every `EVIDENCE` slug: its directory (or "not run"), index status, question, and the guide sections that use it | Evidence |

### `docs/artist-guide/figures.json` (`report.write_results_json`: sorted keys, indent 2)
```
{"format": 1,
 "settings": {"figure_size", "figure_passes", "crop", "window", "edge", "preview_factor", "gutter_px",
              "max_figure_bytes", "socket_defaults": {"<socket>": <default>, ...}},
 "figures": {"<file>": {"title", "section", "knob", "view", "columns", "clip_fraction" (bool), "width", "height",
                        "bytes", "sha256",
                        "panels": [{"label", "source": "reference"|"pair"|"half"|"native", "clip_fraction",
                                    "size", ...}]}}}
```
A panel entry holds its label, the source fields of `_record` (`slug`, `configuration`, `light_w` for experiment
panels; `scene`, `knobs` for native ones), the render fields of `Renders.display` (`experiment` directory, `seeds`,
`passes`; or `passes`; or the reference `file`), `size` and `clip_fraction`. `check_figures` compares the labels, the
`_record` fields and `socket_defaults` with the current sockets and presets, so a changed default, preset or figure
definition is reported as "run figures".

### Rules for later cards
- A card that adds a socket adds its `UNITS` entry, and to `docs/artist-guide.md` the knob's subsection (heading,
  `knob:` block markers and prose) in its group, in socket order, then runs `tables`. Until then `make test` fails
  with the expected heading list.
- A card that changes a socket's default, range or UI text, a shipped preset, or `presets.PRESET_SOCKETS`, lists
  `docs/artist-guide.md` and `docs/artist-guide/` under Modify and runs `figures`, then `tables`. `check_figures`
  detects a changed socket default or panel through `figures.json`.
- A card that changes `ui.HAND_WRITTEN_PANEL` updates `HAND_WRITTEN` and the guide's subsections.
- A card that adds or changes the `experiments/README.md` row of an `EVIDENCE` slug (and Opus when it finalizes one)
  lists `docs/artist-guide.md` under Modify and runs `tables`; otherwise `test_generated_blocks_are_current` fails on
  the stale Evidence table. When an experiment becomes final, the guide sections that name it replace the fixed
  "not final" sentence with its result (Opus reviews).
- A card that changes kernel output reruns `figures`: nothing detects a stale native render by itself.

def _native(label: str, scene: str = "built-in", **knobs: object) -> Panel:
    return Panel(label, Source("native", scene=scene, knobs=tuple(sorted(knobs.items()))))


def socket_map(sockets: list[dict]) -> dict[str, dict]:
    return {s["name"]: s for s in sockets}


def is_default(socket: dict, value: object) -> bool:
    """True if ``value`` equals the socket default as the socket stores it (floats are float32)."""
    if socket["type"] == "float":
        return bool(np.float32(float(value)) == np.float32(socket["default"]))
    return value == socket["default"]


def dose_label(dose: Fraction, default: bool) -> str:
    text = "0" if dose == 0 else f"{dose} of the side"
    return f"{text} (default)" if default else text


def dose_panel(dose: Fraction, jitter: dict) -> Panel:
    """A native panel at this jitter. The default dose renders with no jitter knob set."""
    default = is_default(jitter, float(dose))
    label = f"Jitter {dose_label(dose, default)}"
    return _native(label) if default else _native(label, jitter=float(dose))

def _module_literal(path: Path, name: str) -> object:
    """The literal value of the module-level assignment ``name`` in ``path`` (ast.literal_eval)."""
    for node in ast.parse(path.read_text(encoding="utf-8")).body:
        if isinstance(node, ast.Assign):
            targets = node.targets
        elif isinstance(node, ast.AnnAssign):
            targets = [node.target]
        else:
            continue
        if any(isinstance(t, ast.Name) and t.id == name for t in targets):
            return ast.literal_eval(node.value)
    raise ValueError(f"{path}: no module-level assignment {name}")


def _constant(node: ast.expr) -> object:
    """The value of a constant expression of a preset file: literals, unary +/- and + - * /."""
    if isinstance(node, ast.Constant):
        return node.value
    if isinstance(node, ast.UnaryOp) and isinstance(node.op, (ast.USub, ast.UAdd)):
        value = _constant(node.operand)
        return -value if isinstance(node.op, ast.USub) else +value
    if isinstance(node, ast.BinOp) and isinstance(node.op, (ast.Add, ast.Sub, ast.Mult, ast.Div)):
        left, right = _constant(node.left), _constant(node.right)
        if isinstance(node.op, ast.Add):
            return left + right
        if isinstance(node.op, ast.Sub):
            return left - right
        if isinstance(node.op, ast.Mult):
            return left * right
        return left / right
    raise ValueError(f"not a constant expression: {ast.dump(node)}")


def parse_preset(path: Path) -> Preset:
    """A shipped preset file in T7.2's shape: ``import bpy``, ``painterly = ...``, then only
    ``painterly.<name> = <constant>`` and ``painterly.property_unset("<name>")``."""
    body = ast.parse(path.read_text(encoding="utf-8")).body
    header = ast.parse("import bpy\npainterly = bpy.context.scene.painterly\n").body
    if [ast.dump(s) for s in body[:2]] != [ast.dump(s) for s in header]:
        raise ValueError(f"{path}: not a T7.2 preset file (header)")
    assignments: list[tuple[str, object]] = []
    unset: list[str] = []
    reference_scene = False
    for stmt in body[2:]:
        if (
            isinstance(stmt, ast.Assign)
            and len(stmt.targets) == 1
            and isinstance(stmt.targets[0], ast.Attribute)
            and isinstance(stmt.targets[0].value, ast.Name)
            and stmt.targets[0].value.id == "painterly"
        ):
            name, value = stmt.targets[0].attr, _constant(stmt.value)
            if name == "reference_scene":
                reference_scene = bool(value)
            else:
                assignments.append((name, value))
        elif (
            isinstance(stmt, ast.Expr)
            and isinstance(stmt.value, ast.Call)
            and isinstance(stmt.value.func, ast.Attribute)
            and stmt.value.func.attr == "property_unset"
            and len(stmt.value.args) == 1
            and isinstance(stmt.value.args[0], ast.Constant)
        ):
            unset.append(stmt.value.args[0].value)
        else:
            raise ValueError(f"{path}: line {stmt.lineno} is not a T7.2 preset statement")
    return Preset(
        path.name, path.stem.replace("_", " "), tuple(assignments), tuple(unset), reference_scene
    )


def load_presets(preset_dir: Path = PRESET_DIR) -> list[Preset]:
    """The shipped presets in Blender's menu order (sorted file names, T7.2)."""
    return [parse_preset(p) for p in sorted(preset_dir.glob("*.py"))]


def experiment_dir(slug: str) -> Path | None:
    """The one directory ``experiments/NNN-YYYY-MM-DD-<slug>``, or None. Two raise ValueError."""
    pattern = re.compile(rf"\d{{3}}-\d{{4}}-\d{{2}}-\d{{2}}-{re.escape(slug)}")
    found = sorted(p for p in EXPERIMENTS.iterdir() if p.is_dir() and pattern.fullmatch(p.name))
    if len(found) > 1:
        raise ValueError(f"two experiment directories for slug {slug}: {found}")
    return found[0] if found else None


def experiment_index() -> dict[str, dict[str, str]]:
    """Rows of the index in experiments/README.md, keyed by directory name."""
    rows = {}
    for line in EXPERIMENT_INDEX.read_text(encoding="utf-8").splitlines():
        cells = [c.strip() for c in line.strip().strip("|").split("|")]
        if len(cells) >= 6 and re.fullmatch(r"\d{3}", cells[0]):
            number, date, slug, question, status = cells[:5]
            rows[f"{number}-{date}-{slug}"] = {"question": question, "status": status}
    return rows

def enum_label(identifier: str) -> str:
    """The Blender label of an enum item (T4.2: ``id.replace("_", " ").title()``)."""
    return identifier.replace("_", " ").title()


def number(value: float) -> str:
    return format(float(value), ".6g")


def format_value(socket: dict, value: object) -> str:
    kind = socket["type"]
    if kind == "boolean":
        return "on" if value else "off"
    if kind == "enum":
        return enum_label(str(value))
    if kind in ("int", "uint"):
        return str(int(value))
    if kind == "float":
        return number(value)
    if kind == "vector":
        return "(" + ", ".join(number(v) for v in value) + ")"
    raise ValueError(f"socket {socket['name']}: unknown type {kind}")


def type_text(socket: dict) -> str:
    if socket["type"] == "enum":
        return "choice of " + ", ".join(enum_label(i) for i in socket["enum_items"])
    return {
        "boolean": "on/off",
        "int": "integer",
        "uint": "integer >= 0",
        "float": "number",
        "vector": "XYZ vector",
    }[socket["type"]]


def range_text(socket: dict) -> str:
    lo, hi = socket["min"], socket["max"]
    if lo is not None and hi is not None:
        text = f"range {number(lo)} to {number(hi)}"
    elif lo is not None:
        text = f"minimum {number(lo)}"
    elif hi is not None:
        text = f"maximum {number(hi)}"
    else:
        text = "no range set"
    soft_lo, soft_hi = socket["soft_min"], socket["soft_max"]
    if soft_lo is not None or soft_hi is not None:
        a = number(soft_lo) if soft_lo is not None else "-inf"
        b = number(soft_hi) if soft_hi is not None else "inf"
        text += f", slider {a} to {b}"
    return text


def panel_path(name: str, group: str, subpanels: dict[str, str]) -> str:
    """Where Blender draws a property (T7.1)."""
    if name in subpanels:
        if subpanels[name] not in SUBPANEL_LABELS:
            raise ValueError(f"{name}: unknown subpanel {subpanels[name]}")
        return f"Render Properties > {group} > {SUBPANEL_LABELS[subpanels[name]]}"
    return f"Render Properties > {group}"


def knob_heading(name: str, label: str) -> str:
    return f"{label} (`{name}`)"


def expected_knob_headings(sockets: list[dict]) -> dict[str, list[str]]:
    """The "####" headings of each Knobs subsection, in order: the group's sockets in socket
    order, then its hand-written properties in HAND_WRITTEN order."""
    out: dict[str, list[str]] = {g: [] for g in KNOB_GROUPS}
    for s in sockets:
        out[s["group"]].append(knob_heading(s["name"], s["ui_name"]))
    for name, (group, label) in HAND_WRITTEN.items():
        out[group].append(knob_heading(name, label))
    out[LIGHT_SECTION] = [
        knob_heading(f"light.painterly.{n}", label) for n, label in LIGHT_PROPERTIES.items()
    ]
    return out


def knob_block(socket: dict, subpanels: dict[str, str]) -> str:
    parts = [
        f"`{socket['name']}`",
        panel_path(socket["name"], socket["group"], subpanels),
        type_text(socket),
        f"default **{format_value(socket, socket['default'])}**",
        range_text(socket),
        f"unit: {UNITS[socket['name']]}",
    ]
    return " · ".join(parts) + "\n\n" + f"> Tooltip: {socket['description']}\n"


def knob_table(sockets: list[dict], subpanels: dict[str, str]) -> str:
    lines = [
        "| Panel | Label | Identifier | Type | Default | Range | Unit |",
        "|---|---|---|---|---|---|---|",
    ]
    for s in sockets:
        lines.append(
            f"| {panel_path(s['name'], s['group'], subpanels)} | {s['ui_name']} | `{s['name']}` "
            f"| {type_text(s)} | {format_value(s, s['default'])} | {range_text(s)} "
            f"| {UNITS[s['name']]} |"
        )
    return "\n".join(lines) + "\n"


def preset_table(sockets: list[dict], presets: list[Preset], preset_sockets: tuple) -> str:
    by_name = socket_map(sockets)
    lines = ["| Preset | Sets | Scene |", "|---|---|---|"]
    for p in presets:
        sets = [
            f"{by_name[n]['ui_name']} = {format_value(by_name[n], v)}" for n, v in p.assignments
        ]
        sets += [
            f"{by_name[n]['ui_name']} reset to its default "
            f"({format_value(by_name[n], by_name[n]['default'])})"
            for n in p.unset
        ]
        scene = "smallpaint's built-in scene (Reference Scene on)" if p.reference_scene else "yours"
        lines.append(f"| {p.menu} | {'; '.join(sets) if sets else 'nothing'} | {scene} |")
    reset = ", ".join(by_name[n]["ui_name"] for n in preset_sockets)
    never = ", ".join(s["ui_name"] for s in sockets if s["name"] not in preset_sockets)
    lines += [
        "",
        f"Before a preset file runs, these knobs return to their socket defaults: {reset} "
        "(`presets.PRESET_SOCKETS`). A preset never changes: " + never + ".",
    ]
    return "\n".join(lines) + "\n"


def jitter_table(sockets: list[dict]) -> str:
    jitter = socket_map(sockets)["jitter"]
    head = ["Jitter (fraction of the fitted side)", "Image-plane units (2 x jitter)"]
    head += [f"Largest shift at {side} px" for side in JITTER_TABLE_SIDES]
    lines = ["| " + " | ".join(head) + " |", "|" + "---|" * len(head)]
    for dose in JITTER_DOSES:
        cells = [dose_label(dose, is_default(jitter, float(dose))), str(2 * dose)]
        cells += [f"{format(float(dose * side), '.3g')} px" for side in JITTER_TABLE_SIDES]
        lines.append("| " + " | ".join(cells) + " |")
    lines += [
        "",
        f"The socket default is {format_value(jitter, jitter['default'])} of the fitted side. "
        "Each pixel's samples are shifted by up to this many pixels on each axis.",
    ]
    return "\n".join(lines) + "\n"


def evidence_table() -> str:
    index = experiment_index()
    lines = ["| Experiment | Status | Question | Used in |", "|---|---|---|---|"]
    for slug, used in EVIDENCE:
        directory = experiment_dir(slug)
        if directory is None:
            lines.append(f"| `{slug}` | not run | - | {used} |")
            continue
        row = index.get(directory.name, {"question": "-", "status": "not indexed"})
        link = f"[{directory.name}](../experiments/{directory.name}/README.md)"
        lines.append(f"| {link} | {row['status']} | {row['question']} | {used} |")
    return "\n".join(lines) + "\n"


def describe_panel(meta: dict, by_name: dict[str, dict]) -> str:
    """One caption line: where a panel's image comes from."""
    kind = meta["source"]
    if kind == "reference":
        return f"`{meta['file']}`, smallpaint's own render"
    if kind in ("pair", "half"):
        link = f"[{meta['experiment']}](../experiments/{meta['experiment']}/README.md)"
        seeds = ("seeds " if len(meta["seeds"]) > 1 else "seed ") + " and ".join(
            str(s) for s in meta["seeds"]
        )
        passes = " + ".join(str(p) for p in meta["passes"])
        text = (
            f"experiment {link}, configuration `{meta['configuration']}`, {seeds}, {passes} "
            f"passes, {meta['size']} px"
        )
        if meta["light_w"] is not None and meta["light_w"] != REFERENCE_LIGHT_W:
            text += (
                f", the light shown at {meta['light_w']} W (sums x {meta['light_w']}/"
                f"{REFERENCE_LIGHT_W}: radiance is linear in emission, SPEC §6)"
            )
        return text
    knobs = [f"{by_name[n]['ui_name']} {format_value(by_name[n], v)}" for n, v in meta["knobs"]]
    knob_text = ", ".join(knobs) if knobs else "no knob changed"
    return (
        f"native core, {SCENE_TEXT[meta['scene']]}, {knob_text}, every other knob at its socket "
        f"default, {meta['passes']} passes, {meta['size']} px"
    )


def figure_block(figure: Figure, meta: dict, by_name: dict[str, dict]) -> str:
    rows = math.ceil(len(figure.panels) / figure.columns)
    order = "left to right" if rows == 1 else "left to right, then top to bottom"
    lines = [
        f"![{figure.title}](artist-guide/{figure.name})",
        "",
        f"*{figure.title}.* Panels, {order}; each panel is {VIEW_TEXT[figure.view]}:",
        "",
    ]
    for letter, panel, pmeta in zip(
        string.ascii_lowercase, figure.panels, meta["panels"], strict=False
    ):
        line = f"- ({letter}) {panel.label}: {describe_panel(pmeta, by_name)}"
        if figure.clip_fraction:
            line += f"; clip fraction {format(pmeta['clip_fraction'], '.3f')}"
        lines.append(line + ".")
    return "\n".join(lines) + "\n"


def generated_blocks(sockets: list[dict], figures_meta: dict) -> dict[str, str]:
    """Every generated block of the guide, keyed by block id."""
    by_name = socket_map(sockets)
    subpanels = _module_literal(UI_PY, "SOCKET_SUBPANEL")
    presets = load_presets()
    preset_sockets = tuple(_module_literal(PRESETS_PY, "PRESET_SOCKETS"))
    blocks = {f"knob:{s['name']}": knob_block(s, subpanels) for s in sockets}
    for figure in all_figures(sockets, presets):
        if figure.name not in figures_meta["figures"]:
            raise ValueError(f"{figure.name} is not in figures.json: run the figures subcommand")
        blocks[f"figure:{figure.name}"] = figure_block(
            figure, figures_meta["figures"][figure.name], by_name
        )
    blocks["jitter-pixels"] = jitter_table(sockets)
    blocks["preset-table"] = preset_table(sockets, presets, preset_sockets)
    blocks["knob-table"] = knob_table(sockets, subpanels)
    blocks["evidence"] = evidence_table()
    return blocks


BLOCK = re.compile(
    r"^<!-- BEGIN GENERATED (?P<id>\S+) -->\n(?P<body>.*?)^<!-- END GENERATED (?P=id) -->$",
    re.M | re.S,
)


def apply_blocks(text: str, blocks: dict[str, str]) -> str:
    """``text`` with the body of every generated block replaced. Every block id of ``blocks``
    must occur exactly once in ``text``, and ``text`` must hold no other block."""
    found = [m.group("id") for m in BLOCK.finditer(text)]
    problems = []
    duplicates = sorted({i for i in found if found.count(i) > 1})
    missing = sorted(set(blocks) - set(found))
    unknown = sorted(set(found) - set(blocks))
    if duplicates:
        problems.append(f"duplicate blocks: {duplicates}")
    if missing:
        problems.append(f"missing blocks: {missing}")
    if unknown:
        problems.append(f"unknown blocks: {unknown}")
    if problems:
        raise ValueError("; ".join(problems))
    return BLOCK.sub(
        lambda m: (
            f"<!-- BEGIN GENERATED {m.group('id')} -->\n{blocks[m.group('id')]}"
            f"<!-- END GENERATED {m.group('id')} -->"
        ),
        text,
    )


def headings(text: str) -> list[tuple[int, str, int]]:
    """(level, title, line index) of every ATX heading outside fenced code blocks."""
    out, fenced = [], False
    for i, line in enumerate(text.splitlines()):
        if line.startswith("```"):
            fenced = not fenced
        elif not fenced and (m := re.match(r"(#{1,6}) (.+)$", line)):
            out.append((len(m.group(1)), m.group(2).strip(), i))
    return out


def _span(heads: list[tuple[int, str, int]], k: int, n_lines: int) -> tuple[int, int]:
    level, _, start = heads[k]
    end = next((h[2] for h in heads[k + 1 :] if h[0] <= level), n_lines)
    return start, end


def check_structure(text: str, sockets: list[dict]) -> list[str]:
    """Every structure rule of the guide that ``text`` breaks, as messages ([] when none)."""
    problems: list[str] = []
    heads = headings(text)
    n_lines = len(text.splitlines())
    titles = [t for level, t, _ in heads if level == 1]
    if titles != [GUIDE_TITLE]:
        problems.append(f"level-1 headings {titles}, expected [{GUIDE_TITLE!r}]")
    sections = [t for level, t, _ in heads if level == 2]
    if sections != list(GUIDE_SECTIONS):
        problems.append(f"level-2 headings {sections}, expected {list(GUIDE_SECTIONS)}")
    spans: dict[str, tuple[int, int]] = {}
    for k, (level, title, _) in enumerate(heads):
        if level == 2:
            spans[title] = _span(heads, k, n_lines)
    knob_spans: dict[str, tuple[int, int]] = {}
    expected = expected_knob_headings(sockets)
    if "Knobs" in spans:
        lo, hi = spans["Knobs"]
        inner = [(k, h) for k, h in enumerate(heads) if lo < h[2] < hi]
        groups = [h[1] for _, h in inner if h[0] == 3]
        if groups != [*KNOB_GROUPS, LIGHT_SECTION]:
            problems.append(f"Knobs subsections {groups}, expected {[*KNOB_GROUPS, LIGHT_SECTION]}")
        for k, h in inner:
            if h[0] != 3 or h[1] not in expected:
                continue
            g_lo, g_hi = _span(heads, k, n_lines)
            got = [x[1] for x in heads if g_lo < x[2] < g_hi and x[0] == 4]
            if got != expected[h[1]]:
                problems.append(f"Knobs > {h[1]}: knob headings {got}, expected {expected[h[1]]}")
            for j, x in enumerate(heads):
                if g_lo < x[2] < g_hi and x[0] == 4:
                    knob_spans[x[1]] = _span(heads, j, n_lines)
    else:
        problems.append("no Knobs section")
    lines = text.splitlines()
    by_name = socket_map(sockets)

    def block_line(block_id: str) -> int | None:
        marker = f"<!-- BEGIN GENERATED {block_id} -->"
        return next((i for i, line in enumerate(lines) if line == marker), None)

    def inside(line: int | None, span: tuple[int, int] | None) -> bool:
        return line is not None and span is not None and span[0] < line < span[1]

    for figure in all_figures(sockets, load_presets()):
        span = spans.get(figure.section)
        if figure.knob is not None:
            span = knob_spans.get(knob_heading(figure.knob, by_name[figure.knob]["ui_name"]))
        if not inside(block_line(f"figure:{figure.name}"), span):
            where = figure.section + (f" > {figure.knob}" if figure.knob else "")
            problems.append(f"block figure:{figure.name} is not in {where}")
    for s in sockets:
        span = knob_spans.get(knob_heading(s["name"], s["ui_name"]))
        if not inside(block_line(f"knob:{s['name']}"), span):
            problems.append(f"block knob:{s['name']} is not in its knob subsection")
    for block_id, section in TABLE_SECTIONS.items():
        if not inside(block_line(block_id), spans.get(section)):
            problems.append(f"block {block_id} is not in {section}")
    if "<!-- PROSE" in text:
        problems.append("a <!-- PROSE ... --> placeholder remains")
    prose = BLOCK.sub("", text)
    statuses = {name: row["status"] for name, row in experiment_index().items()}
    for target in re.findall(r"\]\(([^)\s]+)\)", text):
        if re.match(r"[a-z]+:", target) or target.startswith("#"):
            continue
        if not (GUIDE.parent / target.split("#")[0]).exists():
            problems.append(f"link target does not exist: {target}")
    for name in re.findall(r"\]\(\.\./experiments/([^/)]+)/", prose):
        if statuses.get(name) != "final":
            problems.append(f"the prose links experiment {name}, whose status is not final")
    return problems


def png_size(path: Path) -> tuple[int, int]:
    """(width, height) from a PNG's IHDR chunk."""
    data = path.read_bytes()[:24]
    return struct.unpack(">II", data[16:24])


def check_figures(figure_dir: Path, sockets: list[dict]) -> list[str]:
    """Every way the figures in ``figure_dir`` disagree with figures.json or all_figures()."""
    meta_path = figure_dir / FIGURES_JSON
    if not meta_path.is_file():
        return [f"{meta_path} is missing: run the figures subcommand"]
    meta = json.loads(meta_path.read_text(encoding="utf-8"))
    figures = all_figures(sockets, load_presets())
    names = {f.name for f in figures}
    problems = []
    if set(meta["figures"]) != names:
        problems.append(f"figures.json lists {sorted(meta['figures'])}, expected {sorted(names)}")
    present = {p.name for p in figure_dir.iterdir()}
    if present != names | {FIGURES_JSON}:
        problems.append(
            f"{figure_dir} holds {sorted(present)}, expected {sorted(names)} and {FIGURES_JSON}"
        )
    if meta["settings"]["socket_defaults"] != socket_defaults(sockets):
        problems.append("the figures were rendered with other socket defaults: run figures")
    for figure in figures:
        entry, path = meta["figures"].get(figure.name), figure_dir / figure.name
        if entry is None or not path.is_file():
            continue
        data = path.read_bytes()
        if len(data) > MAX_FIGURE_BYTES:
            problems.append(f"{figure.name}: {len(data)} bytes > {MAX_FIGURE_BYTES}")
        if len(data) != entry["bytes"] or hashlib.sha256(data).hexdigest() != entry["sha256"]:
            problems.append(f"{figure.name}: bytes differ from figures.json")
        if list(png_size(path)) != [entry["width"], entry["height"]]:
            problems.append(f"{figure.name}: size differs from figures.json")
        recorded = [
            {k: p.get(k) for k in ("label", *_record(q.source))}
            for p, q in zip(entry["panels"], figure.panels, strict=False)
        ]
        wanted = [{"label": q.label, **_record(q.source)} for q in figure.panels]
        if recorded != wanted:
            problems.append(f"{figure.name}: panels differ from all_figures(): run figures")
    return problems

def _load_file(name: str, path: Path) -> ModuleType:
    spec = importlib.util.spec_from_file_location(name, path)
    if spec is None or spec.loader is None:
        raise RuntimeError(f"cannot load {path}")
    module = importlib.util.module_from_spec(spec)
    spec.loader.exec_module(module)
    return module


def import_painterly(core_build_dir: Path) -> ModuleType:
    """``_painterly``: the module already imported (tests), else the one in
    ``<core_build_dir>/src/blender``."""
    if "_painterly" not in sys.modules:
        sys.path.insert(0, str(core_build_dir / "src" / "blender"))

def module_sha256(module: ModuleType) -> str:
    digest = hashlib.sha256()
    with open(module.__file__, "rb") as f:
        while chunk := f.read(HASH_CHUNK_BYTES):
            digest.update(chunk)
    return digest.hexdigest()


def native_key(source: Source, module_digest: str) -> str:
    """16 hex digits of the sha256 of the canonical JSON of all that a native render depends on."""
    canonical = {
        "format": FORMAT,
        "module_sha256": module_digest,
        "size": FIGURE_SIZE,
        "passes": FIGURE_PASSES,
        "scene": source.scene,
        "knobs": dict(source.knobs),
    }
    text = json.dumps(canonical, sort_keys=True, separators=(",", ":"))
    return hashlib.sha256(text.encode("utf-8")).hexdigest()[:16]


def render_native(source: Source, module: ModuleType, reference: ModuleType, threads: int):
    """One native render: (sums, wall seconds). The sums are identical for any thread count
    (SPEC §3)."""
    scene = module.Scene()
    reference.build_smallpaint_scene(scene, size=FIGURE_SIZE, ghost=SCENE_GHOST[source.scene])
    if source.knobs:
        scene.set_integrator(**dict(source.knobs))
    session = module.Session(scene, threads)
    start = time.monotonic()
    session.start(FIGURE_PASSES, FIGURE_PASSES)
    session.wait()
    seconds = time.monotonic() - start
    progress = session.progress()
    if progress["state"] != "done":
        raise RuntimeError(f"native render {source}: {progress['state']}: {progress['error']}")
    return session.combined(), seconds


class Renders:
    """Experiment and native renders of the figures: listing, rendering, loading."""

    def __init__(self, figures, module, reference, native_cache: Path, threads: int):
        from painterly_analysis import experiment

        self.experiment = experiment
        self.module, self.reference, self.threads = module, reference, threads
        self.digest = module_sha256(module)
        self.native_cache = native_cache
        self._jobs: dict[tuple[str, str], list] = {}
        sources = [p.source for f in figures for p in f.panels]
        self.jobs = list(
            dict.fromkeys(
                j for s in sources if s.kind in ("pair", "half") for j in self.source_jobs(s)
            )
        )
        self.natives = list(dict.fromkeys(s for s in sources if s.kind == "native"))

    def source_jobs(self, source: Source) -> list:
        key = (source.slug, source.configuration)
        if key not in self._jobs:
            directory = experiment_dir(source.slug)
            if directory is None:
                raise FileNotFoundError(f"no experiment directory for slug {source.slug}")
            module = self.experiment.load_jobs_module(directory / "jobs.py")
            self._jobs[key] = module.ENSEMBLES[source.configuration]
        jobs = self._jobs[key]
        return list(jobs[:2] if source.kind == "pair" else jobs[:1])

    def native_dir(self, source: Source) -> Path:
        return self.native_cache / native_key(source, self.digest)

    def render(self, budget: float) -> tuple[int, int]:
        """Render what is missing until ``budget`` seconds have passed: (completed, remaining)."""
        start = time.monotonic()
        status = self.experiment.run_jobs(self.jobs, budget_seconds=budget)
        for source in self.natives:
            directory = self.native_dir(source)
            if (directory / DONE).is_file():
                continue
            if time.monotonic() - start >= budget:
                break
            sums, seconds = render_native(source, self.module, self.reference, self.threads)
            directory.mkdir(parents=True, exist_ok=True)
            np.save(directory / "sum.npy", sums)
            meta = {
                "format": FORMAT,
                "module_sha256": self.digest,
                "size": FIGURE_SIZE,
                "passes": FIGURE_PASSES,
                "scene": source.scene,
                "knobs": dict(source.knobs),
                "threads": self.threads,
                "wall_seconds": seconds,
            }
            (directory / "meta.json").write_text(json.dumps(meta, sort_keys=True, indent=1) + "\n")
            (directory / DONE).write_text("done\n")
            print(f"native {source.scene} {dict(source.knobs)}: {seconds:.1f} s", flush=True)
        native_remaining = sum(not (self.native_dir(s) / DONE).is_file() for s in self.natives)
        completed = status.completed + len(self.natives) - native_remaining
        return completed, status.remaining + native_remaining

    def display(self, source: Source) -> tuple[np.ndarray, dict]:
        """The display image of a panel (uint8 (H, W, 3), SPEC §7) and the fields of its
        figures.json entry that come from the render (``_record`` gives the others)."""
        from painterly_analysis import io

        if source.kind == "reference":
            img = io.read_ppm(REFERENCE_PPM)
            return img, {"file": str(REFERENCE_PPM.relative_to(REPO)), "size": int(img.shape[0])}
        if source.kind in ("pair", "half"):
            jobs = self.source_jobs(source)
            renders = [self.experiment.load(job) for job in jobs]
            total = np.asarray(renders[0].sum, dtype=np.float64)
            for r in renders[1:]:
                total = total + np.asarray(r.sum, dtype=np.float64)
            if source.light_w is not None:
                total = total * (source.light_w / REFERENCE_LIGHT_W)
            img = io.smallpaint_display(_finite(total, source), sum(r.passes for r in renders))
            return img, {
                "experiment": experiment_dir(source.slug).name,
                "seeds": [job.seed for job in jobs],
                "passes": [r.passes for r in renders],
                "size": int(img.shape[0]),
            }
        sums = np.load(self.native_dir(source) / "sum.npy")
        img = io.smallpaint_display(_finite(sums, source), FIGURE_PASSES)
        return img, {"passes": FIGURE_PASSES, "size": int(img.shape[0])}


def _record(source: Source) -> dict:
    """The fields of a panel's source that figures.json records and check_figures compares, in
    their JSON form (tuples become lists)."""
    if source.kind == "reference":
        record: dict = {"source": "reference"}
    elif source.kind == "native":
        record = {"source": "native", "scene": source.scene, "knobs": list(source.knobs)}
    else:
        record = {
            "source": source.kind,
            "slug": source.slug,
            "configuration": source.configuration,
            "light_w": source.light_w,
        }
    return json.loads(json.dumps(record))


def socket_defaults(sockets: list[dict]) -> dict:
    """Every socket's default, in JSON form: the native renders depend on all of them."""
    return json.loads(json.dumps({s["name"]: s["default"] for s in sockets}))


def _finite(sums: np.ndarray, source: Source) -> np.ndarray:
    """``sums``, after checking that every value is finite: the display mapping (SPEC §7) of a NaN
    or an infinity is undefined, so such a panel is an error, never a drawing."""
    if not np.all(np.isfinite(sums)):
        raise ValueError(f"{source}: {int(np.sum(~np.isfinite(sums)))} non-finite radiance sums")
    return sums


def view(img: np.ndarray, kind: str) -> np.ndarray:
    """The part of a square display image that a panel shows."""
    from painterly_analysis import report

    side = img.shape[0]
    if img.shape[1] != side:
        raise ValueError(f"panel images are square, got {img.shape}")
    if kind == "full":
        return img
    if kind == "preview":
        return report.block_preview(img, PREVIEW_FACTOR)
    if kind in ("crop", "edge") and side != FIGURE_SIZE:
        raise ValueError(f"a {kind} view needs a {FIGURE_SIZE} px image, got {side} px")
    if kind == "crop":
        return img[CROP_ROW : CROP_ROW + CROP_SIDE, CROP_COL : CROP_COL + CROP_SIDE]
    if kind == "edge":
        win = img[EDGE_ROW : EDGE_ROW + EDGE_SIDE, EDGE_COL : EDGE_COL + EDGE_SIDE]
        return np.repeat(np.repeat(win, EDGE_ZOOM, axis=0), EDGE_ZOOM, axis=1)
    if kind == "window":
        row, col, width = WINDOW_ROW * side, WINDOW_COL * side, WINDOW_SIDE * side
        if any(v.denominator != 1 for v in (row, col, width)) or WINDOW_PANEL_SIDE % width:
            raise ValueError(f"the window is not whole pixels at {side} px")
        r, c, w = int(row), int(col), int(width)
        zoom = WINDOW_PANEL_SIDE // w
        return np.repeat(np.repeat(img[r : r + w, c : c + w], zoom, axis=0), zoom, axis=1)
    raise ValueError(f"unknown view {kind}")


def compose(figures, renders: Renders, out_dir: Path, sockets: list[dict]) -> dict:
    """Write every figure into ``out_dir`` and return the figures.json content."""
    from painterly_analysis import io, metrics, report

    out_dir.mkdir(parents=True, exist_ok=True)
    entries = {}
    for figure in figures:
        tiles, panels = [], []
        for panel in figure.panels:
            img, rendered = renders.display(panel.source)
            meta = {"label": panel.label, **_record(panel.source), **rendered}
            meta["clip_fraction"] = float(metrics.clip_fraction(img))
            panels.append(meta)
            tile = view(img, figure.view)
            g = GUTTER_PX
            tiles.append(np.pad(tile, ((g, g), (g, g), (0, 0)), constant_values=255))
        grid = report.mosaic(tiles, figure.columns)
        path = out_dir / figure.name
        io.write_png(path, grid)
        data = path.read_bytes()
        if len(data) > MAX_FIGURE_BYTES:
            raise ValueError(f"{figure.name}: {len(data)} bytes > {MAX_FIGURE_BYTES}")
        entries[figure.name] = {
            "title": figure.title,
            "section": figure.section,
            "knob": figure.knob,
            "view": figure.view,
            "columns": figure.columns,
            "clip_fraction": figure.clip_fraction,
            "width": int(grid.shape[1]),
            "height": int(grid.shape[0]),
            "bytes": len(data),
            "sha256": hashlib.sha256(data).hexdigest(),
            "panels": panels,
        }
    for stale in sorted(out_dir.glob("fig_*.png")):
        if stale.name not in entries:
            stale.unlink()
    return {
        "format": FORMAT,
        "settings": {
            "figure_size": FIGURE_SIZE,
            "figure_passes": FIGURE_PASSES,
            "crop": [CROP_ROW, CROP_COL, CROP_SIDE],
            "window": [str(WINDOW_ROW), str(WINDOW_COL), str(WINDOW_SIDE), WINDOW_PANEL_SIDE],
            "edge": [EDGE_ROW, EDGE_COL, EDGE_SIDE, EDGE_ZOOM],
            "preview_factor": PREVIEW_FACTOR,
            "gutter_px": GUTTER_PX,
            "max_figure_bytes": MAX_FIGURE_BYTES,
            "socket_defaults": socket_defaults(sockets),
        },
        "figures": entries,
    }
