# T7.2 — Presets from experiment results: Smallpaint Reference, Showcase (approx.), Fine, Broad and Soft strokes
Milestone: M7 · Depends on: T7.1 (and through it all of M4 and M5) · Parallel-safe: no

## Goal
After this card:
- The presets popover in the Sampling panel header (T7.1) lists five shipped presets: **Broad strokes**, **Fine strokes**,
  **Showcase (approx.)**, **Smallpaint Reference** and **Soft strokes** (Blender sorts them by file name).
- Every value a preset sets is cited, in a comment above it, to a final experiment result (001, 002, 003; jitter: 006 and
  the jitter dose-response experiment when it is final) or to the SPEC section that defines it.
- A preset gives the same knobs from any prior state. `presets.PRESET_SOCKETS` names the look knobs every preset determines.
  The preset panel's `reset_cb` returns each of them to its `PainterlyIntegrator` socket default before the preset file
  runs, so a preset file writes only the values that differ from the defaults, and no default is ever written twice.
- Presets set only `scene.painterly` integrator sockets, plus `reference_scene` in the two built-in-scene presets
  (Smallpaint Reference and Showcase), which also reset `output_mode`. They never touch lights, the view transform, the
  display or the render size (SPEC §6, §8). `PAINTERLY_OT_apply_display_settings` stays the explicit way to get
  smallpaint's display mapping. Both built-in-scene presets need a square resolution, and T4.3 reports an error otherwise.
- A user preset saved with the add-preset button holds exactly `PRESET_SOCKETS`, and applying it restores them (round trip).
- `tests/blender/test_presets.py` proves all of the above.

**Verification of T4.2's "Smallpaint Reference".** It has two defects, and this card fixes both:
1. Its file is `smallpaint_reference.py`. `PresetPanel` menus show file names with `display_name(..., title_case=False)`
   (Blender v5.2.2 `scripts/modules/_bpy_types.py:1461`), so the menu reads "smallpaint reference". The file is renamed
   `Smallpaint_Reference.py`, the convention of Blender's bundled presets (`presets/cycles/sampling/Final.py`).
2. It sets `chain` and `reference_scene` and unsets `output_mode` and `passes`, but leaves `alpha`, `u2_mode`,
   `k0_phase_lock_bits`, `continue_after_emitter`, `jitter`, `lane_length` and `max_depth` at whatever an earlier preset or
   the user set. Reference mode keeps those user values (T4.3), so after "Soft strokes" the reference preset would render
   with α = 0.25. `reset_cb` fixes this for every preset.

## Interface

### `src/blender/addon/presets.py`
```python
PRESET_SOCKETS: tuple[str, ...] = (
    "chain", "lane_length", "passes", "u2_mode", "k0_phase_lock_bits",
    "alpha", "max_depth", "continue_after_emitter", "jitter",
)  # socket order (T3.13)

class PAINTERLY_PT_render_presets(PresetPanel, Panel):  # T4.2; attributes this card relies on
    preset_subdir = "painterly/render"
    preset_operator = "script.execute_preset"
    preset_add_operator = "painterly.render_preset_add"

    @staticmethod
    def reset_cb(context, _filepath): ...  # property_unset(name) on context.scene.painterly for name in PRESET_SOCKETS

class PAINTERLY_OT_render_preset_add(AddPresetBase, Operator):  # T4.2; bl_idname "painterly.render_preset_add"
    preset_menu = "PAINTERLY_PT_render_presets"
    preset_subdir = "painterly/render"
    preset_defines = ["painterly = bpy.context.scene.painterly"]
    preset_values = [f"painterly.{name}" for name in PRESET_SOCKETS]
```
- **Applying a preset** means `bpy.ops.script.execute_preset(filepath=<file>, menu_idname="PAINTERLY_PT_render_presets")`,
  which is what the popover does: `reset_cb` first, then the file. `bpy.utils.execfile(<file>)` alone skips the reset and is
  not a preset application.
- **A shipped preset file** has exactly this shape: `import bpy`, `painterly = bpy.context.scene.painterly`, then only
  assignments `painterly.<name> = <constant expression>` with `<name>` in `PRESET_SOCKETS` or `reference_scene`, and
  `painterly.property_unset("output_mode")`. Comments cite each value.
- **Rule for later cards.** A new socket is outside `PRESET_SOCKETS`, so presets leave it alone, until a card adds it there.
  That card lists `tests/blender/test_presets.py` under Modify and updates the `PRESET_SOCKETS` assertion. Shipped files need
  no change, because `reset_cb` gives the new knob its default. T7.5's artist guide documents the table below.

### The shipped presets (`src/blender/addon/presets/painterly/render/`)
Every knob of `PRESET_SOCKETS` not listed in "Sets" is at its socket default after the preset: `chain` "row",
`lane_length` 16 px, `passes` 1024, `u2_mode` "same", `k0_phase_lock_bits` 0, `alpha` 0, `max_depth` 20,
`continue_after_emitter` True and `jitter` 1/1400 of the fitted image side.

| File | Menu name | Sets | Source of each value |
|---|---|---|---|
| `Smallpaint_Reference.py` | Smallpaint Reference | `chain = "image"`, `reference_scene = True`, unsets `output_mode` | SPEC §3, §8, §9; experiment 001 (H1, H5) |
| `Showcase_(approx.).py` | Showcase (approx.) | `reference_scene = True`, unsets `output_mode`; `chain` stays "row" | SPEC §8, §9; experiment 003 H3 (row ≡ image, 0 of 46 keys) |

| `Broad_strokes.py` | Broad strokes | `continue_after_emitter = False`; `jitter` per Step 2 | experiment 002 H4; Step 2 |
| `Soft_strokes.py` | Soft strokes | `alpha = 0.25`; `jitter` per Step 2 | experiment 002 H3 (0.25: the smallest α measured); Step 2 |

Units: `jitter` is a fraction of the camera's fitted image side (SPEC §7), `lane_length` is in pixels, `passes` counts
passes, `alpha` is the dimensionless exponent of `d · |d|^(−α)` (SPEC §4).

The cited effects were measured with the oracle on the reference scene (every sphere a ghost, chain `image`, 400 px,
64 passes). On a Blender scene, where only lights are ghosts (002 H5) and the chain is `row`, their size may differ. The
directions are the citable result. T7.5 renders each preset.

   CASES = [

   ]


   def _presets_module():
       return importlib.import_module("painterly.presets")


   def _sockets() -> dict[str, dict]:
       return {s["name"]: s for s in _painterly.integrator_sockets()}


   def _as_stored(socket: dict, value: object) -> object:
       """The value Blender stores: float sockets are float32 (RNA float properties)."""
       return float(np.float32(value)) if socket["type"] == "float" else value


   def _plain(value: object) -> object:
       """A comparable copy of an RNA value: arrays and collections become tuples, groups dicts."""
       if value is None or isinstance(value, (bool, int, float, str, bpy.types.ID)):
           return value
       if isinstance(value, bpy.types.PropertyGroup):
           return _snapshot(value)
       if isinstance(value, set):
           return frozenset(value)
       return tuple(_plain(v) for v in value)


   def _names(group: bpy.types.PropertyGroup) -> list[str]:
       """The group's property names, without RNA bookkeeping."""
       return [
           p.identifier for p in group.bl_rna.properties if p.identifier not in ("rna_type", "name")
       ]


   def _snapshot(group: bpy.types.PropertyGroup) -> dict[str, object]:
       return {n: _plain(getattr(group, n)) for n in _names(group)}


   def _external(scene: bpy.types.Scene) -> dict[str, object]:
       """Everything a preset must never change: view and display settings, the render size and
       every light (SPEC §6, §8)."""
       view, render = scene.view_settings, scene.render
       snap: dict[str, object] = {
           "view": (view.view_transform, view.look, view.exposure, view.gamma),
           "display_device": scene.display_settings.display_device,
           "render": (
               render.engine,
               render.dither_intensity,
               render.resolution_x,
               render.resolution_y,
               render.resolution_percentage,
           ),
       }
       for light in bpy.data.lights:
           snap[f"light:{light.name}"] = (
               light.type,
               light.energy,
               tuple(light.color),
               light.shadow_soft_size,
               _snapshot(light.painterly),
           )
       return snap


   def _unset_all(group: bpy.types.PropertyGroup) -> None:
       for name in _names(group):
           group.property_unset(name)


   def _perturbed(prop: bpy.types.Property, value: object, probe: bpy.types.Object) -> object:
       """A different valid value of the same property, derived from its RNA definition, or KEEP."""
       if prop.type == "BOOLEAN" and not prop.is_array:
           return not value
       if prop.type == "ENUM" and not prop.is_enum_flag:
           ids = [item.identifier for item in prop.enum_items]
           return ids[(ids.index(value) + 1) % len(ids)] if len(ids) > 1 else KEEP
       if prop.type in {"INT", "FLOAT"}:

           def step(v):
               return v + 1 if v + 1 <= prop.hard_max else v - 1

           return tuple(step(v) for v in value) if prop.is_array else step(value)
       if prop.type == "POINTER" and prop.fixed_type.identifier == "Object":
           return probe if value is None else None
       return KEEP


   def _perturb(scene: bpy.types.Scene, probe: bpy.types.Object) -> None:
       """Move every perturbable scene.painterly property, the view exposure and gamma, and every
       light's energy away from its current value."""
       settings = scene.painterly
       for prop in settings.bl_rna.properties:
           name = prop.identifier
           if name in NOT_PERTURBED or prop.is_readonly:
               continue
           new = _perturbed(prop, getattr(settings, name), probe)
           if new is KEEP:
               continue
           before = _plain(getattr(settings, name))
           setattr(settings, name, new)
           assert _plain(getattr(settings, name)) != before, name
       scene.view_settings.exposure += 1
       scene.view_settings.gamma += 1
       for light in bpy.data.lights:
           light.energy += 1


   def _apply(path: Path) -> None:
       assert bpy.ops.script.execute_preset(filepath=str(path), menu_idname=MENU) == {"FINISHED"}


   def _set_prior(scene: bpy.types.Scene, prior: str, probe: bpy.types.Object) -> None:
       _unset_all(scene.painterly)
       if prior == "defaults":
           return
       _perturb(scene, probe)
       if prior.startswith("after:"):
           _apply(SHIPPED_DIR / prior.removeprefix("after:"))

   @pytest.mark.parametrize(("name", "prior"), CASES)
   def test_apply_from_any_prior_state(name, prior, probe):
       scene, expected, sockets = bpy.context.scene, EXPECTED[name], _sockets()
       preset_sockets = _presets_module().PRESET_SOCKETS
       settings = scene.painterly
       _set_prior(scene, prior, probe)
       before, external = _snapshot(settings), _external(scene)
       _apply(SHIPPED_DIR / name)
       after = _snapshot(settings)
       for socket in preset_sockets:
           default = sockets[socket]["default"]
           if socket in expected.values:
               assert after[socket] == _as_stored(sockets[socket], expected.values[socket]), socket
               assert after[socket] != default, socket
           else:
               assert after[socket] == default, socket
               assert not settings.is_property_set(socket), socket
       owned = set(preset_sockets)
       if expected.builtin_scene:
           assert after["reference_scene"] is True
           assert after["output_mode"] == sockets["output_mode"]["default"]
           assert not settings.is_property_set("output_mode")
           owned |= {"reference_scene", "output_mode"}
       assert {k: v for k, v in after.items() if k not in owned} == {
           k: v for k, v in before.items() if k not in owned
       }
       assert _external(scene) == external
