# T7.3 — `lane_stagger`: a per-row offset of the lane grid, and experiment NNN (seam-column amplitude with and without stagger)
Milestone: M7 · Depends on: T7.2 (and through it T7.1 and all of M3, M4 and M5) · Parallel-safe: no

## Goal
After this card:
- `PainterlyIntegrator` has an `int` socket **`lane_stagger`** (group Sampling, default 0, min 0), placed right after
  `lane_length`. With `chain = lane`, the lane grid of row `r` is offset by `o = (r · lane_stagger) mod lane_length`
  pixels (the lane grid of SPEC §3 as amended below). `image` and `row` ignore it.
- `lane_stagger = 0` is the current lane grid **bit for bit**. Every existing test, the core-vs-oracle parity (T3.16), the
  Blender end-to-end parity (T4.4) and the Blender reference parity (T5.4) pass unchanged. The oracle is not touched.
- The kernel's lane grid lives in four `ccl_device_inline` functions of `painterly/kernel/sample/sampler.h`. The lane
  scheduler (`painterly/integrator/path_trace.cpp`) takes its units and spans from them. The output stays bit-identical
  for any thread count and batching (SPEC §3), now also with a stagger.
- In Blender, `scene.painterly.lane_stagger` exists (generated from the socket, T4.2), is drawn in the Sampling panel
  (T7.1), is greyed out unless the chain is Lane (`ui.ACTIVE_WHEN`), and is returned to its default by every preset
  (`presets.PRESET_SOCKETS`, T7.2). No shipped preset sets it.
- **Experiment NNN** (number assigned when it runs) is pre-registered by this card and run by it. It measures the
  seam-column amplitude of `chain = lane` with and without stagger, with the native core through `_painterly.Session`.

## Opus decisions (fixed for this card)
1. **Lane grid.** `o_row = (row · S) mod L`, with `S = lane_stagger`, `L = lane_length`. Lane `m ≥ 0` of a row covers the
   global columns `[max(0, m·L − o), min(W, (m+1)·L − o))`, so column `col` lies in lane `(col + o) div L`, and the row
   has `ceil((W + o) / L)` lanes. The grid of row `r + 1` is the grid of row `r` shifted left by `S` (mod L).
2. **Knob.** `int`, default 0, minimum 0, no maximum: only `S mod L` matters. A negative value is a kernel precondition
   violation, rejected by `Scene.set_integrator` (ValueError) and by `PainterlyPathTrace` (std::invalid_argument),
   exactly like `lane_length < 1`.
3. **Chain starts.** `K0 = rng_u32(seed, PURPOSE_LANE_K0, 0, row, lane_in_row, pass) mod 2^22`, unchanged in form, with
   `lane_in_row` from the lane grid above. With `S = 0` every `(row, lane_in_row)` covers the same pixels as today.
4. **Oracle untouched.** `smallpaint_oracle` gets no `--lane-stagger`. Bit parity with it is required where the lane
   grid is the oracle's: `S ≡ 0 (mod L)`, and `row`/`image` with any `S`. A grid that moves (`S ≢ 0`) is tested against
   the SPEC definition: an independent column walk and a serial reference render (`src/test/test_lane_stagger.cpp`).
5. **The default stays 0 in every outcome of experiment NNN.** SPEC §8 defaults equal the reference behaviour, and 0 is
   the grid that experiment 003 measured. The experiment decides what SPEC §3 and the artist guide say about the knob.
6. **Presets** reset it to its socket default before every preset (it joins `PRESET_SOCKETS`); none sets it.
7. **UI**: active only when the effective chain is `lane`, like `lane_length`.

## SPEC change (Opus)
Proposed text for `docs/spec.md`. Opus applies it; the agent never edits the SPEC. This card implements it as written.

**§0 Terms.** Replace the `lane` row and add a `seam` row after it:

| Term | Meaning |
|---|---|
| **lane** | Up to L consecutive pixels of one row, on that row's lane grid (§3). |
| **seam** | The first pixel of every lane except the first lane of its row (§3). |

**§3 Chains.** Replace the whole `lane` bullet (from "**`lane`** (knob `lane_length` …" to the line that ends with
"`K0 = rng_u32(seed, PURPOSE_LANE_K0, 0, row, lane_in_row, pass) mod 2^22`.") with:

> - **`lane`** (knobs `lane_length` = L ≥ 1 pixels, default 16, and `lane_stagger` = S ≥ 0 pixels, default 0). A
>   stylization and GPU-parallelism option.
>   - Fidelity to the reference pattern grows with L. Pattern correlation is 0.126, 0.210, 0.327, 0.427, 0.500, 0.542, 0.564 and 0.573
>     for L = 1, 2, …, 128, against 0.590 for `row` (experiment 003). The texture amplitude is flat from L = 2. The anisotropy is not:
>     at L = 16 the lag-1 is −23% along rows and +17% along columns, relative to `row`.
>   - Each lane start is a **seam**. Its structure amplitude is about 50% above the lane's median: 8.2-9.0 vs 5.5-5.7 on the
>     back wall for L = 16…128 (exploratory analysis of experiment 003). With S = 0 the lanes are aligned in global
>     coordinates, so the seams line up across rows into **seam columns**, visible at short L. `lane_stagger` offsets the
>     lane grid of each row; experiment NNN measures the seam-column amplitude with and without it.
>   - **Lane grid.** Row `row` has the offset `o = (row·S) mod L` pixels, `0 ≤ o < L`. Its lane `lane_in_row = m ≥ 0` covers
>     the columns `[max(0, m·L − o), min(W, (m+1)·L − o))` in *global* image coordinates, so column `col` lies in lane
>     `(col + o) div L`, and the row has `ceil((W + o)/L)` lanes. The first lane has `min(W, L − o)` pixels, and the last
>     may be shorter.
>     - With S = 0, `o = 0` in every row and lane m is `[L·m, min(W, L·(m+1)))`: the lanes of SPEC v1, bit for bit.
>     - Only `S mod L` matters. The seams of a row are its columns `j > 0` with `(j + o) mod L = 0`, so the grid of row
>       `row + 1` is that of row `row` shifted left by S (mod L). With `g = gcd(S mod L, L)` (g = L when S mod L = 0), the
>       seams of every row fall in the column classes `j mod L` that are multiples of g, and each such class takes the seams
>       of a fraction g/L of the rows. g = 1 spreads them evenly over all L classes.
>     - `image` and `row` ignore `lane_stagger`.
>   - One chain per (lane, pass), walking columns left to right. `K0 = rng_u32(seed, PURPOSE_LANE_K0, 0, row, lane_in_row, pass) mod 2^22`,
>     with `lane_in_row` from the lane grid.
>   - The oracle has no `lane_stagger`: its `lane:L` is S = 0. Core-oracle bit parity therefore covers S ≡ 0 (mod L) and the
>     chains without lanes; the core's moving grid is tested against the definition above (T7.3).

**§8 Knobs**, Sampling row: after the `lane_length (…)` entry insert
"`lane_stagger` (0; only for `chain=lane`: the lane grid of row r is offset by (r·S) mod L pixels, §3; 0 is the aligned
grid of experiment 003, bit for bit)".

When experiment NNN is final, Opus replaces "experiment NNN measures the seam-column amplitude with and without it" with
its result (see "What each outcome means" in the pre-registration).

~~~markdown
# Experiment NNN: does a per-row lane offset (lane_stagger) remove the seam columns of chain=lane?

## Background

- `docs/plan.md`, "What makes the look", item 3 (scan-line chaining): each path's counter K starts where the previous
  pixel's path in the same row ended, and that chaining makes the converged texture. `chain=lane` (SPEC §3) restarts K at
  a hashed K0 every L pixels of a row.
- `docs/spec.md` §3, lane grid (amended with T7.3): row `row` has the offset `o = (row·S) mod L` pixels, with
  `S = lane_stagger` and `L = lane_length`. Lane `m` covers the columns `[max(0, m·L − o), min(W, (m+1)·L − o))`. Each
  lane after the first starts at a column `j` with `(j + o) mod L = 0`: a **seam**. With S = 0 the seams of every row fall
  in the columns `j ≡ 0 (mod L)`, the **seam columns**. With `g = gcd(S mod L, L)` they fall in the column classes
  `j mod L` that are multiples of g, each class taking the seams of a fraction g/L of the rows. `lane_stagger` defaults
  to 0, the grid of experiment 003, bit for bit.
- `experiments/003-2026-10-08-lane-length/` (final): lanes are a stroke-shape knob, not a fidelity knob. At L = 16 the
  back wall's lag-1 is −23% along rows and +17% along columns relative to `row`. An exploratory per-offset analysis found
  a seam column at each lane start, about +50% amplitude, aligned across rows (SPEC §3: 8.2-9.0 vs 5.5-5.7 display bytes
  on the back wall for L = 16…128). Decision 3: a deterministic per-row lane offset, `lane_stagger`, is a candidate knob
  for an M7 experiment. This is that experiment.
- Pilot (card T7.3; exploratory, not evidence). Experiment 003's cached oracle renders `lane_16` (block 23) and `row`
  (block 27), 8 pairs each, 400 px, P = 64, measured with the definitions below. E_col is mean ± sd over pairs; p is the
  exact two-sided permutation p-value of lane_16 against row.

  | region (SPEC §9) | E_col, lane_16 | E_col, row | p |
  |---|---:|---:|---:|
  | r3 floor | −0.147 ± 0.049 | +0.004 ± 0.026 | 1.55e-4 |
  | r4 back wall | +0.449 ± 0.045 | +0.022 ± 0.042 | 1.55e-4 |
  | r5 left wall | −0.027 ± 0.094 | +0.033 ± 0.076 | 0.181 |
  | r6 right wall | +0.166 ± 0.051 | −0.009 ± 0.070 | 1.55e-4 |
  | r7 ceiling | +0.237 ± 0.061 | −0.034 ± 0.045 | 1.55e-4 |

  - The sign of the seam signature depends on the region: on the floor the seam column has less amplitude than the
    median column. On the back wall the pixel after the seam is also low: the mean column profile starts 8.04, 4.85,
    5.41 display bytes, with a median of 5.55.
  - The de-alignment prediction (H3, "Estimation") from lane_16's chain profiles is E_col = 0 for g = 1. For S = 8

## Hypothesis

### Common definitions

- **Configurations.** `row`, `lane16_s0`, `lane16_s1`, `lane16_s5` and `lane16_s8` (Method). Each is 8 pairs. A pair is
  two half renders with seeds 2k and 2k + 1 of the configuration's block. A half render is the analytic SPEC §9 scene
  (`build_smallpaint_scene(scene, size=400)`, ghost spheres for every sphere) with P = 64 passes, rendered by the native
  core. Every knob keeps its socket default except `seed` and the configuration's chain knobs. L = 16 px.
- **Pixel classes.** Column class `q = col mod L`. Chain position `κ` = the column minus the first column of its lane
  (SPEC §3 lane grid; `κ = col` for `row`), and chain class `k = κ mod L`. For `lane16_s0` the two classes coincide, and
  for `row` the chain class is the column class.
- **Per pair (a, b).** `hp_x = metrics.highpass(metrics.luminance(io.smallpaint_display(sum_x, 64)))`, display bytes.
  Masks `M_r = metrics.region_masks(object_id, 4)[r]` for `r` in R = (3, 4, 5, 6, 7), the planes in view (SPEC §9: floor,
  back wall, left wall, right wall, ceiling). A region is measured only if every class of both partitions has pixels in
  every configuration. Excluded regions are reported.
- **Profiles.** `A_col_r(q) = metrics.structure_std(hp_a, hp_b, M_r & (q-class))` and `A_chain_r(k)` likewise, in display
  bytes.
- **Seam excess.** `E_col_r = A_col_r(0) / median_q A_col_r(q) − 1`, the **seam-column excess**, and
  `E_chain_r = A_chain_r(0) / median_k A_chain_r(k) − 1`, the seam excess in chain coordinates. Both are dimensionless.
  Class 0 holds the seams: with S = 0 all of them; with S > 0, column class 0 holds the seams of the rows with `o = 0`, a
  fraction g/L of the rows.
- **Texture keys T** (15): `r{r}.structure_std = structure_std(hp_a, hp_b, M_r)`, and
  `r{r}.slag1.x`, `r{r}.slag1.y = metrics.noise_corrected_lag(hp_a, hp_b, M_r, axis, lag=1)` along rows (axis 1) and
  columns (axis 0), 1 px.
- **Estimation only:** `r{r}.mean.{R,G,B}` of `ab8 = smallpaint_display(sum_a + sum_b, 128)`; the mean profiles; the
  seam lattice of each stagger (Method).
- **Significance.** α = 0.01 per hypothesis family (`SIGNIFICANCE`; not the knob `alpha`). Every p-value is an exact
  two-sided permutation p-value (`ensemble.permutation_pvalue`). Holm (`ensemble.holm`) runs within each family at 0.01;
  H4 runs each of its three comparisons at 0.01/3.
- **Power.** With 8 vs 8 pairs the smallest attainable two-sided p is 2/C(16, 8) = 1.55e-4. The largest family, H3 with
  at most 15 tests, has a first Holm threshold of 6.67e-4, and H4's is (0.01/3)/15 = 2.22e-4. Every family is powered.
  `analyze.py` checks this with `ensemble.min_attainable_pvalue`, and an underpowered family is inconclusive.
- **Estimation with every verdict.** Every test reports mean ± sd of both sides, the difference, `rel_diff` and Cohen's d
  (`ensemble.effect_summary`). "Not rejected" is always written together with `min_attainable_p`, the difference and d.

### H1: without stagger the seam columns exist (positive control; replicates 003's exploratory finding)

- Derived from: 003's exploratory analysis (SPEC §3: about +50% on the back wall) and the pilot (back wall E_col 0.449 vs
  0.022; floor −0.147 vs 0.004). New seeds and the native core make this an independent replication.
- Test: for each measured region, `E_col_r(lane16_s0)` against `E_col_r(row)`, Holm over the measured regions.
- The rejected regions are the **seam regions R1**. The pilot predicts R1 = {3, 4, 6, 7}, with a negative sign on r3.
- Decision: supported iff r4 is in R1 and the mean of `E_col_r4(lane16_s0)` exceeds that of `row`. Refuted otherwise.
  Inconclusive if r4 is not measured. The other regions are reported with their signs, without a verdict.

### H2: a stagger with gcd(S mod L, L) = 1 removes the seam columns

- Derived from: SPEC §3's lane grid. For g = 1 the row offsets run through all L values, so every column class holds the
  seams of 1/L of the rows, the same share as every other class. If a seam's amplitude belongs to its chain position (the
  de-alignment reading, H3), the column profile is flat: `E_col` falls to the noise floor. The pilot's de-alignment
  prediction for g = 1 is exactly 0.
- (a) Removal: for S ∈ {1, 5} and every r in R1, `E_col_r(lane16_sS)` against `E_col_r(lane16_s0)`, Holm over the
  2·|R1| tests. It holds iff every test rejects, and in each the difference `mean(sS) − mean(s0)` has the sign opposite to
  `mean(s0) − mean(row)` of H1 (the stagger moves E_col toward `row`).
- (b) Noise floor: for S ∈ {1, 5} and every measured region, `E_col_r(lane16_sS)` against `E_col_r(row)`, Holm over
  these 2 × (number of measured regions) tests. It holds iff none rejects.
- Decision: **supported** iff (a) and (b). **Reduced, residual seam column** iff (a) and not (b); the rejected regions of
  (b) are listed. **Refuted** iff (a) fails. **Inconclusive** iff R1 is empty.
- Effect statistic: the **residual fraction** `ρ_r(S) = (m_sS − m_row) / (m_s0 − m_row)`, where m is the mean of
  `E_col_r` over pairs, for every r in R1 and S ∈ {1, 5, 8}. ρ = 0 means removed to the noise floor, ρ = 1 unchanged. Each
  ρ gets a 95% percentile bootstrap interval: 10,000 resamples (`BOOTSTRAP_RESAMPLES`), `numpy.random.default_rng(0)`,
  pairs resampled with replacement within each of the three configurations. The resample count sets only the Monte Carlo
  precision. No decision depends on the intervals, but the Conclusion says whether each g = 1 interval contains 0.
  S = 8 (g = 8) is estimation only: the pilot predicts ρ_r4(8) = 0.52.

### H3: the stagger moves the seams and leaves them unchanged (the contrast that separates H2's readings)

- Two readings predict H2(a):
  - **A, de-alignment:** each chain keeps its amplitude profile, and only the columns where chains start change;
  - **B, neighbourhood:** a seam's amplitude depends on whether the pixels above and below it are seams too, for
    instance through the 9 × 9 high-pass window, which spans 9 rows of an aligned seam column, or through a vertical
    coupling of the seams' structure. Then the stagger changes the seam itself.
- Observable: `E_chain`. A predicts it unchanged by the stagger, and B predicts a change.
- Test: for S ∈ {1, 5, 8} and every r in R1, `E_chain_r(lane16_sS)` against `E_chain_r(lane16_s0)`, Holm over the
  3·|R1| tests.
- Decision: supported (A) iff no test rejects; refuted (B) iff any rejects, listed with its sign. Inconclusive iff R1 is
  empty. H1 is the positive control of this statistic: for `lane16_s0` and `row`, `E_chain = E_col`.
- Estimation: the de-alignment prediction `E_pred_r(S)`. For each pair of `lane16_s0`, column class q pools the chain
  classes `(q + j·g) mod L`, j = 0 … L/g − 1, from equal shares of rows, so its variance is the mean of their
  `A_chain²`; `E_pred` is the seam excess of the pooled profile. It is reported with the measured `E_col_r(lane16_sS)`,
  and as `ρ_pred` for the regions in R1.
- R1 is selected on `lane16_s0`, which H2(a) and H3 reuse. The selection favours extreme `lane16_s0` values, which makes
  H2(a) easier to reject and H3 harder to support.

### H4: the stagger leaves the region texture unchanged

- Derived from: the stagger changes only which columns chains start in. Every lane except the first and the last of a
  row still has L pixels, and the region keys average over all chain positions. Reading B, or a dependence of vertically
  adjacent pixels on sharing a chain position (S = 0 aligns them), would show in `r{r}.slag1.y`.
- Test: for S ∈ {1, 5, 8}, `lane16_sS` against `lane16_s0` on T, Holm over the 15 keys at 0.01/3.
- Positive control (sensitivity of T): `lane16_s0` against `row` on T, Holm over the 15 keys at 0.01. Experiment 003
  found lane_16's back-wall lag-1 different from row's (−23% along rows, d −8.1).
- Decision: inconclusive iff the positive control rejects no key. Otherwise supported iff no key is rejected in any of
  the three comparisons, and refuted iff any is; the rejected keys are listed.

### What each outcome means (pre-registered, for Opus's conclusion)

- In every outcome the default of `lane_stagger` stays 0 (card T7.3, Opus decision 5).
- H2 and H3 supported: SPEC §3 states that a stagger with gcd(S mod L, L) = 1 removes the seam columns, with the r4 ρ
  values and their intervals. It also states where the seams go instead: the seam lattice of Table 6 (for example, S = 1
  puts them on 45° diagonals). The artist guide (T7.5) recommends g = 1 staggers.
- H2 "reduced, residual seam column": SPEC §3 says that the stagger lowers the seam columns but leaves a residual, with

- H2 refuted: the knob stays, documented as moving the lane starts without removing the seam columns.
- H3 refuted: SPEC §3's "about 50% above the lane's median" is qualified as the amplitude of aligned seams.
- H4 refuted: the knob's tooltip and the artist guide say which texture keys the stagger changes, with their effect

## Method

### Configurations

Every configuration: 400 px, P = 64 passes per half render, 8 pairs, native core (`render.py`), every other knob at its

| name | knobs (`set_integrator`) | g = gcd(S mod 16, 16) | seam lattice: shortest vector, length | block | seeds |
|---|---|---:|---|---:|---|

- `B0` = 1 + the highest seed block of every earlier experiment's `JOBS` at pre-registration (card T7.3, Step 11). The
~~~

```cpp
/* The lane grid of SPEC §3 (T7.3). With L = lane_length, the lane grid of `row` is offset by
 *   o = (row * lane_stagger) mod L pixels, 0 <= o < L.
 * Lane m >= 0 of the row covers the global columns [max(0, m*L - o), min(width, (m+1)*L - o)).
 * Column col lies in lane (col + o) div L, and the row has ceil((width + o) / L) lanes. Each lane
 * after the first starts at a column j with (j + o) mod L == 0: a seam.
 * - lane_stagger = 0 (the default) gives o = 0 in every row, so lane m is [m*L, min(width,
 *   (m+1)*L)): the lanes of SPEC v1, bit for bit. Only lane_stagger mod L matters.
 * - CHAIN_IMAGE and CHAIN_ROW have no lane grid: o = 0, and the row is one lane, lane 0.
 * - The products are taken in 64 bits, so no row, stagger or lane length overflows an int.
 * Preconditions, which PainterlyPathTrace checks for CHAIN_LANE: lane_length >= 1 and
 * lane_stagger >= 0. Callers pass row >= 0, col >= 0 and width >= 0. */

/* SPEC §3: the offset o of the lane grid of `row`, in pixels, in [0, lane_length). */
ccl_device_inline int painterly_lane_offset(const KernelPainterlyIntegrator &p, const int row)
{
  if (p.chain != CHAIN_LANE) {
    return 0;
  }
  return int((int64_t(row) * int64_t(p.lane_stagger)) % int64_t(p.lane_length));
}

/* SPEC §3: the number of lanes of `row` in an image `width` pixels wide. */
ccl_device_inline int painterly_lanes_in_row(const KernelPainterlyIntegrator &p,
                                             const int width,
                                             const int row)
{
  if (p.chain != CHAIN_LANE) {
    return 1;
  }
  const int64_t L = p.lane_length;
  return int((int64_t(width) + painterly_lane_offset(p, row) + L - 1) / L);
}

/* SPEC §3: the lane of `row` that contains column `col`. */
ccl_device_inline int painterly_lane_in_row(const KernelPainterlyIntegrator &p,
                                            const int row,
                                            const int col)
{
  if (p.chain != CHAIN_LANE) {
    return 0;
  }
  return int((int64_t(col) + painterly_lane_offset(p, row)) / int64_t(p.lane_length));
}

/* SPEC §3: the columns [*col_begin, *col_end) of lane `lane_in_row` of `row`, clipped to
 * [0, width). A lane_in_row at or past painterly_lanes_in_row() gives an empty span
 * (*col_begin >= *col_end). */
ccl_device_inline void painterly_lane_span(const KernelPainterlyIntegrator &p,
                                           const int width,
                                           const int row,
                                           const int lane_in_row,
                                           int *col_begin,
                                           int *col_end)
{
  if (p.chain != CHAIN_LANE) {
    *col_begin = 0;
    *col_end = (lane_in_row == 0) ? width : 0;
    return;
  }
  const int64_t L = p.lane_length;
  const int64_t begin = int64_t(lane_in_row) * L - painterly_lane_offset(p, row);
  const int64_t end = begin + L;
  *col_begin = int(begin < 0 ? 0 : (begin < width ? begin : int64_t(width)));
  *col_end = int(end < width ? end : int64_t(width));
}
```

```cpp
bool PainterlyPathTrace::render_lanes(const int pass_begin,
                                      const int pass_end,
                                      const std::atomic<bool> &cancel)
{
  const KernelPainterlyIntegrator &p = kg_->data->integrator;
  const int width = buffers_.width;
  const int height = buffers_.height;
  /* SPEC §3: with lane_stagger the rows can have different numbers of lanes. The units cover the
   * largest number, and a unit past the last lane of its row has no pixels. ROW has one lane per
   * row, the whole row. */
  int max_lanes = 0;
  for (int row = 0; row < height; row++) {
    max_lanes = std::max(max_lanes, painterly_lanes_in_row(p, width, row));
  }
  std::atomic<bool> interrupted{false};

  /* A unit is one (row, lane_in_row). The unit index is row-major over the lanes. */
  pool_.parallel_for(int64_t(height) * max_lanes, [&](int64_t unit, int worker) {
    const int row = int(unit / max_lanes);
    const int lane = int(unit % max_lanes);
    int col_begin = 0;
    int col_end = 0;
    painterly_lane_span(p, width, row, lane, &col_begin, &col_end);
    if (col_begin >= col_end) {
      return;
    }
    PainterlyPathVertex *scratch = scratch_[worker].data();

    /* Cancellation is checked before the unit and between its passes (T3.12 card). */
    const auto stop_requested = [&] {
      if (cancel.load() || interrupted.load()) {
        interrupted.store(true);
        return true;
      }
      return false;
    };
    if (stop_requested()) {
      return;
    }

    for (int pass = pass_begin; pass < pass_end; pass++) {
      if (stop_requested()) {
        return;
      }
      uint64_t K = painterly_chain_start(p, row, lane, pass);
      for (int col = col_begin; col < col_end; col++) {
        const PainterlyPathResult result = painterly_trace_pixel(kg_, row, col, pass, &K, scratch);
        accumulate_pixel(buffers_, row, col, result);
      }
    }
  });
  return !interrupted.load();
}
```

```cpp
// A stagger that is a multiple of neither identity lane length, so it moves the lanes.
constexpr int MOVING_STAGGER = 3;

// Grid parameters of the exhaustive lane-grid test. Widths: 1 px, shorter than a lane, exactly
// one lane, the fixture, one more than the fixture, and the reference size (SPEC §9). Lane
// lengths: 1, 2, a non-divisor of 32, the default 16, and two longer than the fixture.
constexpr int GRID_WIDTHS[] = {1, 5, 16, 32, 33, 400};
constexpr int GRID_LANE_LENGTHS[] = {1, 2, 5, 16, 40, 128};
// Staggers: 0 (the default), divisors and non-divisors of 16, 16 and 17 (= 0 and 1 mod 16), and
// INT_MAX, the largest int socket value, for the 64-bit products.
constexpr int GRID_STAGGERS[] = {0, 1, 3, 5, 8, 15, 16, 17, INT_MAX};
// Rows 0..GRID_ROWS-1, plus two large rows for the 64-bit products.
constexpr int GRID_ROWS = 64;
constexpr int GRID_LARGE_ROWS[] = {1 << 20, INT_MAX};

// The lane grid of one row by a column walk (SPEC §3): column col starts a lane iff col == 0 or
// (col + o) mod L == 0, with o = (row * S) mod L in unsigned 64-bit arithmetic. Returns the spans
// [begin, end) in column order. This shares no code with sampler.h.
std::vector<Span> walk_lanes(const int width,
                             const int lane_length,
                             const int stagger,
                             const int row)
{
  const uint64_t L = uint64_t(lane_length);
  const uint64_t o = (uint64_t(row) * uint64_t(stagger)) % L;
  std::vector<Span> spans;
  for (int col = 0; col < width; col++) {
    if (col == 0 || (uint64_t(col) + o) % L == 0) {
      spans.emplace_back(col, col);
    }
    spans.back().second = col + 1;
  }
  return spans;
}

KernelPainterlyIntegrator lane_knobs(const int lane_length, const int stagger)
{
  KernelPainterlyIntegrator p{};
  p.chain = CHAIN_LANE;
  p.lane_length = lane_length;
  p.lane_stagger = stagger;
  return p;
}

// Mismatches of the sampler.h lane grid against walk_lanes for one row.
int64_t row_mismatches(const KernelPainterlyIntegrator &p, const int width, const int row)
{
  const std::vector<Span> spans = walk_lanes(width, p.lane_length, p.lane_stagger, row);
  int64_t mismatches = 0;
  const uint64_t expected_offset = (uint64_t(row) * uint64_t(p.lane_stagger)) %
                                   uint64_t(p.lane_length);
  mismatches += uint64_t(painterly_lane_offset(p, row)) != expected_offset;
  mismatches += painterly_lanes_in_row(p, width, row) != int(spans.size());
  for (int lane = 0; lane < int(spans.size()); lane++) {
    int begin = -1;
    int end = -1;
    painterly_lane_span(p, width, row, lane, &begin, &end);
    mismatches += Span(begin, end) != spans[size_t(lane)];
    for (int col = spans[size_t(lane)].first; col < spans[size_t(lane)].second; col++) {
      mismatches += painterly_lane_in_row(p, row, col) != lane;
    }
  }
  // The lane after the last one is empty.
  int begin = -1;
  int end = -1;
  painterly_lane_span(p, width, row, int(spans.size()), &begin, &end);
  mismatches += begin < end;
  return mismatches;
}

// Renders the fixture on a pool of `threads` threads, in the given batches of passes.
PainterlyRenderBuffers render_scene(const Fixture &scene,
                                    const int threads,
                                    const Batches &batches)
{
  PainterlyThreadPool pool(threads);
  PainterlyRenderBuffers buffers;
  buffers.reset(Fixture::WIDTH, Fixture::HEIGHT);
  PainterlyPathTrace trace(scene.globals, buffers, pool);
  const std::atomic<bool> never_cancelled{false};
  for (const auto &[begin, end] : batches) {
    CHECK(trace.render_passes(begin, end, never_cancelled));
  }
  return buffers;
}

// The SPEC §3 lane chains rendered serially from the column walk, without PainterlyPathTrace:
// for each row, each lane, each pass, the lane's pixels left to right from its K0. Each pixel gets
// its passes in increasing order, as SPEC §7 requires.
PainterlyRenderBuffers serial_reference(const Fixture &scene)
{
  const KernelPainterlyIntegrator &p = scene.data.integrator;
  PainterlyRenderBuffers buffers;
  buffers.reset(Fixture::WIDTH, Fixture::HEIGHT);
  std::vector<PainterlyPathVertex> scratch(size_t(p.max_depth));
  for (int row = 0; row < Fixture::HEIGHT; row++) {
    const std::vector<Span> spans = walk_lanes(Fixture::WIDTH, p.lane_length, p.lane_stagger, row);
    for (int lane = 0; lane < int(spans.size()); lane++) {
      for (int pass = 0; pass < PASSES; pass++) {
        uint64_t K = painterly_chain_start(p, row, lane, pass);
        for (int col = spans[size_t(lane)].first; col < spans[size_t(lane)].second; col++) {
          const PainterlyPathResult r = painterly_trace_pixel(
              scene.kg(), row, col, pass, &K, scratch.data());
          const size_t pixel = size_t(row) * Fixture::WIDTH + size_t(col);
          painterly_film_accumulate(&buffers.combined[PAINTERLY_CHANNELS * pixel], r.radiance);
          buffers.k_consumed[pixel] += r.k_consumed;
        }
      }
    }
  }
  buffers.passes_done = PASSES;
  return buffers;
}

bool bit_identical(const PainterlyRenderBuffers &a, const PainterlyRenderBuffers &b)
{
  return a.combined.size() == b.combined.size() && a.k_consumed.size() == b.k_consumed.size() &&
         std::memcmp(a.combined.data(), b.combined.data(), a.combined.size() * sizeof(double)) ==
             0 &&
         std::memcmp(a.k_consumed.data(),
                     b.k_consumed.data(),
                     a.k_consumed.size() * sizeof(uint64_t)) == 0;
}

  for (const int width : GRID_WIDTHS) {
    for (const int lane_length : GRID_LANE_LENGTHS) {
      const KernelPainterlyIntegrator p0 = lane_knobs(lane_length, 0);
      for (int row = 0; row < GRID_ROWS; row++) {
        // SPEC v1: lane m is [m L, min(W, (m + 1) L)), and there are ceil(W / L) lanes.
        const int lanes = (width + lane_length - 1) / lane_length;
        mismatches += painterly_lanes_in_row(p0, width, row) != lanes;
        for (int lane = 0; lane < lanes; lane++) {

          int end = -1;
          painterly_lane_span(p0, width, row, lane, &begin, &end);
          const int v1_end = (lane + 1) * lane_length < width ? (lane + 1) * lane_length : width;
          mismatches += Span(begin, end) != Span(lane * lane_length, v1_end);
        }
        // S and S + L give the same lanes.
        for (const int stagger : GRID_STAGGERS) {
          if (stagger > INT_MAX - lane_length) {
            continue;
          }
          const KernelPainterlyIntegrator a = lane_knobs(lane_length, stagger);
          const KernelPainterlyIntegrator b = lane_knobs(lane_length, stagger + lane_length);
          mismatches += painterly_lanes_in_row(a, width, row) !=
                        painterly_lanes_in_row(b, width, row);
          for (int lane = 0; lane < painterly_lanes_in_row(a, width, row); lane++) {
            int ab = -1, ae = -1, bb = -1, be = -1;
            painterly_lane_span(a, width, row, lane, &ab, &ae);
            painterly_lane_span(b, width, row, lane, &bb, &be);
            mismatches += Span(ab, ae) != Span(bb, be);
          }
        }
      }
    }
  }

}

    const PainterlyRenderBuffers zero = render_scene(aligned, 1, {{0, PASSES}});

  }
}
```

```python
def module_sha256() -> str:
    """The sha256 of the imported ``_painterly`` module file."""
    digest = hashlib.sha256()
    with open(_painterly.__file__, "rb") as f:
        while chunk := f.read(HASH_CHUNK_BYTES):
            digest.update(chunk)
    return digest.hexdigest()

def render_key(job: Job, module_digest: str) -> str:
    """The first KEY_HEX_DIGITS hex digits of the sha256 of the canonical JSON of the job's options
    and seed, RENDERER_VERSION and the module's sha256. The job name is not part of the key."""
    canonical = {
        "options": dict(job.options),
        "seed": job.seed,
        "renderer_version": RENDERER_VERSION,
        "module_sha256": module_digest,
    }
    text = json.dumps(canonical, sort_keys=True, separators=(",", ":"))
    return hashlib.sha256(text.encode("utf-8")).hexdigest()[:KEY_HEX_DIGITS]

        raise FileNotFoundError(
            f"job {job.name!r} (seed {job.seed}) is not rendered: run render.py"

    passes = knobs.pop("passes")

    reference.build_smallpaint_scene(scene, size=size)
    scene.set_integrator(seed=job.seed, **knobs)
    session = _painterly.Session(scene, THREADS)
    start = time.monotonic()
    session.start(passes, passes)
    session.wait()
    wall_seconds = time.monotonic() - start
    progress = session.progress()
    if progress["state"] != "done":
        raise RuntimeError(f"{job.name} seed {job.seed}: {progress['state']}: {progress['error']}")
    directory = render_dir(job, module_digest)
    directory.mkdir(parents=True, exist_ok=True)
    np.save(directory / "sum.npy", session.combined())
    np.save(directory / "k_consumed.npy", session.k_consumed())
    np.save(directory / "object_id.npy", session.object_id())
    meta = {
        "passes": passes,
        "width": size,
        "height": size,
        "seed": job.seed,
        "options": dict(job.options),
        "renderer_version": RENDERER_VERSION,
        "module_sha256": module_digest,
        "threads": THREADS,
        "cpu_count": os.cpu_count(),
        "wall_seconds": wall_seconds,
    }
    (directory / "meta.json").write_text(json.dumps(meta, sort_keys=True, indent=1) + "\n")
    record = {"name": job.name, "seed": job.seed, "options": dict(job.options)}
    (directory / DONE).write_text(json.dumps(record, sort_keys=True) + "\n")
```

```python
"""Analysis of experiment NNN (T7.3): does lane_stagger remove the seam columns of chain=lane?

Implements the Common definitions and H1 to H4 of ``README.md``, which is the specification. It
re-runs from the native render cache of ``render.py``, so every render must exist. A smoke run
(``--smoke``) reads the smoke renders from ``$PAINTERLY_CACHE`` and writes to a scratch

Figures (no text is drawn; the layout is also in ``results.json`` under ``figures``):
- ``fig_crops.png``: a CROP_SIZE square of the display image of pair 0 of each configuration, in

  the most pixels of the eroded back wall (ties: smallest row, then column).
- ``fig_profiles.png``: one row per configuration in ``jobs.DESIGN`` order; per measured region
  two bar panels, the column-class profile then the chain-class profile, means over pairs. Bar k
  is BAR_WIDTH px wide (the last column black) with height round(PANEL_HEIGHT / 2 * A(k) /
  median A), clipped to PANEL_HEIGHT; the seam class is red, the others grey, and a white line

import argparse

import importlib.util

from collections.abc import Callable, Mapping, Sequence

import numpy as np
from painterly_analysis import ensemble, io, metrics, report

EXP_DIR = Path(__file__).resolve().parent
REPO_ROOT = EXP_DIR.parents[1]

# SPEC §9 ids of the planes in view: floor, back, left, right, ceiling. The front plane (8) is
# behind the camera, and the spheres are too small for 16 classes of a 4-px-eroded mask.
REGIONS = (3, 4, 5, 6, 7)

# edge (metrics.measure derives the same value).
EROSION_RADIUS = metrics.HIGHPASS_SIZE // 2
# The class of the lane starts: column j = m * L when S = 0, chain position 0 for every S.
SEAM_CLASS = 0
# The family-wise level of every hypothesis (README). Not the knob alpha.
SIGNIFICANCE = 0.01
ROW = "row"
ALIGNED = "lane16_s0"
# px: the staggers of the design (README, Method), and those with gcd(S mod L, L) = 1 (H2).
STAGGERS = (1, 5, 8)
H2_STAGGERS = (1, 5)
# The bootstrap of the residual fraction (README, H2). The resample count sets only the Monte
# Carlo precision of the interval.
BOOTSTRAP_RESAMPLES = 10_000
BOOTSTRAP_SEED = 0
BOOTSTRAP_PERCENTILES = (2.5, 97.5)  # a 95% percentile interval
# Figures only: eight 16-px lanes per crop, three crops per row; profile bars 8 px wide in panels
# 128 px high, so the median sits at 64 px; 8-bit sRGB colours of the bars and the median line.
CROP_SIZE = 128

BAR_WIDTH = 8
PANEL_HEIGHT = 128

def _load_file(name: str, path: Path) -> ModuleType:
    spec = importlib.util.spec_from_file_location(name, path)
    if spec is None or spec.loader is None:
        raise RuntimeError(f"cannot load {path}")

def staggered(stagger: int) -> str:
    return f"lane16_s{stagger}"


def stagger_gcd(knobs: Mapping[str, object], lane_length: int) -> int:
    """g = gcd(S mod L, L); g = L when S mod L = 0 (SPEC §3, lane grid)."""
    return math.gcd(int(knobs["lane_stagger"]) % lane_length, lane_length)


def seam_lattice(stagger: int, lane_length: int) -> dict[str, Any]:
    """The shortest nonzero vector (d_row, d_col) between two seams, in px.

    Seams are the pixels (row, j) with (j + row * S) mod L == 0 (SPEC §3), a lattice whose vectors
    satisfy (d_col + d_row * S) mod L == 0. Ties go to the smaller (d_row, d_col).
    """
    best = None
    for d_row in range(lane_length + 1):
        for d_col in range(-lane_length, lane_length + 1):
            if (d_row, d_col) == (0, 0) or (d_col + d_row * stagger) % lane_length != 0:
                continue
            key = (d_row * d_row + d_col * d_col, d_row, d_col)
            if best is None or key < best:
                best = key
    return {"d_row": best[1], "d_col": best[2], "length_px": math.sqrt(best[0])}


def chain_position(height: int, width: int, knobs: Mapping[str, object]) -> np.ndarray:
    """(H, W) int64: the column minus the first column of its lane (SPEC §3, lane grid).

    ``row`` is one lane per row, so the position is the column.
    """
    cols = np.arange(width, dtype=np.int64)[None, :]
    if knobs["chain"] == "row":
        return np.broadcast_to(cols, (height, width)).copy()
    lane_length = int(knobs["lane_length"])
    rows = np.arange(height, dtype=np.int64)[:, None]
    offset = (rows * int(knobs["lane_stagger"])) % lane_length
    lane = (cols + offset) // lane_length
    return cols - np.maximum(0, lane * lane_length - offset)


def class_maps(
    height: int, width: int, knobs: Mapping[str, object], lane_length: int
) -> dict[str, np.ndarray]:
    """The column class q = col mod L and the chain class k = chain position mod L."""
    cols = np.arange(width, dtype=np.int64)[None, :] % lane_length
    return {
        "col": np.broadcast_to(cols, (height, width)).copy(),
        "chain": chain_position(height, width, knobs) % lane_length,
    }


def profile(hp_a, hp_b, mask: np.ndarray, classes: np.ndarray, lane_length: int) -> np.ndarray:
    """structure_std of each class over the mask, in display bytes."""
    return np.array(
        [
            float(metrics.structure_std(hp_a, hp_b, mask & (classes == k)))
            for k in range(lane_length)
        ]
    )


def excess(amplitudes: np.ndarray) -> float:
    """A(SEAM_CLASS) / median A - 1. Dimensionless."""
    return float(amplitudes[SEAM_CLASS] / np.median(amplitudes) - 1.0)


def mixed_excess(chain_profile: np.ndarray, g: int) -> float:
    """The de-alignment prediction of E_col for a stagger of gcd g (README, H3).

    Column class q pools the chain classes (q + j g) mod L, j = 0 .. L/g - 1, from equal shares
    of rows, so its structure variance is their mean.
    """
    lane_length = chain_profile.size
    variance = chain_profile**2
    mixed = np.array(
        [
            np.mean([variance[(q + j * g) % lane_length] for j in range(lane_length // g)])
            for q in range(lane_length)
        ]
    )
    return excess(np.sqrt(mixed))


def residual_fraction(
    e_s: Sequence[float], e_0: Sequence[float], e_row: Sequence[float], rng: np.random.Generator
) -> dict[str, Any]:
    """rho = (mean e_s - mean e_row) / (mean e_0 - mean e_row) and its percentile interval.

    Pairs are resampled with replacement within each of the three configurations, in the order
    e_s, e_0, e_row. The interval is None when a resample has a zero denominator.
    """
    xs = [np.asarray(x, dtype=np.float64) for x in (e_s, e_0, e_row)]
    point = (xs[0].mean() - xs[2].mean()) / (xs[1].mean() - xs[2].mean())
    idx = [rng.integers(0, x.size, size=(BOOTSTRAP_RESAMPLES, x.size)) for x in xs]
    numerator = xs[0][idx[0]].mean(axis=1) - xs[2][idx[2]].mean(axis=1)
    denominator = xs[1][idx[1]].mean(axis=1) - xs[2][idx[2]].mean(axis=1)
    if np.any(denominator == 0.0):
        return {"rho": float(point), "interval": None}
    lo, hi = np.percentile(numerator / denominator, BOOTSTRAP_PERCENTILES)
    return {"rho": float(point), "interval": [float(lo), float(hi)]}


def pair_values(
    sum_a: np.ndarray,
    sum_b: np.ndarray,
    passes: int,
    masks: Mapping[int, np.ndarray],
    classes: Mapping[str, np.ndarray],
    lane_length: int,
) -> tuple[dict[str, float], dict[int, dict[str, np.ndarray]], np.ndarray]:
    """The per-pair keys, the class profiles and the display image ab8 of one pair."""
    hp_a = metrics.highpass(metrics.luminance(io.smallpaint_display(sum_a, passes)))
    hp_b = metrics.highpass(metrics.luminance(io.smallpaint_display(sum_b, passes)))
    ab8 = io.smallpaint_display(np.asarray(sum_a) + np.asarray(sum_b), 2 * passes)
    values: dict[str, float] = {}
    profiles: dict[int, dict[str, np.ndarray]] = {}
    for region, mask in masks.items():
        p_col = profile(hp_a, hp_b, mask, classes["col"], lane_length)
        p_chain = profile(hp_a, hp_b, mask, classes["chain"], lane_length)
        profiles[region] = {"col": p_col, "chain": p_chain}
        values[f"r{region}.E_col"] = excess(p_col)
        values[f"r{region}.E_chain"] = excess(p_chain)
        values[f"r{region}.structure_std"] = float(metrics.structure_std(hp_a, hp_b, mask))
        values[f"r{region}.slag1.x"] = float(
            metrics.noise_corrected_lag(hp_a, hp_b, mask, axis=1, lag=1)
        )
        values[f"r{region}.slag1.y"] = float(
            metrics.noise_corrected_lag(hp_a, hp_b, mask, axis=0, lag=1)
        )
        mean = metrics.region_mean_rgb(ab8, mask)
        for channel, name in enumerate("RGB"):
            values[f"r{region}.mean.{name}"] = float(mean[channel])
    return values, profiles, ab8


def family(
    runs: Mapping[str, list[dict[str, float]]],
    tests: Mapping[str, tuple[str, str, str]],
    alpha: float,
    smoke: bool,
) -> dict[str, Any]:
    """Two-sided exact permutation tests of {label: (config_a, config_b, key)}, Holm at alpha.

    Raises ValueError when the family is underpowered, except in a smoke run.
    """
    if not tests:
        return {"tests": {}, "alpha": alpha, "powered": False, "min_attainable_p": None}
    pvalues: dict[str, float] = {}
    out: dict[str, dict[str, Any]] = {}
    for label, (a, b, key) in tests.items():
        xs = [run[key] for run in runs[a]]
        ys = [run[key] for run in runs[b]]
        pvalues[label] = ensemble.permutation_pvalue(xs, ys, "two-sided")
        out[label] = {"a": a, "b": b, "key": key, "p": pvalues[label]}
        out[label].update(ensemble.effect_summary(runs[a], runs[b], [key])[key])
    a, b, _ = next(iter(tests.values()))
    min_p = ensemble.min_attainable_pvalue(len(runs[a]), len(runs[b]), "two-sided")
    threshold = alpha / len(tests)
    powered = min_p <= threshold
    if not powered and not smoke:
        raise ValueError(
            f"{len(tests)} tests at alpha={alpha}: smallest attainable p {min_p:.3g} exceeds the "
            f"first Holm threshold {threshold:.3g}"
        )
    rejected = ensemble.holm(pvalues, alpha)
    for label in out:
        out[label]["rejected"] = rejected[label]
    return {
        "tests": out,
        "alpha": alpha,
        "powered": powered,
        "min_attainable_p": min_p,
        "first_threshold": threshold,
    }


def _rejected(result: Mapping[str, Any]) -> list[str]:
    return [label for label, test in result["tests"].items() if test["rejected"]]


def _region(label: str) -> int:
    """The region id of a test label "r{id}" or "s{S}.r{id}"."""
    return int(label.rsplit(".r", 1)[-1].removeprefix("r"))


def check_design(jobs: ModuleType, ensembles: Mapping[str, list], smoke: bool) -> None:
    """The configurations, knobs, blocks and seeds of README, Method; in a full run also the sizes
    and the global seed rule (report.check_seed_reuse)."""
    lane_length = jobs.LANE_LENGTH
    expected = {ROW: {"chain": "row"}}
    for stagger in (0, *STAGGERS):
        expected[staggered(stagger)] = {
            "chain": "lane",
            "lane_length": lane_length,
            "lane_stagger": stagger,
        }
    if list(jobs.DESIGN) != list(expected) or dict(jobs.DESIGN) != expected:
        raise RuntimeError(f"jobs.DESIGN differs from the README: {jobs.DESIGN}")
    if list(ensembles) != list(expected):
        raise RuntimeError(f"ensembles {list(ensembles)} differ from {list(expected)}")
    sizes = {dict(job.options)["size"] for jobs_ in ensembles.values() for job in jobs_}
    for index, (name, ensemble_jobs) in enumerate(ensembles.items()):
        base = jobs.BLOCK * (jobs.FIRST_BLOCK + index)
        if [job.seed for job in ensemble_jobs] != list(range(base, base + len(ensemble_jobs))):
            raise RuntimeError(f"{name}: seeds differ from block {jobs.FIRST_BLOCK + index}")
        for job in ensemble_jobs:
            options = dict(job.options)
            knobs = {k: v for k, v in options.items() if k not in ("size", "passes")}
            if knobs != expected[name]:
                raise RuntimeError(f"{name} seed {job.seed}: knobs {knobs}")
    if smoke:
        return
    if sizes != {jobs.SIZE} or any(len(e) != 2 * jobs.PAIRS for e in ensembles.values()):
        raise RuntimeError("a full run needs jobs.SIZE and jobs.PAIRS in every configuration")
    earlier = {
        path.parent.name.split("-")[0]: path
        for path in sorted((REPO_ROOT / "experiments").glob("*/jobs.py"))
        if path.parent.resolve() != EXP_DIR
    }
    report.check_seed_reuse(ensembles, earlier, {})


def check_renders(ensembles: Mapping[str, list], renders: Mapping[str, list]) -> dict[str, Any]:
    """Equal object ids everywhere, the jobs' passes, and distinct replicates in every
    configuration (independent replicates, experiment 006)."""
    first = next(iter(renders.values()))[0].object_id
    distinct: dict[str, int] = {}
    wall: list[float] = []
    for name, rendered in renders.items():
        for job, render in zip(ensembles[name], rendered, strict=True):
            if render.passes != dict(job.options)["passes"]:
                raise RuntimeError(f"{name} seed {job.seed}: passes {render.passes}")
            if not np.array_equal(render.object_id, first):
                raise RuntimeError(f"{name} seed {job.seed}: object id differs")
            wall.append(float(render.meta.get("wall_seconds", 0.0)))
        digests = {hashlib.sha256(r.sum.tobytes()).hexdigest() for r in rendered}
        distinct[name] = len(digests)
        if len(digests) != len(rendered):
            raise RuntimeError(f"{name}: {len(digests)} distinct renders of {len(rendered)}")
    return {
        "count": sum(len(r) for r in renders.values()),
        "distinct": distinct,
        "wall_seconds_total": float(np.sum(wall)),
        "wall_seconds_median": float(np.median(wall)),
    }


def measured_regions(
    masks: Mapping[int, np.ndarray], classes: Mapping[str, Mapping[str, np.ndarray]], lanes: int
) -> tuple[list[int], list[int]]:
    """Regions whose every class of both partitions is non-empty in every configuration."""
    measured, excluded = [], []
    for region in REGIONS:
        mask = masks.get(region)
        ok = mask is not None and bool(mask.any())
        if ok:
            for maps in classes.values():
                for cls in maps.values():
                    ok = ok and all(bool((mask & (cls == k)).any()) for k in range(lanes))
        (measured if ok else excluded).append(region)
    return measured, excluded


def crop_window(mask: np.ndarray) -> tuple[int, int, int]:
    """(row0, col0, side) of the side x side square holding the most mask pixels, side =
    min(CROP_SIZE, image side). Ties go to the smallest row0, then col0 (np.argmax order)."""
    side = min(CROP_SIZE, *mask.shape)
    table = np.zeros((mask.shape[0] + 1, mask.shape[1] + 1), dtype=np.int64)
    table[1:, 1:] = mask.astype(np.int64).cumsum(axis=0).cumsum(axis=1)
    counts = (
        table[side:, side:] - table[:-side, side:] - table[side:, :-side] + table[:-side, :-side]
    )
    row0, col0 = np.unravel_index(int(np.argmax(counts)), counts.shape)
    return int(row0), int(col0), side


def bar_panel(amplitudes: Sequence[float]) -> np.ndarray:
    """One profile as bars (module docstring)."""
    panel = np.zeros((PANEL_HEIGHT, len(amplitudes) * BAR_WIDTH, 3), dtype=np.uint8)
    median = float(np.median(amplitudes))
    for k, amplitude in enumerate(amplitudes):
        height = min(PANEL_HEIGHT, int(round(PANEL_HEIGHT / 2 * amplitude / median)))
        colour = SEAM_RGB if k == SEAM_CLASS else BAR_RGB
        panel[PANEL_HEIGHT - height :, k * BAR_WIDTH : (k + 1) * BAR_WIDTH - 1] = colour
    panel[PANEL_HEIGHT // 2, :] = MEDIAN_RGB
    return panel


def run(render: ModuleType, smoke: bool, out_dir: Path, say: Callable[[str], None]) -> dict:
    jobs = render.jobs_module
    lane_length = jobs.LANE_LENGTH
    ensembles = render.experiment_ensembles(smoke)
    check_design(jobs, ensembles, smoke)
    digest = render.module_sha256()
    renders = {name: [render.load(job, digest) for job in e] for name, e in ensembles.items()}
    bookkeeping = check_renders(ensembles, renders)
    object_id = renders[ROW][0].object_id
    height, width = object_id.shape
    all_masks = {
        int(r): np.asarray(m) for r, m in metrics.region_masks(object_id, EROSION_RADIUS).items()
    }
    classes = {
        name: class_maps(height, width, jobs.DESIGN[name], lane_length) for name in ensembles
    }
    measured, excluded = measured_regions(all_masks, classes, lane_length)
    if not measured:
        raise RuntimeError(f"no region of {REGIONS} has every class in every configuration")
    masks = {r: all_masks[r] for r in measured}

    runs: dict[str, list[dict[str, float]]] = {}
    profiles: dict[str, list[dict[int, dict[str, np.ndarray]]]] = {}
    previews: dict[str, np.ndarray] = {}
    for name, rendered in renders.items():
        runs[name], profiles[name] = [], []
        for a, b in zip(rendered[0::2], rendered[1::2], strict=True):
            values, prof, ab8 = pair_values(
                a.sum, b.sum, a.passes, masks, classes[name], lane_length
            )
            runs[name].append(values)
            profiles[name].append(prof)
            previews.setdefault(name, ab8)

    def e_values(name: str, region: int, kind: str) -> list[float]:
        return [run_[f"r{region}.E_{kind}"] for run_ in runs[name]]

    h1 = family(
        runs, {f"r{r}": (ALIGNED, ROW, f"r{r}.E_col") for r in measured}, SIGNIFICANCE, smoke
    )
    seam_regions = [int(label[1:]) for label in _rejected(h1)]
    h2a = family(
        runs,
        {
            f"s{s}.r{r}": (staggered(s), ALIGNED, f"r{r}.E_col")
            for s in H2_STAGGERS
            for r in seam_regions
        },
        SIGNIFICANCE,
        smoke,
    )
    h2b = family(
        runs,
        {f"s{s}.r{r}": (staggered(s), ROW, f"r{r}.E_col") for s in H2_STAGGERS for r in measured},
        SIGNIFICANCE,
        smoke,
    )
    h3 = family(
        runs,
        {
            f"s{s}.r{r}": (staggered(s), ALIGNED, f"r{r}.E_chain")
            for s in STAGGERS
            for r in seam_regions
        },
        SIGNIFICANCE,
        smoke,
    )
    texture = [f"r{r}.{k}" for r in measured for k in ("structure_std", "slag1.x", "slag1.y")]
    h4 = {
        staggered(s): family(
            runs,
            {key: (staggered(s), ALIGNED, key) for key in texture},
            SIGNIFICANCE / len(STAGGERS),
            smoke,
        )
        for s in STAGGERS
    }
    h4_control = family(runs, {key: (ALIGNED, ROW, key) for key in texture}, SIGNIFICANCE, smoke)

    rng = np.random.default_rng(BOOTSTRAP_SEED)
    rho = {
        f"s{s}.r{r}": residual_fraction(
            e_values(staggered(s), r, "col"),
            e_values(ALIGNED, r, "col"),
            e_values(ROW, r, "col"),
            rng,
        )
        for r in seam_regions
        for s in STAGGERS
    }
    prediction: dict[str, dict[str, Any]] = {}
    for s in STAGGERS:
        g = stagger_gcd(jobs.DESIGN[staggered(s)], lane_length)
        for r in measured:
            predicted = [mixed_excess(p[r]["chain"], g) for p in profiles[ALIGNED]]
            entry = {
                "g": g,
                "e_pred_mean": float(np.mean(predicted)),
                "e_pred_sd": float(np.std(predicted, ddof=1)),
                "e_col_mean": float(np.mean(e_values(staggered(s), r, "col"))),
            }
            if r in seam_regions:
                m_row = float(np.mean(e_values(ROW, r, "col")))
                m_0 = float(np.mean(e_values(ALIGNED, r, "col")))
                entry["rho_pred"] = (entry["e_pred_mean"] - m_row) / (m_0 - m_row)
            prediction[f"s{s}.r{r}"] = entry

    decisions = decide(h1, h2a, h2b, h3, h4, h4_control, seam_regions, smoke)
    lattice = {
        name: None
        if name == ROW
        else {
            "g": stagger_gcd(jobs.DESIGN[name], lane_length),
            **seam_lattice(int(jobs.DESIGN[name]["lane_stagger"]), lane_length),
        }
        for name in ensembles
    }
    summary = {
        name: {
            key: {"mean": float(np.mean(vals)), "sd": float(np.std(vals, ddof=1))}
            for key in runs[name][0]
            for vals in [[run_[key] for run_ in runs[name]]]
        }
        for name in runs
    }
    profile_summary = {
        name: {
            f"r{r}": {
                kind: [float(v) for v in np.mean([p[r][kind] for p in profiles[name]], axis=0)]
                for kind in ("col", "chain")
            }
            for r in measured
        }
        for name in profiles
    }
    figures = write_figures(
        out_dir, previews, profile_summary, all_masks[BACK_WALL], list(ensembles), measured
    )
    results = {
        "smoke": smoke,
        "design": {
            name: {
                "knobs": jobs.DESIGN[name],
                "block": jobs.FIRST_BLOCK + index,
                "seeds": [e[0].seed, e[-1].seed],
                "size": dict(e[0].options)["size"],
                "passes": dict(e[0].options)["passes"],
                "pairs": len(e) // 2,
                "seam_lattice": lattice[name],
            }
            for index, (name, e) in enumerate(ensembles.items())
        },
        "module_sha256": digest,
        "renders": bookkeeping,
        "regions": {"measured": measured, "excluded": excluded, "seam_regions": seam_regions},
        "summary": summary,
        "profiles": profile_summary,
        "h1": h1,
        "h2a": h2a,
        "h2b": h2b,
        "h3": h3,
        "h4": h4,
        "h4_control": h4_control,
        "rho": rho,
        "prediction": prediction,
        "decisions": decisions,
        "figures": figures,
    }
    report.write_results_json(out_dir / "results.json", results)
    print_tables(results, say)
    return results


def write_figures(
    out_dir: Path,
    previews: Mapping[str, np.ndarray],
    profile_summary: Mapping[str, Mapping[str, Mapping[str, list[float]]]],
    back_wall: np.ndarray,
    order: Sequence[str],
    measured: Sequence[int],
) -> dict[str, Any]:
    """fig_crops.png and fig_profiles.png (module docstring)."""
    row0, col0, side = crop_window(back_wall)
    window = (slice(row0, row0 + side), slice(col0, col0 + side))
    io.write_png(
        out_dir / "fig_crops.png",
        report.mosaic([previews[n][window] for n in order], FIGURE_COLUMNS),
    )
    panels = [
        bar_panel(profile_summary[name][f"r{r}"][kind])
        for name in order
        for r in measured
        for kind in ("col", "chain")
    ]
    io.write_png(out_dir / "fig_profiles.png", report.mosaic(panels, 2 * len(measured)))
    return {
        "fig_crops.png": {
            "order": list(order),
            "columns": FIGURE_COLUMNS,
            "crop": [row0, col0, side],
            "content": "display bytes of pair 0 (both halves summed)",
        },
        "fig_profiles.png": {
            "rows": list(order),
            "columns": [f"r{r}.{kind}" for r in measured for kind in ("col", "chain")],
            "content": "class profiles A(k), means over pairs; bar height 64 px * A(k) / median",
        },
    }


def _fmt(x: float | None, spec: str = ".4g") -> str:
    return "None" if x is None else format(x, spec)


def print_tables(results: Mapping[str, Any], say: Callable[[str], None]) -> None:
    """The README Results tables, from results.json."""
    measured = results["regions"]["measured"]
    say(f"regions measured {measured}, excluded {results['regions']['excluded']}")
    say(f"seam regions (H1 rejected) {results['regions']['seam_regions']}")
    say("Table 1. E_col and E_chain, mean +- sd over pairs")
    for name, keys in results["summary"].items():
        cells = []
        for r in measured:
            for kind in ("col", "chain"):
                v = keys[f"r{r}.E_{kind}"]
                cells.append(f"r{r}.{kind} {v['mean']:+.3f}+-{v['sd']:.3f}")
        say(f"  {name}: " + "; ".join(cells))
    for title in ("h1", "h2a", "h2b", "h3"):
        fam = results[title]
        say(
            f"{title.upper()}: alpha {fam['alpha']}, powered {fam['powered']}, "
            f"min_attainable_p {_fmt(fam['min_attainable_p'])}"
        )
        for label, test in fam["tests"].items():
            say(
                f"  {label}: {test['a']} vs {test['b']} {test['key']}: "
                f"{test['mean_a']:+.4f} vs {test['mean_b']:+.4f}, diff {test['diff']:+.4f}, "
                f"d {_fmt(test['cohen_d'])}, p {test['p']:.4g}, rejected {test['rejected']}"
            )
    for label, entry in results["rho"].items():
        interval = entry["interval"]
        text = "None" if interval is None else f"[{interval[0]:.4f}, {interval[1]:.4f}]"
        pred = results["prediction"][label]
        say(
            f"rho {label}: {entry['rho']:.4f} {text}; prediction rho {_fmt(pred.get('rho_pred'))}, "
            f"E_pred {pred['e_pred_mean']:+.4f}+-{pred['e_pred_sd']:.4f}, "
            f"E_col {pred['e_col_mean']:+.4f}"
        )
    for name, fam in [*results["h4"].items(), ("control lane16_s0 vs row", results["h4_control"])]:
        effects = {t["key"]: t for t in fam["tests"].values()}
        rel = report.largest_abs_rel_diff(effects)
        d = report.largest_abs_cohen_d(effects)
        say(
            f"H4 {name}: rejected {len(_rejected(fam))} of {len(fam['tests'])} "
            f"{_rejected(fam)}; min p {_fmt(min(t['p'] for t in fam['tests'].values()))}; "
            f"largest |rel| {report.format_largest(rel)}; largest |d| {report.format_largest(d)}"
        )
    for name, entry in results["design"].items():
        lattice = entry["seam_lattice"]
        say(f"design {name}: block {entry['block']} seeds {entry['seeds']} lattice {lattice}")
    say(f"renders {results['renders']}")
    say(f"decisions {results['decisions']}")


def decide(h1, h2a, h2b, h3, h4, h4_control, seam_regions, smoke) -> dict[str, str]:
    """The decision rules of README, Hypothesis, applied literally."""
    if smoke:
        return {h: "inconclusive (smoke)" for h in ("H1", "H2", "H3", "H4")}
    out: dict[str, str] = {}
    key = f"r{BACK_WALL}"
    if key not in h1["tests"]:
        out["H1"] = "inconclusive"
    else:
        test = h1["tests"][key]
        out["H1"] = "supported" if test["rejected"] and test["diff"] > 0.0 else "refuted"
    if not seam_regions:
        out["H2"] = "inconclusive"
    else:
        # Every seam region rejects, and the stagger moves E_col from lane16_s0 toward row.
        removal = all(
            test["rejected"]
            and math.copysign(1.0, test["diff"])
            == -math.copysign(1.0, h1["tests"][f"r{_region(label)}"]["diff"])
            for label, test in h2a["tests"].items()
        )
        floor = not _rejected(h2b)
        if not removal:
            out["H2"] = "refuted"
        elif floor:
            out["H2"] = "supported"
        else:
            out["H2"] = "reduced, residual seam column"
    if not seam_regions:
        out["H3"] = "inconclusive"
    else:
        out["H3"] = "refuted" if _rejected(h3) else "supported"
    if not _rejected(h4_control):
        out["H4"] = "inconclusive"
    else:
        out["H4"] = "refuted" if any(_rejected(r) for r in h4.values()) else "supported"
    return out


def main(argv: list[str] | None = None) -> int:
    parser = argparse.ArgumentParser(description=__doc__.splitlines()[0])
    parser.add_argument("--smoke", action="store_true", help="analyse the smoke renders")
    parser.add_argument("--out-dir", type=Path, default=EXP_DIR, help="where results go")
    args = parser.parse_args(argv)
    out_dir = args.out_dir.resolve()
    if args.smoke and out_dir == EXP_DIR:
        parser.error("--smoke needs a scratch --out-dir")
    out_dir.mkdir(parents=True, exist_ok=True)
    render = _load_file("lane_stagger_render", EXP_DIR / "render.py")

    def say(line: str) -> None:
        print((SMOKE_PREFIX if args.smoke else "") + line)

    run(render, args.smoke, out_dir, say)
    return 0


if __name__ == "__main__":
    raise SystemExit(main())
```
