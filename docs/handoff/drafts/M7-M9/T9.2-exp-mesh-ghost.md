# T9.2 — Experiment NNN: the four mesh-ghost candidates against analytic ghost spheres on UV-sphere meshes
Milestone: M9 · Depends on: T9.1, T4.3 (run after M3, M4 and M5 have landed) · Parallel-safe: no

## Goal
After this card, experiment NNN (number assigned when it runs) exists in `experiments/NNN-DATE-mesh-ghost/`:
pre-registered, rendered with the native core through `_painterly.Session`, analysed and drafted. It scores T9.1's four
`mesh_ghost` candidates (`bounding_sphere`, `homothety`, `angular_dilation`, `sdf_step`) on SPEC §9's reference scene with
its three non-emissive spheres as UV-sphere meshes. The analytic-ghost ensemble is the reference, the mesh without
ghosting is the negative control, and a pre-registered, effect-size-based rule says which candidate, if any, becomes an
artist option. Nothing outside the experiment directory and one row of `experiments/README.md` changes: no socket, no
default, no SPEC text, no UI.

## Opus decisions (fixed for this card)
1. **Native core.** The oracle has no triangle meshes and no `mesh_ghost`, and stays a minimal diff of smallpaint. Renders
   come from the experiment's own `render.py`, as in T3.18 and T7.3; `jobs.py` declares `JOBS` for the global seed rule
   only.
2. **One source for the scene.** Every configuration is built by the add-on's bpy-free `sync/reference.py`
   `build_smallpaint_scene` (T4.3; SPEC §9 geometry, materials, order, object ids and `apply_reference_knobs()`). The mesh
   configurations pass it a wrapper, `mesh_spheres.MeshSphereScene`, that adds every sphere with zero emission (SPEC §9 ids
   0, 1, 2) as a UV-sphere mesh with the same centre, radius, material and object id. The six planes stay analytic in every
   configuration, and so does the light (id 9), as a Blender point light is (SPEC §5). Only the three spheres change.
3. **The mesh.** Blender's default UV sphere, 32 segments × 16 rings (`bpy.ops.mesh.primitive_uv_sphere_add` defaults),
   960 triangles, smooth: object-space vertices `r·u` (float32), corner normals `u` (the analytic normal at each vertex),
   object-to-world a translation by the centre. Not T5.4's 64 × 32: `angular_dilation` costs O(triangles) per ray (T9.1),
   and the pilot (pre-registration, Background) measured 1299 µs per path at 960 triangles per sphere.
4. **`two_sided = False` in every configuration.** Analytic primitives keep smallpaint's normals (SPEC §6), so the mesh
   spheres then shade with the analytic spheres' normal semantics, as T3.17 does for its quads. It has no effect on the
   analytic configurations. Blender's default (`true`) is not tested here.
5. **Size and sample counts.** 200 px, 16 passes per half render, 9 pairs per configuration, `chain` at its socket default
   `row` (003: row ≡ image, 0 of 46 keys). The pilot cost of `angular_dilation` makes 400 px × 64 passes about 17 h for
   its 18 renders (55 minutes each on 4 threads); 200 × 16 is 1/16 of that. Nine pairs, not eight, make the
   per-candidate comparisons powered (Hypothesis, Power). Every comparison is between configurations of the same size, so
   006's 200-px departure is common to all of them.
6. **Default.** `mesh_ghost` stays `off` in every outcome (SPEC §8: defaults are the reference behaviour; 002 Decision 1:
   lights-only ghosting is the Blender look). The experiment decides exposure; a later Opus card exposes.
7. **No pytest tests.** As in T3.18 and T7.3, the scripts' design and render checks, the smoke run and the determinism
   check (two analyses, one `sha256sum`) are the tests.

    footprint seen from o dilated by `acos(1/L)`) for `dot(d, d) ≥ 1`, and the triangle itself for `dot(d, d) < 1`;
  - `sdf_step` sphere-traces the object's unsigned distance with steps `t ← t + f` and never dilates.

# Experiment NNN: which mesh-ghost candidate reproduces analytic ghost spheres on UV-sphere meshes?

## Background

- `docs/plan.md`, "What makes the look", item 2: ghost spheres are the dominant light source. smallpaint's sphere test
  assumes |d| = 1, so with |d| = L it hits the ghost sphere centred at `o + L²(c − o)` with radius
  `L·sqrt((L² − 1)|o − c|² + r²)` (SPEC §5), whose cone from the ray origin grows to `acos(1/L)` as r → 0. "Triangles and
  planes are unaffected by |d|." The owner decided that in Blender only point and spot lights are ghosts and that mesh
  ghosting is a research experiment: X-mesh-ghost, "candidate generalizations of ghosting to triangles (bounding-sphere
  proxy, L²-homothety about the ray origin, angular dilation by acos(1/L), unnormalized SDF stepping), scored against
  analytic ghosts on sphere meshes" (M9). Its conclusion feeds a go/no-go on exposing painterly spheres and mesh ghosting.
  This is that experiment.
- `experiments/002-2026-10-08-ingredient-ablation/` (final), H5 and Decision 1: lights-only ghosting (`--ghost lights`,
  the analytic counterpart of a Blender scene) is a distinct look, not a degraded copy. Against every sphere ghosted
  (400 px, P = 64, image chain): floor `r3.mean.G` 166.02 vs 84.84 (+95.7%), back wall `r4.mean.G` 198.11 vs 148.68
  (+33.2%), ceiling `r7.mean.G` 77.68 vs 106.76 (−27.2%), `r4.structure_std` 5.38 vs 5.74, K 19.21 vs 16.27 draws per pixel
  per pass, and the realization lost (pattern correlation 0.005). On the 26 diffuse keys of the realization-free family
  used here, 24 have |d| ≥ 3.1; the two others are `r2.structure_std` (d 2.0) and `r5.structure_std` (d 0.73).
- T9.1 adds the knob `mesh_ghost` (default `off`) with the four candidates, defined in the header comment of
  `src/painterly/kernel/geom/mesh_ghost.h`:
  - `bounding_sphere`: each mesh object becomes, for every ray, a SPEC §5 ghost sphere of its world bounding sphere
    (centre the midpoint of the vertices' bounding box, radius the largest distance from it to a vertex);
  - `homothety`: the true triangle hit, moved to `t = dot(d, d) · t_true`, i.e. `P = o + L²(P_true − o)`;
  - `angular_dilation`: every point of a triangle is an r = 0 ghost sphere; the triangle is hit where the ray enters their
    union (for L ≥ 1), and as itself for L < 1;
  - `sdf_step`: sphere tracing of the object's unsigned distance with steps `t ← t + f`, which assume |d| = 1.
- Pilot (card T9.2; exploratory, not evidence). T9.1's prototype kernel before its card ran, SPEC §9 with spheres 0-2 as
  the 32 × 16 UV-sphere meshes of this experiment, `two_sided` off, the light analytic; 64 px, 4 passes, image chain,
  seed 0, one thread. Mean radiance per sample over the image (display-byte units, before SPEC §7's truncation and clip),
  and `f` on the red channel, `f = (m_X − m_ghost) / (m_off − m_ghost)` (Hypothesis, Common definitions):

  | configuration | µs per path | mean R, G, B | K per path | f (mean R) |
  |---|---:|---|---:|---:|
  | analytic_ghost | 2.16 | 99.11, 100.35, 71.50 | 16.213 | 0 |
  | analytic_exact | 1.94 | 125.93, 124.58, 89.22 | 19.127 | 0.988 |
  | mesh_off | 2.38 | 126.27, 124.51, 90.29 | 19.179 | 1 |
  | mesh_bounding_sphere | 1.96 | 99.11, 100.35, 71.50 | 16.213 | 0.000 |
  | mesh_homothety | 2.47 | 131.17, 128.44, 92.01 | 19.188 | +1.180 |
  | mesh_angular_dilation | 1299 | 78.39, 78.69, 53.08 | 15.440 | −0.763 |
  | mesh_sdf_step | 158 | 130.24, 130.03, 93.04 | 19.245 | +1.146 |

  - On this key the meshing alone (`mesh_off` against `analytic_exact`) is |126.27 − 125.93| / 27.16 = 0.0125 of the
    ghost gap.
  - Cost: `angular_dilation` is 546 times `mesh_off` per path, `sdf_step` 66 times. At 400 px × 64 passes one
    `angular_dilation` render would take about 55 minutes on 4 threads; at 200 px × 16 passes about 3.5 minutes. This sets
    the size and passes below.
- Why the native core: the oracle has no triangle meshes. Why the add-on's reference builder: it is the single source of
  the SPEC §9 scene (T4.3), so the mesh configurations differ from the analytic ones in the three spheres only.
- Experiment 006 (final), "Analysis practice", applied here:
  - (a) independent replicates: every configuration has its own seeds, disjoint from every earlier experiment's (checked
    with `report.check_seed_reuse`), and 18 distinct renders (checked); the reference has an independent replicate
    configuration;
  - (b) separating contrasts: `analytic_exact` against `mesh_off` separates what meshing alone does from what ghosting
    does; the sign of f separates over-ghosting from under-ghosting;

    bounds, and every permutation family reports `ensemble.effect_summary`;
  - (e) units: sizes in px; region means and `structure_std` in display bytes (0-255, SPEC §7); `spectral_slope`
    dimensionless; `clip_fraction` a fraction of pixels; f and ρ dimensionless fractions of the per-key ghost gap; K in
    diffuse draws per pixel per pass; `jitter` at its socket default, 1/1400 of the fitted image side (SPEC §7); sphere

## Hypothesis

### Common definitions

- **Configurations** (Method): `analytic_ghost` (R, the reference: every sphere a ghost), `analytic_ghost_rep` (R′, an
  independent replicate of R), `analytic_exact` (E: spheres 0-2 exact, the light a ghost), `mesh_off` (N, the negative
  control: spheres 0-2 meshes, `mesh_ghost = off`) and `mesh_<c>` (C_c) for the candidates c = `bounding_sphere`,
  `homothety`, `angular_dilation`, `sdf_step`. Each is 9 pairs. A pair is two half renders with seeds 2k and 2k + 1 of the
  configuration's seed range. A half render is 200 px, 16 passes, rendered by the native core. Every knob keeps its
  socket default except `seed`, `two_sided = False`, the smallpaint-unit knobs of `apply_reference_knobs()` (applied by
  the builder: `diffuse_gain` float32(0.1), `emission_gain` 2, `ray_epsilon` float32(1e-4), `max_depth` 20,
  `spiral_frame` smallpaint) and, for the mesh configurations, `mesh_ghost`. `chain` is `row`, its default.
- **Mesh spheres.** Spheres 0, 1 and 2 of SPEC §9 as smooth UV spheres of 32 segments × 16 rings (960 triangles each):
  vertices `r·u` in object space (float32), corner normals `u`, object-to-world the translation by the centre, the
  sphere's material and object id. The planes and the light are analytic.
- **Measurement.** The common id map: a pixel keeps its unjittered primary-hit object id if all 8 configurations agree,
  else −1; the light (id 9, a constant 240 display bytes) is set to −1 too. Per pair,
  `metrics.measure(sum_a, sum_b, 16, ref8, common_map)` with the plan's 9-px box high-pass and 4-px erosion. `ref8`, the
  display image of pair 0 of R, enters only `pattern_corr` and `block_rmse`, which are not used.
- **Key family F**: `metrics.realization_free_key_family(metrics.diffuse_key_family(keys))` plus `r0.mean.{R,G,B}` and
  `r1.mean.{R,G,B}` (the mirror and glass spheres, whose means show what they reflect and refract). With regions 0-7
  measured (the front plane, 8, is behind the camera): 6 diffuse regions × (mean R, G, B, `structure_std`),
  `all.spectral_slope`, `all.clip_fraction` and the 6 sphere means, 32 keys. Realization-free, because a mesh changes K
  consumption (pilot: 19.18 vs 16.21 draws per path), and 002 showed that `pattern_corr` and `block_rmse` then measure the
  changed sample sequence, not the look.
- **Significance.** α = 0.01 per hypothesis (`SIGNIFICANCE`; not the knob `alpha`). Every p-value is an exact two-sided
  permutation p-value (`ensemble.permutation_pvalue`); Holm (`ensemble.holm`) runs over the 32 keys of a comparison.
- **Power.** 9 vs 9 pairs: the smallest attainable two-sided p is 2 / C(18, 9) = 4.11e-5. The first Holm threshold is
  0.01 / 32 = 3.13e-4 for H1, H3 and the meshing comparison, and 0.01 / 4 / 32 = 7.81e-5 for the per-candidate
  comparisons. All are powered; `analyze.py` checks it.
- **Ghost-sensitive keys G**: the keys of F that H1 rejects (N against R): the keys on which ghosting is detectable.
- **Residual fraction.** For a configuration X and a key k of G, with m the mean over pairs:
  `f_X,k = (m_X,k − m_R,k) / (m_N,k − m_R,k)`. f = 0 is the analytic ghost, f = 1 the mesh without ghosting, f < 0 lies
  beyond the analytic ghost on the far side from N (**over-ghosting**: more ghost effect than the analytic ghost), and
  f > 1 lies beyond N.
- **ρ_X = median over k in G of |f_X,k|**: the median fraction of the ghost effect that X leaves. ρ_R = 0 and ρ_N = 1 by
  construction.
- **Floors.** The noise floor ρ_rep = ρ_R′. The meshing floor `ρ_mesh = median over k in G of |m_N,k − m_E,k| / |m_N,k − m_R,k|`:
  what meshing alone does, without ghosts, in units of the ghost gap.
- **Bootstrap.** 100,000 resamples (`BOOTSTRAP_RESAMPLES`); in each, the pairs of every configuration are resampled with
  replacement, independently, with indices from `numpy.random.default_rng(0)` drawn in configuration order; G stays
  fixed. A **bound at level q** is the q or 1 − q quantile of the resampled statistic. The decision bounds use
  q = 0.01 / 4 = 0.0025 per candidate (Bonferroni over the four), and H2 uses q = 0.01. Estimation intervals are two-sided
  99% (quantiles 0.005 and 0.995). The resample count sets only the Monte Carlo precision of the bounds. With 9 pairs per
  configuration, percentile bounds are approximate and tend to be narrow; the permutation families (Estimation) test the
  same configurations exactly.
- **Estimation with every verdict.** `ensemble.effect_summary` of every configuration against R on F; the companion
  families C_c against R and C_c against N on F (Holm at 0.01 / 4 each); ρ by key class (means, `structure_std`, global);
  the signed median of f and the share of G with f < 0 (the over-ghost share); K per pixel per pass; the median wall
  seconds per render and their ratio to `mesh_off`. "Not rejected" is written only with `min_attainable_p` and the
  largest effects.

### H1: the ghosting of the three spheres is detectable on meshes (positive control)

- Derived from: 002 H5 (lights-only ghosting differs from all-ghost on 45 of 46 keys; 24 of the 26 diffuse keys of F with
  |d| ≥ 3.1) and the pilot (f = 1 vs 0 on the mean, K 19.18 vs 16.21).
- Test: N against R on F, Holm at 0.01. The rejected keys are G.
- Prediction: every mean key of F is in G. At 200 px and 16 passes some `structure_std` keys may not be.
- Decision: supported iff G is not empty. Refuted otherwise; then H2 and H4 are inconclusive.

### H2: meshing alone stays below the ghost effect (design check)

- Derived from: the pilot, where the meshing alone was 0.0125 of the ghost gap on the mean. If meshing moved the look as
  much as ghosting, "at the meshing floor" (H4) could not tell a candidate from no ghosting.
- Observable: ρ_mesh. Also reported: N against E on F, Holm at 0.01, whose rejected keys are what meshing changes.
- Decision: supported iff the one-sided upper bound of ρ_mesh at level 0.01 is below 1. Refuted otherwise; then every
  candidate that recovers (H4 (a)) is inconclusive.

### H3: the replicate is indistinguishable from the reference (noise floor)

- Derived from: R′ is R's configuration with other seeds. Holm at 0.01 bounds the chance of a false rejection by 0.01.
- Test: R′ against R on F, Holm at 0.01. ρ_rep is reported.
- Decision: supported iff no key is rejected. Refuted otherwise: the renders are not replicates (a seed or harness fault),
  and every H4 outcome is inconclusive.

### H4: which candidates reproduce the analytic ghost on sphere meshes (decision statistic)

- **Outcome of a candidate c**, with ρ_c and ρ_mesh from the same resamples:
  - (a) *recovers*: the upper bound of ρ_c at level 0.0025 is below 1;
  - (b) *at the floor*: the lower bound of ρ_c − ρ_mesh at level 0.0025 is at most 0;
  - **go** iff (a) and (b); **partial** iff (a) and not (b); **no-go** iff not (a).
  - Why these anchors: 0 and 1 are the two ends of the ghost effect, measured, not chosen; the floor is what a mesh costs
    without ghosting. A candidate is go when it leaves less of the ghost effect than no ghosting does, and is not shown to
    be farther from the analytic ghost than meshing alone puts a mesh from an analytic sphere.
- Geometry used below (SPEC §5). A ray from o with |d| = L and a sphere (c, r) at D = |o − c| > r. The analytic ghost
  subtends from o the cone of half-angle θ_g with `sin θ_g = sqrt((L² − 1)D² + r²) / (L·D)`, so
  `sin² θ_g − r²/D² = (L² − 1)(D² − r²) / (L²D²)`: wider than the sphere's `α = asin(r/D)` for L > 1, narrower for L < 1.
  With `β = acos(1/L)`, `sin² θ_g = sin² β + sin² α · cos² β`. This cone growth lights the back wall (002 H1: 144 vs 13
  grey levels without ghosts) and shadows the floor (002 H5).
- **H4a: `bounding_sphere` is go.** Derived from: its proxy is the bounding sphere for every ray (T9.1). A 32 × 16 UV
  sphere has vertices on the sphere, among them ±r along each axis (the poles, and the equator ring at azimuths 0°, 90°,
  180° and 270°), so its bounding box is c ± r and its radius r, up to the float32 rounding of the vertices and the
  transform: the proxy is the analytic sphere. Pilot: equal to `analytic_ghost` to every printed digit. Decision:
  supported iff its outcome is go; refuted iff partial or no-go.
- **H4b: `homothety` is not go.** Derived from: a homothety about o maps each direction from o to itself, so the scaled
  mesh subtends the mesh's own cone (T9.1: "the hit set is the true one"). It reproduces the ghost centre `o + L²(c − o)`
  but has the radius L²r, whose cone is α for every L: no cone growth. Pilot f = +1.18. Decision: supported iff partial or
  no-go; refuted iff go.
- **H4c: `angular_dilation` is not go, and over-ghosts.** Derived from: on a sphere mesh the dilated footprint has the
  half-angle α + β (for L ≥ 1). Then `sin²(α + β) − sin² θ_g = sin α · sin β · (2 cos α cos β − sin α sin β)`, which is
  positive whenever α + β < 90°: a wider cone than the analytic ghost for every L > 1 and r > 0. For L < 1 it keeps the
  mesh where the analytic ghost shrinks. Both mean more ghost effect: f < 0. Pilot f = −0.763. Decision: supported iff
  its outcome is partial or no-go and the 99% interval of its signed median f lies below 0; refuted iff go, or iff that
  interval lies above 0; inconclusive otherwise.
- **H4d: `sdf_step` is not go.** Derived from: a march of the unsigned distance never hits a ray that passes the mesh by
  more than eps (T9.1: "it never dilates"), so its hit set is the mesh's: no cone growth. Pilot f = +1.146. Decision:
  supported iff partial or no-go; refuted iff go.
- Gates: every outcome is inconclusive if H1 is not supported or H3 is refuted; a candidate that recovers is inconclusive
  if H2 is refuted.

### Decision: which candidate becomes an artist option (pre-registered)

- The **go** candidates are the candidates whose H4 outcome is go.
- If there is at least one, the go candidate with the smallest ρ (ties: the earlier candidate in T9.1's order) is
  **recommended** as the artist option. The 99% intervals of the pairwise ρ differences between go candidates are
  reported; when one contains 0, this experiment does not separate those two, and Opus chooses between them with their
  cost ratios (Table 6).
- If there is none, no candidate becomes an artist option.
- In every outcome the default of `mesh_ghost` stays `off`, and this experiment changes no knob, preset or SPEC text.

### What each outcome means (pre-registered, for Opus's conclusion)

- **`bounding_sphere` go.** Its proxy replaces the object for every ray, camera rays included (T9.1), so on a mesh that is
  not a sphere the camera sees the bounding sphere. A go therefore answers the plan's question on exposing painterly
  spheres: a sphere-shaped mesh rendered as its ghost bounding sphere is the analytic ghost sphere. It is offered for
  sphere-like objects only, as a per-object option; the socket is global, so a later Opus card decides the form. It does
  not generalize ghosting to other shapes.
- **`homothety`, `angular_dilation` or `sdf_step` go.** That candidate becomes the artist option for mesh ghosting
  (default off), with its cost ratio to `mesh_off` stated (pilot: 546 for `angular_dilation`, 66 for `sdf_step`).
- **Partial.** The candidate is not exposed as the ghost generalization. The sign of its signed median f says whether it
  over-ghosts (f < 0) or under-ghosts (0 < f < 1). Opus may consider it as a stylization in a later card.
- **No candidate go.** SPEC §5's Blender rule stands: only point and spot lights are ghosts. The ghost look of a sphere
  then needs an analytic painterly sphere.
- **Not measured here:** non-spherical meshes, 400 px, and `two_sided = true`. X-open-scenes (T9.3) or a later experiment
  takes them up.

## Appendix B — `experiments/NNN-DATE-mesh-ghost/mesh_spheres.py` (Step 4)
```python
"""UV-sphere meshes in place of SPEC §9's non-emissive spheres (experiment NNN, T9.2).

``MeshSphereScene`` wraps a ``_painterly.Scene`` and is passed to the add-on's
``sync/reference.py`` ``build_smallpaint_scene`` (T4.3), the single source of the SPEC §9 scene.
Every call is forwarded unchanged, except ``add_sphere`` for a sphere whose material has zero
emission: that sphere becomes a smooth UV-sphere mesh with the same centre, radius, material and
object id. The emissive sphere (the light, SPEC §9 id 9) stays an analytic sphere, as a Blender
point light does (SPEC §5). Everything else in the scene, its order and its knobs, is the
reference builder's. The module is bpy-free and needs no ``_painterly`` import.
"""

from typing import Any

import numpy as np

# Blender's default UV sphere (bpy.ops.mesh.primitive_uv_sphere_add: segments=32, ring_count=16):
# 32 segments around the polar axis, 16 rings from pole to pole, 960 triangles, smooth shading.
# The reference .blend of T5.4 uses 64 x 32; this experiment uses the default because the cost of
# angular_dilation grows with the triangle count (T9.1; README, Background).
UV_SEGMENTS = 32
UV_RINGS = 16
# SPEC §9 ids of the spheres whose material has zero emission (middle, right, left sphere).
REPLACED_IDS = (0, 1, 2)


def uv_sphere(segments: int = UV_SEGMENTS, rings: int = UV_RINGS) -> tuple[np.ndarray, np.ndarray]:
    """Unit UV sphere about the origin, poles on ±z, with Blender's UV-sphere topology.

    Returns ``(unit, triangles)``: ``unit`` float64 (V, 3) with V = 2 + (rings - 1) * segments,
    vertex 0 the +z pole, then ring k = 1 .. rings - 1 at polar angle pi * k / rings, segment
    j = 0 .. segments - 1 at azimuth 2 pi j / segments, then the -z pole; ``triangles`` uint32
    (T, 3) with T = 2 * segments * (rings - 1): the two pole fans and two triangles per quad,
    wound counter-clockwise seen from outside (outward geometric normals).
    """
    if segments < 3 or rings < 2:
        raise ValueError("a UV sphere needs segments >= 3 and rings >= 2")
    polar = np.pi * np.arange(1, rings) / rings
    azimuth = 2.0 * np.pi * np.arange(segments) / segments
    ring = np.stack(
        [
            np.outer(np.sin(polar), np.cos(azimuth)),
            np.outer(np.sin(polar), np.sin(azimuth)),
            np.outer(np.cos(polar), np.ones(segments)),
        ],
        axis=-1,
    ).reshape(-1, 3)
    unit = np.concatenate([[[0.0, 0.0, 1.0]], ring, [[0.0, 0.0, -1.0]]])
    south = unit.shape[0] - 1

    def vertex(k: int, j: int) -> int:
        """Index of ring k (1-based), segment j (wrapped)."""
        return 1 + (k - 1) * segments + j % segments

    tris: list[tuple[int, int, int]] = []
    for j in range(segments):
        tris.append((0, vertex(1, j), vertex(1, j + 1)))
    for k in range(1, rings - 1):
        for j in range(segments):
            a, b = vertex(k, j), vertex(k, j + 1)
            c, d = vertex(k + 1, j), vertex(k + 1, j + 1)
            tris.append((a, c, d))
            tris.append((a, d, b))
    for j in range(segments):
        tris.append((vertex(rings - 1, j), south, vertex(rings - 1, j + 1)))
    triangles = np.asarray(tris, dtype=np.uint32)
    if unit.shape[0] != 2 + (rings - 1) * segments:
        raise RuntimeError("UV sphere vertex count")
    if triangles.shape[0] != 2 * segments * (rings - 1):
        raise RuntimeError("UV sphere triangle count")
    corners = unit[triangles.astype(np.int64)]
    normals = np.cross(corners[:, 1] - corners[:, 0], corners[:, 2] - corners[:, 0])
    # The sign of a dot product with the triangle's centroid: outward iff positive (no tolerance).
    if not bool(np.all(np.einsum("ij,ij->i", normals, corners.mean(axis=1)) > 0.0)):
        raise RuntimeError("UV sphere triangles are not wound outward")
    return unit, triangles


class MeshSphereScene:
    """A ``_painterly.Scene`` whose non-emissive spheres are added as UV-sphere meshes.

    ``scene`` is the wrapped ``_painterly.Scene``; pass it, not the wrapper, to
    ``_painterly.Session``. ``replaced`` lists the object ids made into meshes, in call order;
    ``forwarded`` lists the object ids of the spheres passed through as analytic spheres. An
    ``object_id < 0`` (auto) is resolved as the core resolves it: the running count of
    add_sphere, add_plane and add_object calls (T3.13). Each replaced sphere is one add_object
    call, so the count, and every later auto id, is the one the unwrapped scene would get.
    """

    def __init__(self, scene: Any, segments: int = UV_SEGMENTS, rings: int = UV_RINGS) -> None:
        self.scene = scene
        self._unit, self._triangles = uv_sphere(segments, rings)
        self._emission: dict[int, tuple[float, float, float]] = {}
        self.replaced: list[int] = []
        self.forwarded: list[int] = []
        self.triangles_per_sphere = int(self._triangles.shape[0])
        self._primitives = 0

    def _object_id(self, object_id: int) -> int:
        """The object id the core assigns to the next add_sphere/add_plane/add_object call."""
        resolved = int(object_id) if object_id >= 0 else self._primitives
        self._primitives += 1
        return resolved

    def __getattr__(self, name: str) -> Any:
        return getattr(self.scene, name)

    def add_material(self, lobes, emission=(0.0, 0.0, 0.0)) -> int:
        """Forwarded; the emission of the returned material index is recorded."""
        index = self.scene.add_material(lobes, emission)
        self._emission[int(index)] = tuple(float(e) for e in emission)
        return index

    def add_plane(self, normal, d, material, object_id=-1) -> int:
        """Forwarded with its object id resolved."""
        return self.scene.add_plane(normal, d, material, self._object_id(object_id))

    def add_sphere(
        self, center, radius, material, intersection="ghost", object_id=-1, spot=None
    ) -> int:
        """Forwarded for an emissive material; otherwise a UV-sphere mesh object.

        The mesh has the vertices ``radius * unit`` (float32, object space) and the corner normals
        ``unit`` at each triangle corner (float32): the analytic sphere's normals at the vertices,
        interpolated by the core (SPEC §6). Its object-to-world transform is the translation by
        ``center`` (float32, 3 x 4). Returns the core's object index for a mesh, else the analytic
        index.
        """
        object_id = self._object_id(object_id)
        if any(e != 0.0 for e in self._emission[int(material)]):
            self.forwarded.append(object_id)
            return self.scene.add_sphere(center, radius, material, intersection, object_id, spot)
        if spot is not None:
            raise ValueError("a replaced sphere has no spot profile (SPEC §9 has none)")
        vertices = np.ascontiguousarray(float(radius) * self._unit, dtype=np.float32)
        corner_normals = np.ascontiguousarray(
            self._unit[self._triangles.astype(np.int64)], dtype=np.float32
        )
        tri_material = np.full(self._triangles.shape[0], int(material), dtype=np.int32)
        mesh = self.scene.add_mesh(vertices, self._triangles, tri_material, corner_normals)
        cx, cy, cz = (float(v) for v in center)
        object_to_world = np.array(
            [[1.0, 0.0, 0.0, cx], [0.0, 1.0, 0.0, cy], [0.0, 0.0, 1.0, cz]], dtype=np.float32
        )
        self.replaced.append(object_id)
        return self.scene.add_object(mesh, object_to_world, object_id)

    def check(self) -> None:
        """Raise unless exactly SPEC §9's three non-emissive spheres became meshes, in id order,
        and exactly one sphere (the light) stayed analytic."""
        if tuple(self.replaced) != REPLACED_IDS or len(self.forwarded) != 1:
            raise RuntimeError(
                f"replaced {self.replaced}, forwarded {self.forwarded}: expected replaced "
                f"{list(REPLACED_IDS)} and one forwarded light (SPEC §9)"
            )
```

## Appendix C — `experiments/NNN-DATE-mesh-ghost/render.py` (Step 4)
```python
"""Native-core renders of experiment NNN (T9.2, mesh ghost), cached and resumable.

The oracle has no triangle meshes and no mesh_ghost, so this experiment renders with the native
core, ``_painterly.Session``, instead of ``python -m painterly_analysis.experiment run``. A job is
a ``painterly_analysis.experiment.Job`` of ``jobs.py``. Its ``spheres`` option picks the scene:
``analytic_ghost`` and ``analytic_exact`` are the add-on's ``build_smallpaint_scene`` (T4.3) with
``ghost="all"`` and ``ghost="lights"``; ``mesh`` is the same builder with ``ghost="lights"`` through
``mesh_spheres.MeshSphereScene``, which adds SPEC §9's three non-emissive spheres as UV-sphere
meshes. Then ``set_integrator(seed=job.seed, **knobs)`` with the job's remaining options.

Each render goes to ``<cache>/native-renders/<key>/`` with the file layout of an oracle render
(``sum.npy``, ``k_consumed.npy``, ``object_id.npy``, ``meta.json``), so
``painterly_analysis.io.read_oracle`` loads it. A ``done`` marker is written last. ``<cache>`` is
``$PAINTERLY_CACHE`` (relative to the repository root) or ``<repo>/.cache``, as in
``painterly_analysis.experiment.cache_root``.

Run ``.venv/bin/python experiments/<this directory>/render.py --budget 540`` until it exits 0.
Exit code 3 means jobs remain. ``--smoke`` renders the small smoke jobs instead, and needs
``$PAINTERLY_CACHE`` set to a scratch directory.
"""

import argparse
import hashlib
import importlib
import importlib.util
import json
import os
import sys
import time
from pathlib import Path
from types import ModuleType

import numpy as np
from painterly_analysis.experiment import (
    DEFAULT_BUDGET_SECONDS,
    EXIT_REMAINING,
    Job,
    load_jobs_module,
)
from painterly_analysis.io import OracleRender, read_oracle

EXP_DIR = Path(__file__).resolve().parent
REPO_ROOT = EXP_DIR.parents[1]
# Part of every cache key, so no other experiment's native render is ever loaded as one of these.
EXPERIMENT = "mesh-ghost"
# Part of every cache key. Increment it when this file or mesh_spheres.py changes what a render
# writes.
RENDERER_VERSION = "1"
# Hex digits of a cache key, as in painterly_analysis.experiment.job_key.
KEY_HEX_DIGITS = 16
# Read size when hashing the module. It affects I/O only, never the digest.
HASH_CHUNK_BYTES = 1 << 20
# Session threads: 0 is one per logical CPU. The output is identical for any count (SPEC §3).
THREADS = 0
DONE = "done"
# The smoke run, a code check only: 128 px keeps every SPEC §9 region after the 4-px erosion; four
# passes and two pairs per configuration.
SMOKE_SIZE = 128
SMOKE_PASSES = 4
SMOKE_PAIRS = 2
# The exit code of a smoke run without $PAINTERLY_CACHE (argparse also uses 2 for usage errors).
EXIT_USAGE = 2
# The mesh_ghost socket as T9.1 defines it: its enum items in C++ enum value order, and default.
MESH_GHOST_SOCKET = "mesh_ghost"
MESH_GHOST_DEFAULT = "off"


def _load_file(name: str, path: Path) -> ModuleType:

    if spec is None or spec.loader is None:
        raise RuntimeError(f"cannot load {path}")

    return module


def _import_painterly() -> ModuleType:
    """``_painterly`` from ``$PAINTERLY_BUILD_DIR/src/blender`` (default ``build/dev``, relative to
    the repository root), as ``tests/conftest.py`` and T3.18 do."""
    build_dir = Path(os.environ.get("PAINTERLY_BUILD_DIR", "build/dev"))
    if not build_dir.is_absolute():
        build_dir = REPO_ROOT / build_dir
    sys.path.insert(0, str(build_dir / "src" / "blender"))
    return importlib.import_module("_painterly")


_painterly = _import_painterly()
# The SPEC §9 scene of the add-on's reference mode (T4.3). The file is bpy-free.
reference = _load_file(
    "mesh_ghost_reference", REPO_ROOT / "src" / "blender" / "addon" / "sync" / "reference.py"
)
mesh_spheres = _load_file("mesh_ghost_mesh_spheres", EXP_DIR / "mesh_spheres.py")
jobs_module = load_jobs_module(EXP_DIR / "jobs.py")


def experiment_ensembles(smoke: bool) -> dict[str, list[Job]]:
    """The full ensembles of ``jobs.py``, or the smoke ensembles."""
    if not smoke:
        return jobs_module.ENSEMBLES
    return jobs_module.ensembles(size=SMOKE_SIZE, passes=SMOKE_PASSES, pairs=SMOKE_PAIRS)


def check_sockets() -> None:
    """Raise unless ``mesh_ghost`` is the enum socket of T9.1, with the candidates of jobs.py."""
    sockets = {s["name"]: s for s in _painterly.integrator_sockets()}
    socket = sockets.get(MESH_GHOST_SOCKET)
    expected = [MESH_GHOST_DEFAULT, *jobs_module.CANDIDATES]
    if (
        socket is None

            f"items {expected} and default {MESH_GHOST_DEFAULT!r}"
        )


def module_sha256() -> str:
    """The sha256 of the imported ``_painterly`` module file."""
    digest = hashlib.sha256()
    with open(_painterly.__file__, "rb") as f:
        while chunk := f.read(HASH_CHUNK_BYTES):
            digest.update(chunk)
    return digest.hexdigest()


def cache_base() -> Path:
    base = Path(os.environ.get("PAINTERLY_CACHE") or REPO_ROOT / ".cache")
    if not base.is_absolute():
        base = REPO_ROOT / base
    return base / "native-renders"


def render_key(job: Job, module_digest: str) -> str:
    """The first KEY_HEX_DIGITS hex digits of the sha256 of the canonical JSON of EXPERIMENT, the
    job's options and seed, RENDERER_VERSION and the module's sha256. The job name is not part of
    the key."""
    canonical = {
        "experiment": EXPERIMENT,
        "options": dict(job.options),
        "seed": job.seed,
        "renderer_version": RENDERER_VERSION,
        "module_sha256": module_digest,
    }
    text = json.dumps(canonical, sort_keys=True, separators=(",", ":"))
    return hashlib.sha256(text.encode("utf-8")).hexdigest()[:KEY_HEX_DIGITS]


def render_dir(job: Job, module_digest: str) -> Path:
    return cache_base() / render_key(job, module_digest)


def is_done(job: Job, module_digest: str) -> bool:
    return (render_dir(job, module_digest) / DONE).is_file()


def load(job: Job, module_digest: str) -> OracleRender:
    """The cached render of ``job``. Raises FileNotFoundError until ``render`` has made it."""
    directory = render_dir(job, module_digest)
    if not (directory / DONE).is_file():
        raise FileNotFoundError(
            f"job {job.name!r} (seed {job.seed}) is not rendered: run render.py"
        )
    return read_oracle(directory)


def finished_seconds(jobs: list[Job], module_digest: str) -> dict[str, list[float]]:
    """The wall seconds of every finished render, by configuration (job name)."""
    seconds: dict[str, list[float]] = {}
    for job in jobs:
        if is_done(job, module_digest):
            meta = json.loads((render_dir(job, module_digest) / "meta.json").read_text())
            seconds.setdefault(job.name, []).append(float(meta["wall_seconds"]))
    return seconds


def build(spheres: str, size: int) -> tuple[object, dict[str, object]]:
    """The core scene of a ``spheres`` option and a record of how it was built."""
    scene = _painterly.Scene()
    if spheres == "analytic_ghost":
        reference.build_smallpaint_scene(scene, size=size, ghost="all")
        return scene, {}
    if spheres == "analytic_exact":
        reference.build_smallpaint_scene(scene, size=size, ghost="lights")
        return scene, {}
    if spheres == "mesh":
        wrapper = mesh_spheres.MeshSphereScene(scene)
        reference.build_smallpaint_scene(wrapper, size=size, ghost="lights")
        wrapper.check()
        return scene, {
            "replaced_object_ids": wrapper.replaced,
            "analytic_sphere_object_ids": wrapper.forwarded,
            "triangles_per_sphere": wrapper.triangles_per_sphere,
            "uv_segments": mesh_spheres.UV_SEGMENTS,
            "uv_rings": mesh_spheres.UV_RINGS,
        }
    raise ValueError(f"unknown spheres option {spheres!r}")


def render(job: Job, module_digest: str) -> float:
    """Render ``job`` with the native core into its cache directory. Returns the wall seconds."""
    knobs = dict(job.options)
    size = knobs.pop("size")
    passes = knobs.pop("passes")
    scene, built = build(knobs.pop("spheres"), size)
    scene.set_integrator(seed=job.seed, **knobs)
    integrator = scene.get_integrator()
    session = _painterly.Session(scene, THREADS)
    start = time.monotonic()
    session.start(passes, passes)
    session.wait()
    wall_seconds = time.monotonic() - start
    progress = session.progress()
    if progress["state"] != "done":
        raise RuntimeError(f"{job.name} seed {job.seed}: {progress['state']}: {progress['error']}")
    object_id = session.object_id()
    if built and not set(mesh_spheres.REPLACED_IDS) <= set(np.unique(object_id).tolist()):
        raise RuntimeError(f"{job.name} seed {job.seed}: a mesh sphere is not visible")
    directory = render_dir(job, module_digest)
    directory.mkdir(parents=True, exist_ok=True)
    np.save(directory / "sum.npy", session.combined())
    np.save(directory / "k_consumed.npy", session.k_consumed())
    np.save(directory / "object_id.npy", object_id)
    meta = {
        "passes": passes,
        "width": size,
        "height": size,
        "seed": job.seed,
        "options": dict(job.options),
        "integrator": integrator,
        "scene": built,
        "experiment": EXPERIMENT,
        "renderer_version": RENDERER_VERSION,
        "module_sha256": module_digest,
        "threads": THREADS,
        "cpu_count": os.cpu_count(),
        "wall_seconds": wall_seconds,
    }
    (directory / "meta.json").write_text(json.dumps(meta, sort_keys=True, indent=1) + "\n")
    record = {"name": job.name, "seed": job.seed, "options": dict(job.options)}
    (directory / DONE).write_text(json.dumps(record, sort_keys=True) + "\n")
    return wall_seconds


def main(argv: list[str] | None = None) -> int:
    parser = argparse.ArgumentParser(description=__doc__.splitlines()[0])
    parser.add_argument(
        "--budget",
        type=float,
        default=DEFAULT_BUDGET_SECONDS,
        help="seconds after which no further render starts (default: %(default)s)",
    )
    parser.add_argument("--smoke", action="store_true", help="render the smoke jobs")
    args = parser.parse_args(argv)
    if args.smoke and not os.environ.get("PAINTERLY_CACHE"):
        print("--smoke needs PAINTERLY_CACHE set to a scratch directory", file=sys.stderr)
        return EXIT_USAGE
    check_sockets()
    digest = module_sha256()
    jobs = [job for ensemble in experiment_ensembles(args.smoke).values() for job in ensemble]
    seconds = finished_seconds(jobs, digest)
    start = time.monotonic()
    rendered = 0
    for job in jobs:
        if is_done(job, digest):
            continue
        # A call always renders one job. After that, a job starts only if the median wall time of
        # its configuration's finished renders fits in what is left of the budget; a
        # configuration with none waits for the next call. So a call outlasts the budget only by
        # its first render, or by a render slower than its configuration's median.
        known = seconds.get(job.name)
        elapsed = time.monotonic() - start
        if rendered and (not known or elapsed + float(np.median(known)) > args.budget):
            break
        wall_seconds = render(job, digest)
        seconds.setdefault(job.name, []).append(wall_seconds)
        rendered += 1
        print(f"{job.name} seed {job.seed}: {wall_seconds:.1f} s", flush=True)
    remaining = sum(not is_done(job, digest) for job in jobs)
    print(f"completed={len(jobs) - remaining} remaining={remaining}")
    return 0 if remaining == 0 else EXIT_REMAINING


if __name__ == "__main__":
    sys.exit(main())
```

## Appendix D — `experiments/NNN-DATE-mesh-ghost/analyze.py` (Step 4)
```python
"""Analysis of experiment NNN (T9.2): which mesh-ghost candidate reproduces analytic ghost spheres?

Implements the Common definitions, H1 to H4 and the Decision of ``README.md``, which is the
specification. It re-runs from the native render cache of ``render.py``, so every render must
exist. A smoke run (``--smoke``) reads the smoke renders from ``$PAINTERLY_CACHE`` and writes to a
scratch ``--out-dir``; every printed line then starts with ``SMOKE (code check only): `` and
``results.json`` holds ``"smoke": true``. It is deterministic: the tests are exact permutation
tests, and the bootstrap draws its resamples from ``numpy.random.default_rng(BOOTSTRAP_SEED)``.

Figure (no text is drawn; the layout is also in ``results.json`` under ``figures``):
``fig_grid.png``, the display image of pair 0 of each configuration (both halves summed, SPEC §7)
at full resolution, in ``jobs.DESIGN`` order, FIGURE_COLUMNS per row. At 200 px that is 800 x 400
RGB, 960,000 bytes before compression, so the file stays under 1 MB.
"""

import argparse
import hashlib
import importlib.util
from collections.abc import Callable, Mapping, Sequence
from pathlib import Path
from types import ModuleType
from typing import Any

import jax.numpy as jnp
import numpy as np
from painterly_analysis import ensemble, io, metrics, report

EXP_DIR = Path(__file__).resolve().parent
REPO_ROOT = EXP_DIR.parents[1]

# The family-wise level of every hypothesis (README). Not the knob alpha.
SIGNIFICANCE = 0.01
REFERENCE = "analytic_ghost"
REPLICATE = "analytic_ghost_rep"

# Every SPEC §9 id except the light (9), whose region is a constant 240 display bytes: emission
# 120 times emission_gain 2, with cl 0 (SPEC §6, §9). The front plane (8) is behind the camera and
# is measured only if it is visible.
MEASURED_IDS = (0, 1, 2, 3, 4, 5, 6, 7, 8)
# The mirror (0) and glass (1) spheres: their region means are realization-free keys that
# metrics.diffuse_key_family leaves out (README, Common definitions).
SPHERE_MEAN_REGIONS = (0, 1)
# The bootstrap of the decision statistics (README, H2 and H4). The resample count sets only the
# Monte Carlo precision of the bounds; the chunk bounds memory only.
BOOTSTRAP_RESAMPLES = 100_000
BOOTSTRAP_SEED = 0
BOOTSTRAP_CHUNK = 10_000
# Two-sided 99% percentile intervals of the estimation-only statistics (1 - SIGNIFICANCE).
ESTIMATION_QUANTILES = (SIGNIFICANCE / 2, 1.0 - SIGNIFICANCE / 2)

FIGURE_COLUMNS = 4

def _load_file(name: str, path: Path) -> ModuleType:
    spec = importlib.util.spec_from_file_location(name, path)
    if spec is None or spec.loader is None:
        raise RuntimeError(f"cannot load {path}")
    module = importlib.util.module_from_spec(spec)
    spec.loader.exec_module(module)
    return module


def configuration(candidate: str) -> str:
    """The configuration name of a candidate (jobs.DESIGN)."""
    return f"mesh_{candidate}"


def check_design(jobs: ModuleType, ensembles: Mapping[str, list], smoke: bool) -> None:
    """The configurations, options and seeds of README, Method; in a full run also the size, the
    passes, the pairs and the global seed rule (report.check_seed_reuse)."""
    common = {"two_sided": False}
    expected = {
        REFERENCE: {"spheres": "analytic_ghost", **common},
        REPLICATE: {"spheres": "analytic_ghost", **common},
        EXACT: {"spheres": "analytic_exact", **common},
        NEGATIVE: {"spheres": "mesh", "mesh_ghost": "off", **common},
    }
    for candidate in CANDIDATES:
        expected[configuration(candidate)] = {"spheres": "mesh", "mesh_ghost": candidate, **common}
    if tuple(jobs.CANDIDATES) != CANDIDATES:
        raise RuntimeError(f"jobs.CANDIDATES {jobs.CANDIDATES} differ from {CANDIDATES}")
    if list(jobs.DESIGN) != list(expected) or dict(jobs.DESIGN) != expected:
        raise RuntimeError(f"jobs.DESIGN differs from the README: {jobs.DESIGN}")
    if list(ensembles) != list(expected):
        raise RuntimeError(f"ensembles {list(ensembles)} differ from {list(expected)}")
    pairs = {len(e) // 2 for e in ensembles.values()}
    if len(pairs) != 1:
        raise RuntimeError(f"configurations have different numbers of pairs: {pairs}")
    for index, (name, ensemble_jobs) in enumerate(ensembles.items()):
        base = jobs.first_seed(index, len(ensemble_jobs) // 2)
        if [job.seed for job in ensemble_jobs] != list(range(base, base + len(ensemble_jobs))):
            raise RuntimeError(f"{name}: seeds differ from {base} .. {base + len(ensemble_jobs)}")
        for job in ensemble_jobs:
            options = dict(job.options)
            rest = {k: v for k, v in options.items() if k not in ("size", "passes")}
            if rest != expected[name]:
                raise RuntimeError(f"{name} seed {job.seed}: options {rest}")
    if smoke:
        return
    for name, ensemble_jobs in ensembles.items():
        for job in ensemble_jobs:
            options = dict(job.options)
            if (options["size"], options["passes"]) != (jobs.SIZE, jobs.PASSES):
                raise RuntimeError(f"{name} seed {job.seed}: size or passes differ from jobs.py")
    if pairs != {jobs.PAIRS}:
        raise RuntimeError(f"a full run needs jobs.PAIRS = {jobs.PAIRS} pairs everywhere")
    earlier = {
        path.parent.name.split("-")[0]: path
        for path in sorted((REPO_ROOT / "experiments").glob("*/jobs.py"))
        if path.parent.resolve() != EXP_DIR
    }
    report.check_seed_reuse(ensembles, earlier, {})


def check_renders(
    ensembles: Mapping[str, list], renders: Mapping[str, list], digest: str
) -> dict[str, Any]:
    """The jobs' passes and sizes, one object-id map per configuration, the module that rendered
    them, and distinct replicates in every configuration (independent replicates, experiment
    006). Returns the bookkeeping of README Table 6."""
    distinct: dict[str, int] = {}
    wall: dict[str, list[float]] = {}
    k_rate: dict[str, list[float]] = {}
    for name, rendered in renders.items():
        first = rendered[0].object_id
        wall[name], k_rate[name] = [], []
        for job, render in zip(ensembles[name], rendered, strict=True):
            options = dict(job.options)
            if render.passes != options["passes"]:
                raise RuntimeError(f"{name} seed {job.seed}: passes {render.passes}")
            if render.object_id.shape != (options["size"], options["size"]):
                raise RuntimeError(f"{name} seed {job.seed}: size {render.object_id.shape}")
            if render.meta["module_sha256"] != digest or render.meta["seed"] != job.seed:
                raise RuntimeError(f"{name} seed {job.seed}: meta.json is not this job's")
            if not np.array_equal(render.object_id, first):
                raise RuntimeError(f"{name} seed {job.seed}: object id differs within {name}")
            knobs = render.meta["integrator"]
            if (
                knobs["chain"] != "row"
                or knobs["two_sided"] is not False
                or knobs["mesh_ghost"] != options.get("mesh_ghost", "off")
            ):
                raise RuntimeError(f"{name} seed {job.seed}: integrator knobs {knobs}")
            built = render.meta["scene"]
            if (options["spheres"] == "mesh") != bool(built) or (
                built and built["replaced_object_ids"] != [0, 1, 2]
            ):
                raise RuntimeError(f"{name} seed {job.seed}: scene record {built}")
            wall[name].append(float(render.meta["wall_seconds"]))
            # Diffuse draws per pixel per pass (SPEC §2), averaged over the image.
            k_rate[name].append(float(np.mean(render.k_consumed)) / render.passes)
        digests = {hashlib.sha256(r.sum.tobytes()).hexdigest() for r in rendered}
        distinct[name] = len(digests)
        if len(digests) != len(rendered):
            raise RuntimeError(f"{name}: {len(digests)} distinct renders of {len(rendered)}")
    median_wall = {name: float(np.median(w)) for name, w in wall.items()}
    return {
        "count": sum(len(r) for r in renders.values()),
        "distinct": distinct,
        "wall_seconds_total": float(sum(sum(w) for w in wall.values())),
        "wall_seconds_median": median_wall,
        "wall_ratio_to_mesh_off": {
            name: median_wall[name] / median_wall[NEGATIVE] for name in median_wall
        },
        "k_per_pixel_per_pass": {
            name: {"mean": float(np.mean(v)), "sd": float(np.std(v, ddof=1))}
            for name, v in k_rate.items()
        },
    }


def common_id_map(maps: Mapping[str, np.ndarray]) -> tuple[np.ndarray, dict[str, int]]:
    """Pixels whose object id is the same in every configuration keep it; the rest get -1.

    Also returns, per configuration, the number of pixels whose id differs from the common map
    (sphere silhouettes that differ between analytic and mesh spheres).
    """
    stack = np.stack(list(maps.values()))
    agree = np.all(stack == stack[0], axis=0)
    common = np.where(agree, stack[0], -1).astype(np.int32)
    return common, {name: int(np.count_nonzero(m != common)) for name, m in maps.items()}


def key_family(keys: Sequence[str]) -> list[str]:
    """F (README): the diffuse realization-free family plus the sphere region means."""
    family = metrics.realization_free_key_family(metrics.diffuse_key_family(keys))
    family += [f"r{r}.mean.{c}" for r in SPHERE_MEAN_REGIONS for c in "RGB"]
    missing = [key for key in family if key not in keys]
    if missing:
        raise RuntimeError(f"keys missing from the measurement: {missing}")
    return family


def separated_keys(a: list[dict], b: list[dict], keys: Sequence[str]) -> list[str]:
    """The keys on which every value of ``a`` lies above, or below, every value of ``b``."""
    out = []
    for key in keys:
        xs = [run[key] for run in a]
        ys = [run[key] for run in b]
        if min(xs) > max(ys) or max(xs) < min(ys):
            out.append(key)
    return out


def key_class(key: str) -> str:
    """'mean', 'structure_std' or 'global' (README, Estimation)."""
    if key.startswith("all."):
        return "global"
    if key.endswith(".structure_std"):
        return "structure_std"
    return "mean"


def residuals(m_x, m_ref, m_neg):
    """f = (m_X - m_R) / (m_N - m_R) per key, along the last axis. Dimensionless."""
    return (m_x - m_ref) / (m_neg - m_ref)


def rho(m_x, m_ref, m_neg):
    """rho_X = median over keys of |f|."""
    return jnp.median(jnp.abs(residuals(m_x, m_ref, m_neg)), axis=-1)


def rho_floor(m_neg, m_exact, m_ref):
    """rho_mesh = median over keys of |m_N - m_E| / |m_N - m_R|."""
    return jnp.median(jnp.abs(m_neg - m_exact) / jnp.abs(m_neg - m_ref), axis=-1)


def bootstrap_means(values: np.ndarray, idx: np.ndarray) -> jnp.ndarray:
    """(B, K) means over resampled pairs: ``values`` (pairs, K), ``idx`` (B, pairs)."""
    v = jnp.asarray(values)
    chunks = [
        jnp.take(v, jnp.asarray(idx[start : start + BOOTSTRAP_CHUNK]), axis=0).mean(axis=1)
        for start in range(0, idx.shape[0], BOOTSTRAP_CHUNK)
    ]
    return jnp.concatenate(chunks)


def statistics(runs: Mapping[str, list[dict[str, float]]], keys: Sequence[str]) -> dict[str, Any]:
    """The observed decision statistics on ``keys`` (= G) and their bootstrap distributions.

    Pairs are resampled with replacement within each configuration, independently, in
    ``runs`` order, with indices from ``numpy.random.default_rng(BOOTSTRAP_SEED)``. G is fixed.
    """
    values = {
        name: np.array([[run[k] for k in keys] for run in runs[name]], dtype=np.float64)
        for name in runs
    }
    observed = {name: jnp.asarray(v.mean(axis=0)) for name, v in values.items()}
    rng = np.random.default_rng(BOOTSTRAP_SEED)
    boot = {}
    for name, v in values.items():
        idx = rng.integers(0, v.shape[0], size=(BOOTSTRAP_RESAMPLES, v.shape[0]))
        boot[name] = bootstrap_means(v, idx)
    if bool(jnp.any(boot[NEGATIVE] == boot[REFERENCE])):
        raise RuntimeError("a bootstrap resample has a zero ghost gap on a key of G")

    def stats(m: Mapping[str, Any]) -> dict[str, Any]:
        out = {
            "rho": {name: rho(m[name], m[REFERENCE], m[NEGATIVE]) for name in runs},
            "rho_mesh": rho_floor(m[NEGATIVE], m[EXACT], m[REFERENCE]),
            "signed": {},
            "overghost_share": {},
        }
        for name in runs:
            f = residuals(m[name], m[REFERENCE], m[NEGATIVE])
            out["signed"][name] = jnp.median(f, axis=-1)
            out["overghost_share"][name] = jnp.mean(f < 0.0, axis=-1)
        return out

    return {"observed": observed, "point": stats(observed), "boot": stats(boot)}


def quantile(samples, q: float) -> float:
    return float(np.quantile(np.asarray(samples), q))


def interval(samples) -> list[float]:
    return [quantile(samples, q) for q in ESTIMATION_QUANTILES]


def by_class(
    observed: Mapping[str, Any], keys: Sequence[str], name: str
) -> dict[str, float | None]:
    """rho of one configuration over the keys of G in each class; None for an empty class."""
    f = np.abs(np.asarray(residuals(observed[name], observed[REFERENCE], observed[NEGATIVE])))
    out: dict[str, float | None] = {}
    for cls in ("mean", "structure_std", "global"):
        members = [i for i, key in enumerate(keys) if key_class(key) == cls]
        out[cls] = float(np.median(f[members])) if members else None
    return out


def decide(
    h1: Mapping[str, Any],
    h3: Mapping[str, Any],
    stats: Mapping[str, Any] | None,
    candidates: Sequence[str],
    smoke: bool,
) -> dict[str, Any]:
    """The verdicts of H1 to H4 and the artist decision (README, Hypothesis and Decision)."""
    level = SIGNIFICANCE / len(candidates)
    decisions: dict[str, Any] = {"candidate_level": level}
    if smoke:
        decisions["h1"] = decisions["h2"] = decisions["h3"] = "inconclusive (smoke)"
    else:
        for key, fam in (("h1", h1), ("h3", h3)):
            if not fam["powered"]:
                decisions[key] = "inconclusive (underpowered)"
        if "h1" not in decisions:
            decisions["h1"] = "supported" if h1["rejected_keys"] else "refuted"
        if "h3" not in decisions:
            decisions["h3"] = "supported" if not h3["rejected_keys"] else "refuted"
    if stats is None:
        if not smoke:
            decisions["h2"] = "inconclusive (H1 not supported)"
        floor = {"rho_mesh": None, "upper": None}
    else:
        upper = quantile(stats["boot"]["rho_mesh"], 1.0 - SIGNIFICANCE)
        floor = {"rho_mesh": float(stats["point"]["rho_mesh"]), "upper": upper}
        if not smoke:
            decisions["h2"] = "supported" if upper < 1.0 else "refuted"
    decisions["floor"] = floor
    per: dict[str, dict[str, Any]] = {}
    for candidate in candidates:
        name = configuration(candidate)
        entry: dict[str, Any] = {}
        if stats is not None:
            rho_b = np.asarray(stats["boot"]["rho"][name])
            diff_b = rho_b - np.asarray(stats["boot"]["rho_mesh"])
            entry = {
                "rho": float(stats["point"]["rho"][name]),
                "rho_upper": quantile(rho_b, 1.0 - level),
                "rho_minus_floor": float(stats["point"]["rho"][name] - stats["point"]["rho_mesh"]),
                "rho_minus_floor_lower": quantile(diff_b, level),
                "signed_median_f": float(stats["point"]["signed"][name]),
                "signed_median_f_interval": interval(stats["boot"]["signed"][name]),
                "overghost_share": float(stats["point"]["overghost_share"][name]),
            }
            entry["recovers"] = entry["rho_upper"] < 1.0
            entry["at_floor"] = entry["rho_minus_floor_lower"] <= 0.0
        if smoke:
            outcome = "inconclusive (smoke)"
        elif stats is None:
            outcome = "inconclusive (H1 not supported)"
        elif decisions["h3"] != "supported":
            outcome = f"inconclusive (H3 {decisions['h3']})"
        elif not entry["recovers"]:
            outcome = "no-go"
        elif decisions["h2"] == "refuted":
            outcome = "inconclusive (H2 refuted)"
        else:
            outcome = "go" if entry["at_floor"] else "partial"
        entry["outcome"] = outcome
        per[candidate] = entry
    decisions["candidates"] = per

    def verdict(candidate: str, predicted_go: bool, sign: str | None = None) -> str:
        outcome = per[candidate]["outcome"]
        if outcome not in ("go", "partial", "no-go"):
            return outcome
        if (outcome == "go") != predicted_go:
            return "refuted"
        if sign == "negative":
            lo, hi = per[candidate]["signed_median_f_interval"]
            if lo > 0.0:
                return "refuted"
            if hi >= 0.0:
                return "inconclusive (signed median f interval contains 0)"
        return "supported"

    decisions["h4a_bounding_sphere"] = verdict("bounding_sphere", True)
    decisions["h4b_homothety"] = verdict("homothety", False)
    decisions["h4c_angular_dilation"] = verdict("angular_dilation", False, "negative")
    decisions["h4d_sdf_step"] = verdict("sdf_step", False)
    go = [c for c in candidates if per[c]["outcome"] == "go"]
    decisions["go"] = go
    decisions["recommended"] = (
        min(go, key=lambda c: (per[c]["rho"], candidates.index(c))) if go else None
    )
    pairwise: dict[str, list[float]] = {}
    if stats is not None:
        for i, a in enumerate(go):
            for b in go[i + 1 :]:
                diff = np.asarray(stats["boot"]["rho"][configuration(a)]) - np.asarray(
                    stats["boot"]["rho"][configuration(b)]
                )
                pairwise[f"{a} - {b}"] = interval(diff)
    decisions["go_pairwise_rho_difference_interval"] = pairwise
    return decisions


def write_figures(
    out_dir: Path, previews: Mapping[str, np.ndarray], order: Sequence[str]
) -> dict[str, Any]:
    """fig_grid.png (module docstring)."""
    io.write_png(
        out_dir / "fig_grid.png", report.mosaic([previews[n] for n in order], FIGURE_COLUMNS)
    )
    return {
        "fig_grid.png": {
            "order": list(order),
            "columns": FIGURE_COLUMNS,
            "content": "display bytes of pair 0 (both halves summed, SPEC §7)",
        }
    }


def _fmt(x: float | None, spec: str = ".4g") -> str:
    return "None" if x is None else format(x, spec)


def _family_line(title: str, fam: Mapping[str, Any]) -> str:
    rejected = fam["rejected_keys"]
    largest = report.format_largest(fam["largest_abs_cohen_d"])
    smallest = min(fam["pvalues"].values())
    return (
        f"{title}: {fam['comparison']}: alpha {fam['alpha']:.4g}, powered {fam['powered']}, "
        f"rejected {'None' if rejected is None else len(rejected)} of {fam['n_keys']}, "
        f"smallest p {smallest:.4g}, largest |d| {largest}"
    )


def print_tables(results: Mapping[str, Any], say: Callable[[str], None]) -> None:
    """The README Results tables, from results.json."""
    regions = results["regions"]
    say(f"measured regions {regions['measured']}; silhouette pixels {regions['silhouette_pixels']}")
    say(f"F ({len(results['family'])} keys); G ({len(results['ghost_sensitive_keys'])} keys)")
    say("Table 1. Mean +- sd over pairs of every key of F, per configuration")
    for name, keys in results["summary"].items():
        cells = [f"{k} {v['mean']:.4g}+-{v['sd']:.2g}" for k, v in keys.items()]
        say(f"  {name}: " + "; ".join(cells))
    say("Table 2. Family tests on F (Holm)")
    for title in ("h1", "h3", "mesh_floor"):
        say("  " + _family_line(title.upper(), results[title]))
    for candidate, fams in results["companions"].items():
        for label, fam in fams.items():
            say("  " + _family_line(f"{candidate} {label}", fam))
    say("Table 3. rho (median fraction of the ghost gap left), with 99% intervals")
    for name, entry in results["rho"].items():
        say(
            f"  {name}: rho {_fmt(entry['rho'])} {[_fmt(x) for x in entry['interval']]}; "
            f"signed median f {_fmt(entry['signed_median_f'])}; overghost share "
            f"{_fmt(entry['overghost_share'])}; by class {entry['by_class']}"
        )
    decisions = results["decisions"]
    floor = decisions["floor"]
    say(f"  rho_mesh {_fmt(floor['rho_mesh'])}, one-sided upper bound {_fmt(floor['upper'])}")
    say(f"Table 4. Candidates, bounds at level {decisions['candidate_level']:.4g}")
    for candidate, entry in decisions["candidates"].items():
        say(
            f"  {candidate}: rho {_fmt(entry.get('rho'))}, upper {_fmt(entry.get('rho_upper'))}; "
            f"rho - rho_mesh {_fmt(entry.get('rho_minus_floor'))}, lower "
            f"{_fmt(entry.get('rho_minus_floor_lower'))}; outcome {entry['outcome']}"
        )
    say("Table 5. f per key of G")
    for name, entry in results["rho"].items():
        cells = [f"{k} {_fmt(v, '+.3f')}" for k, v in entry["f_by_key"].items()]
        say(f"  {name}: " + "; ".join(cells))
    renders = results["renders"]
    say(
        f"Table 6. renders {renders['count']}, distinct {renders['distinct']}, total wall "
        f"{renders['wall_seconds_total']:.1f} s"
    )
    say(f"  median wall s {renders['wall_seconds_median']}")
    say(f"  ratio to mesh_off {renders['wall_ratio_to_mesh_off']}")
    say(f"  K per pixel per pass {renders['k_per_pixel_per_pass']}")
    say(f"  module_sha256 {results['module_sha256'][:16]}")
    say("Table 7. Decisions")
    for key in (
        "h1",
        "h2",
        "h3",
        "h4a_bounding_sphere",
        "h4b_homothety",
        "h4c_angular_dilation",
        "h4d_sdf_step",
    ):
        say(f"  {key}: {decisions[key]}")
    say(f"  go {decisions['go']}; recommended {decisions['recommended']}")


def run(render: ModuleType, smoke: bool, out_dir: Path, say: Callable[[str], None]) -> dict:
    jobs = render.jobs_module
    candidates = list(CANDIDATES)
    ensembles = render.experiment_ensembles(smoke)
    check_design(jobs, ensembles, smoke)
    digest = render.module_sha256()
    renders = {name: [render.load(job, digest) for job in e] for name, e in ensembles.items()}
    bookkeeping = check_renders(ensembles, renders, digest)
    common, silhouettes = common_id_map({name: r[0].object_id for name, r in renders.items()})
    measure_map = report.diffuse_only(common, MEASURED_IDS)
    masks = metrics.region_masks(measure_map, metrics.HIGHPASS_SIZE // 2)
    measured = sorted(int(r) for r in masks)

    first = renders[REFERENCE]
    passes = first[0].passes
    # metrics.measure needs a reference display image for pattern_corr and block_rmse, which are
    # not in F; pair 0 of the reference configuration serves.
    ref8 = io.smallpaint_display(first[0].sum + first[1].sum, 2 * passes)
    runs: dict[str, list[dict[str, float]]] = {}
    previews: dict[str, np.ndarray] = {}
    for name, rendered in renders.items():
        runs[name] = [
            metrics.measure(a.sum, b.sum, passes, ref8, measure_map)
            for a, b in zip(rendered[0::2], rendered[1::2], strict=True)
        ]
        previews[name] = io.smallpaint_display(rendered[0].sum + rendered[1].sum, 2 * passes)
    family = key_family(list(runs[REFERENCE][0]))

    def compare(a: str, b: str, alpha: float) -> dict[str, Any]:
        return report.family_test(runs[a], runs[b], family, alpha, labels=(a, b))

    h1 = compare(NEGATIVE, REFERENCE, SIGNIFICANCE)
    h3 = compare(REPLICATE, REFERENCE, SIGNIFICANCE)
    mesh_floor = compare(NEGATIVE, EXACT, SIGNIFICANCE)
    level = SIGNIFICANCE / len(candidates)
    companions = {
        c: {
            "vs_reference": compare(configuration(c), REFERENCE, level),
            "vs_negative": compare(configuration(c), NEGATIVE, level),
        }
        for c in candidates
    }
    # G: the keys on which the negative control is separated from the reference (H1). A smoke
    # run is underpowered (rejected_keys None); to exercise the code only, it uses the keys of F
    # on which every pair of the negative control lies on one side of every pair of the reference.
    sensitive = (
        separated_keys(runs[NEGATIVE], runs[REFERENCE], family)
        if smoke
        else list(h1["rejected_keys"] or [])
    )
    stats = statistics(runs, sensitive) if sensitive else None
    decisions = decide(h1, h3, stats, candidates, smoke)

    rho_table: dict[str, Any] = {}
    if stats is not None:
        for name in runs:
            rho_table[name] = {
                "rho": float(stats["point"]["rho"][name]),
                "interval": interval(stats["boot"]["rho"][name]),
                "signed_median_f": float(stats["point"]["signed"][name]),
                "signed_median_f_interval": interval(stats["boot"]["signed"][name]),
                "overghost_share": float(stats["point"]["overghost_share"][name]),
                "by_class": by_class(stats["observed"], sensitive, name),
                "f_by_key": dict(
                    zip(
                        sensitive,
                        (
                            float(x)
                            for x in residuals(
                                stats["observed"][name],
                                stats["observed"][REFERENCE],
                                stats["observed"][NEGATIVE],
                            )
                        ),
                        strict=True,
                    )
                ),
            }
    figures = write_figures(out_dir, previews, list(ensembles))
    results = {
        "smoke": smoke,
        "design": {
            name: {
                "options": jobs.DESIGN[name],
                "seeds": [e[0].seed, e[-1].seed],
                "size": dict(e[0].options)["size"],
                "passes": dict(e[0].options)["passes"],
                "pairs": len(e) // 2,
            }
            for name, e in ensembles.items()
        },
        "module_sha256": digest,
        "renders": bookkeeping,
        "regions": {
            "measured": measured,
            "pixels": {f"r{r}": int(np.count_nonzero(np.asarray(m))) for r, m in masks.items()},
            "silhouette_pixels": silhouettes,
        },
        "family": family,
        "ghost_sensitive_keys": sensitive,
        "summary": report.summary_table(runs, family),
        "effect_vs_reference": {
            name: ensemble.effect_summary(runs[name], runs[REFERENCE], family)
            for name in runs
            if name != REFERENCE
        },
        "h1": h1,
        "h3": h3,
        "mesh_floor": mesh_floor,
        "companions": companions,
        "rho": rho_table,
        "rho_mesh": None
        if stats is None
        else {
            "rho": float(stats["point"]["rho_mesh"]),
            "interval": interval(stats["boot"]["rho_mesh"]),
        },
        "decisions": decisions,
        "figures": figures,
    }
    report.write_results_json(out_dir / "results.json", results)
    print_tables(results, say)
    return results


def main(argv: list[str] | None = None) -> int:
    parser = argparse.ArgumentParser(description=__doc__.splitlines()[0])
    parser.add_argument("--smoke", action="store_true", help="analyse the smoke renders")
    parser.add_argument(
        "--out-dir", type=Path, default=EXP_DIR, help="where results.json and figures go"
    )
    args = parser.parse_args(argv)
    if args.smoke and args.out_dir.resolve() == EXP_DIR:
        parser.error("--smoke needs --out-dir outside the experiment directory")
    args.out_dir.mkdir(parents=True, exist_ok=True)
    render = _load_file("mesh_ghost_render", EXP_DIR / "render.py")

    def say(line: str) -> None:
        print((SMOKE_PREFIX if args.smoke else "") + line, flush=True)

    run(render, args.smoke, args.out_dir, say)
    return 0


if __name__ == "__main__":
    raise SystemExit(main())
```
