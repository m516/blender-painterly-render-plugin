# T6.7 — Closure SVM nodes (Diffuse, Glossy, Glass, Refraction, Transparent and Principled BSDF, Background, Mix and Add Shader), the BSDF lookup tables and the painterly closure collector
Milestone: M6a · Depends on: T3.1, T3.2, T3.3, T6.1, T6.2, T6.3, T6.4, T6.5, T6.6 · Parallel-safe: no

## Goal
After this card:
- The generated `svm_eval_nodes()` (`cycles_svm`, T6.3) dispatches four more cases: `NODE_CLOSURE_BSDF`,
  `NODE_CLOSURE_BACKGROUND`, `NODE_CLOSURE_WEIGHT` and `NODE_MIX_CLOSURE` (`kernel/svm/svm.h:137-176`). Their evaluators are
  in `kernel/svm/closure.h`, which T6.5 vendored whole with every `kernel/closure/*.h`. With T6.5's three emission cases,
  every closure that a surface BSDF node, Emission, Background, Mix Shader or Add Shader emits now runs.
- `cycles_scene` (T6.4) gains the closure node classes as 57 fragments of `scene/shader_nodes.cpp`: `BsdfBaseNode`,
  `BsdfNode`, and the node types `diffuse_bsdf`, `glossy_bsdf`, `glass_bsdf`, `refraction_bsdf`, `transparent_bsdf`,
  `principled_bsdf`, `background_shader`, `add_closure` and `mix_closure`, each with every definition it has upstream.
- Cycles' BSDF lookup tables reach the kernel, with upstream's code:
  - `scene/shader.tables`, `scene/tables.h` and `util/list.h` are vendored. `LookupTables` is assembled from 6 fragments of
    `scene/tables.cpp` into a new generated unit `tables`;
  - the shim `ShaderManager` computes the thin-film table in its constructor (`scene/shader.cpp:932-993, 1022`) and gains
    `device_update_lookup_tables()`, which uploads the nine BSDF tables and the thin-film table into
    `DeviceScene::lookup_table` (`scene/shader.cpp:714-729, 1025-1036`). `Scene` owns a `LookupTables`;
  - `PainterlyShaderManager::bind_kernel_globals()` points a `KernelGlobalsCPU` at the byte code, the shader flags and the
    tables.
- `PainterlyShaderManager` sets `caustics_reflective` and `caustics_refractive` to Cycles' defaults (true).
- `src/painterly/kernel/svm/collect.h`, the painterly closure collector: `painterly_svm_collect()` maps the closures that the
  SVM wrote into `ShaderData` to a `PainterlySvmMaterial`, a list of painterly lobes (`KernelPainterlyLobe`: diffuse, mirror,
  glass, transparent) plus an emission colour (SPEC §6), by the closure policy of "Decisions". It also defines the node
  feature masks of painterly's shader evaluations.
- Doctests build Diffuse, Glossy, Glass, Refraction, Transparent, Emission, Background, Mix Shader, Add Shader and Principled
  BSDF graphs, compile them with `PainterlyShaderManager`, evaluate them with `svm_eval_nodes()`, collect them, and compare
  the lobes, weights and emission exactly with values derived from upstream code. They also compare the uploaded tables
  with `scene/shader.tables`.
- `THIRD_PARTY_NOTICES.md` covers the BSD-3-Clause (Open Shading Language) and MIT (appleseed) code in the closure headers
  that T6.5 vendored.

M6a builds Cycles' shader VM as standalone vendored libraries. Nothing in the painterly engine uses these yet: M6b wires
`painterly_svm_collect()` into `painterly_trace_pixel`, `PainterlyScene` and the Blender sync.

## Decisions (Opus, 2026-10-09)
1. **Scope.**
   - Kernel: the four cases. `NODE_CLOSURE_BSDF` dispatches every closure type of `svm_node_closure_bsdf()`, so with them the
     kernel side of every surface BSDF node is complete.
   - Host: the node classes of the nine node types in "Goal", and their bases `BsdfBaseNode` and `BsdfNode`. `EmissionNode`
     and `MixClosureWeightNode` are T6.4's. Every other closure node class (Metallic, Sheen, Translucent, Toon, Subsurface
     Scattering, Hair, Ray Portal, Holdout, the volume nodes) is left to M6b's node ports. The BSDF classes among them need
     only their own fragments; Holdout and the volume nodes also need their cases (`NODE_CLOSURE_HOLDOUT`,
     `kernel/svm/svm.h:328-331`; `NODE_CLOSURE_VOLUME`, `NODE_VOLUME_COEFFICIENTS`, `NODE_PRINCIPLED_VOLUME`, `:338-366`).
   - The doctests compile node graphs, as T6.5's do, instead of hand-encoding byte code: the closure nodes' byte code is long
     (`SVMNodeClosureBsdf` and a data struct per closure), and compiling is the path that M6b uses.
2. **The lookup tables are a separate update step.** Upstream uploads them inside `ShaderManager::device_update_common`
   (`scene/shader.cpp:714-729`), from the static arrays of `scene/shader.tables`, which only `scene/shader.cpp` includes
   (`:28`).
   - The arrays are `static` (internal linkage, 24,096 floats in all). The uploaded `lookup_table` (the nine BSDF tables
     and the thin-film table computed from `table_thin_film_cmf`, also 3072 floats) has 24,320, because `add_table()`
     rounds each table up to a multiple of `TABLE_CHUNK_SIZE` = 256 (`scene/tables.cpp:71`, `scene/tables.h:16`).
   - `PainterlyShaderManager` is header-only (T6.5 "Decisions" 4): if it included `scene/shader.tables`, every translation
     unit would get its own copies of the `static` arrays, and the inline `device_update_common` would use a different
     array in each, which breaks the one-definition rule;
     `ensure_bsdf_table()` also identifies a table by its address (`scene/shader.cpp:1030-1035`). So the upload stays where
     upstream has it, in the one translation unit `scene/shader.cpp` (here the shim), as the `ShaderManager` member
     `device_update_lookup_tables()`, whose body is `:714-729` verbatim. `device_free_lookup_tables()` holds `:752-757`.
   - `device_update_common` does not call it; the caller runs it after `device_update_post()`. T6.5's doctests compile
     hundreds of graphs, none of which reads a table. With the upload inside every device update, T6.5's doctest "Math
     through compiler and SVM equals an independent reference" took 12.7 s instead of 1.1 s in Opus's prototype (7.3 s of it
     system time, reallocating the table array), past the 10 s of CLAUDE.md rule 6. This revises T6.5's note "A card that
     uploads the BSDF lookup tables extends `device_update_common`". M6b's `PainterlyScene::device_update()` calls
     `device_update_pre()`, `device_update_post()` and `device_update_lookup_tables()`, in this order.
   - `PainterlyShaderManager::device_free()` frees the tables, as upstream's `device_free_common` does.
     `device_update_specific()` calls `device_free()` first (`scene/svm.cpp:79`), so after `device_update_post()` no table is
     registered, and the next `device_update_lookup_tables()` adds them again at the same offsets.
   - `Scene` owns its `LookupTables` (`scene/scene.h:143`, created in `Scene::Scene`, `scene/scene.cpp:75`). The shim
     `~Scene` calls `shader_manager->device_free()`, as upstream's `free_memory()` does before it deletes the managers
     (`scene/scene.cpp:85-90, 143, 157-161`): `~LookupTables` asserts that no table is left (`scene/tables.cpp:22-25`).
   - `LookupTables::device_update()` and `device_free()` (`scene/tables.cpp:27-51`) need a Device and scene statistics, and
     are not extracted. Painterly's `DeviceScene` holds host arrays, so `add_table()` already writes the entries where the
     kernel reads them.
   - The thin-film table is computed in the `ShaderManager` constructor from the XYZ-to-RGB matrix, as upstream does
     (`scene/shader.cpp:1022`); the shim constructor already builds that matrix (T6.4).
3. **Caustics.** Cycles' `Integrator::device_update` writes `kintegrator->caustics_reflective` and `caustics_refractive` from
   the sockets "Reflective Caustics" and "Refractive Caustics", whose defaults are true (`scene/integrator.cpp:119-120,
   267-268`). Painterly has no Cycles `Integrator`, so `PainterlyShaderManager::device_update_common` sets both to true. Under
   `__CAUSTICS_TRICKS__` (`kernel/features.h:138`) the closure evaluators drop glossy, glass and refraction closures when a
   flag is false and the ray has diffuse visibility (`kernel/svm/closure.h:280-285, 354-359, 565-571, 669-675, 742-748,
   785-796`). Painterly evaluates with `path_visibility` 0, which keeps every closure anyway; the flags make the result
   independent of that.
4. **Feature masks.** `collect.h` defines the two masks of painterly's evaluations. They are Cycles' definitions, not knobs:
   - surface hit: `KERNEL_FEATURE_NODE_MASK_SURFACE & ~KERNEL_FEATURE_NODE_RAYTRACE`, the value of T6.3's
     `painterly_svm_test_node_feature_mask` (the generated switch leaves out the ray-traced nodes, T6.2). It contains
     `KERNEL_FEATURE_NODE_BSDF`, `KERNEL_FEATURE_NODE_EMISSION` and `KERNEL_FEATURE_NODE_VORONOI_EXTRA`; a `static_assert`
     says so;
   - miss: `KERNEL_FEATURE_NODE_MASK_SURFACE_BACKGROUND`, as Cycles' background evaluation
     (`kernel/integrator/shade_background.h:86`). With it, `NODE_CLOSURE_BSDF` allocates no BSDF.
5. **The closure policy.** SPEC §6 has four lobe kinds; Cycles has about 40 closure types. The collector maps each closure
   by Cycles' own categories (`kernel/svm/types.h:535-574`), tested in this order (`painterly_svm_lobe_kind()`):

   | Cycles category (macro) | Closures (node) | Painterly lobe | Lobe weight |
   |---|---|---|---|
   | `CLOSURE_IS_BSDF_DIFFUSE`, `CLOSURE_IS_BSSRDF` | diffuse, Oren-Nayar (Diffuse BSDF), Burley, diffuse ramp, sheen (Principled Sheen, Sheen BSDF), diffuse toon, translucent; Burley and random-walk BSSRDF (Principled Subsurface, Subsurface Scattering) | diffuse | closure weight |
   | `CLOSURE_IS_GLASS`, `CLOSURE_IS_REFRACTION` | GGX, multiscatter GGX and Beckmann glass (Glass BSDF, Principled Transmission); GGX and Beckmann refraction (Refraction BSDF) | glass, with the closure's IOR | closure weight times the Fresnel payload's transmission tint (none for refraction) |
   | `CLOSURE_IS_BSDF_TRANSMISSION`, `CLOSURE_IS_BSDF_TRANSPARENT` | thin-glass transmission (Principled Thin Wall), hair transmission; transparent (Transparent BSDF, Principled Alpha) | transparent | closure weight |
   | `CLOSURE_IS_BSDF_GLOSSY` | microfacet reflection (Glossy BSDF, Principled specular, coat and metallic, Metallic BSDF, thin-glass reflection), Ashikhmin-Shirley, velvet, glossy toon, phong ramp, hair reflection, Chiang and Huang hair | mirror | closure weight; for a microfacet closure times the Fresnel payload's reflection colour at normal incidence |
   | anything else | ray portal, holdout, volume closures | none: counted in `num_dropped` | — |

   - Emission is not a lobe. If `SD_EMISSION` is set, `material.emission` is `ShaderData::closure_emission_background`
     (Emission, Background and Principled Emission write it, `kernel/closure/emissive.h:29-38`); otherwise it is zero.
   - Glass and Metallic carry their colour in the Fresnel payload, not in the closure weight: Glass BSDF's weight is the mix
     weight and its Color is the transmission tint (`kernel/svm/closure.h:823-825`); a Principled metallic layer has weight 1
     and its f0 is Base Color (`:320-352`). The collector reads the payload: `painterly_svm_reflection_color()` (DIELECTRIC:
     `F0_from_ior(ior)`; DIELECTRIC_TINT: that times the reflection tint; CONDUCTOR: `fresnel_conductor(1, ior)`;
     GENERALIZED_SCHLICK: f0 times the reflection tint; F82_TINT: f0; NONE: 1) and `painterly_svm_transmission_color()`
     (DIELECTRIC_TINT and GENERALIZED_SCHLICK: the transmission tint; otherwise 1). The payload sits at the end of the
     closure array (`kernel/closure/alloc.h:34-53`), so the collector must read the `ShaderData` that the SVM wrote, never a
     copy.
   - Painterly mirrors and glass have no Fresnel (SPEC §6). So the mirror colour is the payload's reflectance at normal
     incidence, and the glass lobe neither reflects nor weighs by 1 − F: a white Glass BSDF is smallpaint's glass with unit
     weight and its IOR (SPEC §9). Thin-film iridescence is not represented.
   - BSSRDF becomes its diffuse limit: painterly has no subsurface transport, and Cycles itself replaces a BSSRDF by a
     diffuse closure for radii below `BSSRDF_MIN_RADIUS` (`kernel/closure/bssrdf.h:322-336`). Translucent light leaves on the
     far side in Cycles; the painterly diffuse lobe reflects it on the near side.
   - `CLOSURE_NONE_ID` slots are skipped: Cycles leaves them when a setup gives up or moves the weight elsewhere
     (`kernel/closure/bssrdf.h:347-350`, `kernel/closure/bsdf_sheen.h:43-48`).
   - The weight of each lobe is computed in double: the product of two floats is exact in double (at most 48 significand
     bits of 53).
   - If no closure gives a lobe, the material has one diffuse lobe of weight 0: smallpaint's light is a diffuse sphere with
     `cl = 0` whose path keeps bouncing (SPEC §6, "Emitters are surfaces"), and a painterly material has at least one lobe.
   - The policy is Opus's. Changing it needs an Opus decision.
6. **The evaluation contract** (the header comment of `collect.h`; M6b's `painterly_trace_pixel` keeps it):
   - `svm_eval_nodes<painterly_svm_surface_feature_mask, SHADER_TYPE_SURFACE>` at a surface hit, or
     `<painterly_svm_background_feature_mask, SHADER_TYPE_SURFACE>` on a miss, with `path_visibility` 0 and `path_flag` 0.
     `bsdf_alloc_maybe_emission()` then allocates closures (`kernel/closure/alloc.h:96-118`), and no `PATH_RAY_TERMINATE`
     limits them (`kernel/closure/bsdf_transparent.h:43-48`);
   - `ShaderData` prepared as `surface_shader_eval()` prepares it (`num_closure` 0, `num_closure_left` the closure budget,
     `lcg_state` 0), with `sd->flag` from the shader's `KernelShader` and `SD_BACKFACING` clear. The glass lobe decides
     inside and outside itself (SPEC §6, "Triangles"), so its IOR must be the authored one, which Cycles inverts on back
     faces (`kernel/svm/closure.h:761, 816`).
7. **Exact expected values.** As in T6.3-T6.6, no doctest has a tolerance.
   - Every input is dyadic, so closure weights (Color × mix weight × Fac) are exact in float32, and the collector's double
     products are exact.
   - The one value that depends on a table, the diffuse weight of a Principled BSDF (Base Color × (1 − F)), is recomputed
     from the raw `scene/shader.tables` entries by `reference_lookup_corner()`, which repeats the float32 operations of
     `lookup_table_read_3D` (`kernel/util/lookup_table.h:14-74`) in the same order, at the grid corner that a head-on view
     with Roughness 1 reads. Opus checked that the reference is sensitive: reading `table_ggx_gen_schlick_s` instead changes
     the expected value.
   - `PainterlySvmTrace::other_arrays` counts the lookup-table fetches. It shows which closures read a table, and how often:
     Principled 4, Principled metallic 2, glass 2, multiscatter GGX 4; GGX, refraction and diffuse 0.
   - Materials are compared as text: `describe()` prints each double with `%.17g`, which reads back to the same bits, so two
     descriptions are equal if and only if the materials are, and a failure prints both.
8. **Licences.** T6.5 vendored eleven headers in `kernel/closure/` that are marked `SPDX-License-Identifier: BSD-3-Clause`,
   "Adapted code from Open Shading Language" (copyright Sony Pictures Imageworks Inc., et al. and the Blender Foundation):
   `bsdf_ashikhmin_velvet.h`, `bsdf_burley.h`, `bsdf_diffuse.h`, `bsdf_diffuse_ramp.h`, `bsdf_hair.h`, `bsdf_microfacet.h`,
   `bsdf_phong_ramp.h`, `bsdf_toon.h`, `bsdf_transparent.h`, `bsdf_util.h` and `emissive.h`. It also vendored
   `kernel/closure/bsdf.h`, whose `shift_cos_in()` is marked `SPDX-License-Identifier: MIT`, "Copyright (c) 2019 Francois
   Beaune, The appleseedhq Organization" (`bsdf.h:156-166`). No notice covers them yet. This card runs them, so it adds two

/* ShaderManager::compute_thin_film_table: scene/shader.cpp:932-993, verbatim. */

void ShaderManager::compute_thin_film_table(const Transform &xyz_to_rgb)
{
  /* Our implementation of Thin Film Fresnel is based on
   * "A Practical Extension to Microfacet Theory for the Modeling of Varying Iridescence"
   * by Laurent Belcour and Pascal Barla
   * (https://belcour.github.io/blog/research/publication/2017/05/01/brdf-thin-film.html).
   *
   * The idea there is that for a naive implementation of Thin Film interference, you'd compute
   * the reflectivity for a given wavelength using Airy summation, and then numerically integrate
   * the product of this reflectivity function and the Color Matching Functions of the colorspace
   * you're working in to obtain the RGB (or XYZ) values.
   * However, this integration would require too many evaluations to be practical.
   * Therefore, they reformulate the computation as a rapidly converging series involving the
   * Fourier transform of the CMFs.
   *
   * Specifically, we need to:
   * - Compute the RGB CMFs from the XYZ CMFs using the working color space's XYZ-to-RGB matrix
   * - Resample the RGB CMFs to be parametrized by frequency instead of wavelength as usual
   * - Compute the FFT of the CMFs
   * - Store the result as a LUT
   * - Look up the values for each channel at runtime based on the optical path difference and
   *   phase shift.
   *
   * Computing an FFT here would be annoying, so we'd like to precompute it, but we only know
   * the XYZ-to-RGB matrix at runtime. Luckily, both resampling and FFT are linear operations,
   * so we can precompute the FFT of the resampled XYZ CMFs and then multiply each entry with
   * the XYZ-to-RGB matrix to get the RGB LUT.
   *
   * That's what this function does: We load the precomputed values, convert to RGB, normalize
   * the result to make the DC term equal to 1, and then store that into the final table that's
   * used by the kernel.
   */
  assert(sizeof(table_thin_film_cmf) == 6 * THIN_FILM_TABLE_SIZE * sizeof(float));
  thin_film_table.resize(6 * THIN_FILM_TABLE_SIZE);

  float3 normalization;
  for (int i = 0; i < THIN_FILM_TABLE_SIZE; i++) {
    const float *table_row = table_thin_film_cmf[i];
    /* Load precomputed resampled Fourier-transformed XYZ CMFs. */
    const float3 xyzReal = make_float3(table_row[0], table_row[1], table_row[2]);
    const float3 xyzImag = make_float3(table_row[3], table_row[4], table_row[5]);

    /* Linearly combine precomputed data to produce the RGB equivalents. Works since both
     * resampling and Fourier transformation are linear operations. */
    const float3 rgbReal = transform_direction(&xyz_to_rgb, xyzReal);
    const float3 rgbImag = transform_direction(&xyz_to_rgb, xyzImag);

    /* We normalize all entries by the first element. Since that is the DC component, it normalizes
     * the CMF (in non-Fourier space) to an area of 1. */
    if (i == 0) {
      normalization = 1.0f / rgbReal;
    }

    /* Store in lookup table. */
    thin_film_table[i + 0 * THIN_FILM_TABLE_SIZE] = rgbReal.x * normalization.x;
    thin_film_table[i + 1 * THIN_FILM_TABLE_SIZE] = rgbReal.y * normalization.y;
    thin_film_table[i + 2 * THIN_FILM_TABLE_SIZE] = rgbReal.z * normalization.z;
    thin_film_table[i + 3 * THIN_FILM_TABLE_SIZE] = rgbImag.x * normalization.x;
    thin_film_table[i + 4 * THIN_FILM_TABLE_SIZE] = rgbImag.y * normalization.y;
    thin_film_table[i + 5 * THIN_FILM_TABLE_SIZE] = rgbImag.z * normalization.z;
  }
}

/* ShaderManager::ensure_bsdf_table_impl: scene/shader.cpp:1025-1036, verbatim. */

       * is not a Node and keeps no modified flags. */

                              shader->get_displacement_method() == DISPLACE_BOTH);

      shader->has_surface = output->input("Surface")->link != nullptr;
      shader->has_surface_transparent = false;
      shader->has_surface_raytrace = false;
      shader->has_surface_bssrdf = false;
      shader->has_surface_spatial_varying = false;
      shader->has_volume = output->input("Volume")->link != nullptr;
      shader->has_volume_spatial_varying = false;
      shader->has_volume_attribute_dependency = false;
      shader->has_displacement = output->input("Displacement")->link != nullptr;
      shader->has_bump_from_surface = false;

          shader->has_light_path_node = true;
        }
        else if (node->special_type == SHADER_SPECIAL_TYPE_OUTPUT_AOV) {
          shader->has_aov_output_node = true;
        }
        else if (node->special_type == SHADER_SPECIAL_TYPE_SCENE_TIME) {
          shader->has_time_dependency = true;
        }
      }

      if (shader->reference_count()) {
        has_volumes |= shader->has_volume;
      }

 protected:
  /* SVMShaderManager::device_update_specific (scene/svm.cpp:57-146). */
  void device_update_specific(Device *device,
                              DeviceScene *dscene,
                              Scene *scene,
                              Progress &progress) override
  {
    /* Upstream returns unless need_update() (:62-64), and times and logs the update (:66-70,
     * :74-76, :144-145). Painterly updates every time and keeps no statistics. */
    const int num_shaders = scene->shaders.size();

    /* test if we need to update */
    device_free(device, dscene, scene);

    /* Build all shaders, one after the other: upstream compiles them in parallel on a TaskPool
     * (:81-89), into the same per-shader arrays. */
    vector<array<int>> shader_svm_nodes(num_shaders);
    for (int i = 0; i < num_shaders; i++) {
      device_update_shader(scene, scene->shaders[i], progress, &shader_svm_nodes[i]);
    }

    if (progress.get_cancel()) {
      return;
    }

    /* The global node list contains a jump table (one jump node per shader)
     * followed by the nodes of all shaders. */
    const int jump_node_size = 1 + sizeof(SVMNodeShaderJump) / sizeof(int);
    int svm_nodes_size = num_shaders * jump_node_size;
    for (int i = 0; i < num_shaders; i++) {
      /* Since we're not copying the local jump node, the size ends up lower. */
      svm_nodes_size += shader_svm_nodes[i].size() - jump_node_size;
    }

    /* A host array: resize() where upstream allocates a device_vector (:104). */
    int *svm_nodes = dscene->svm_nodes.resize(svm_nodes_size);

    int node_offset = num_shaders * jump_node_size;
    for (int i = 0; i < num_shaders; i++) {
      Shader *shader = scene->shaders[i];

      /* Upstream clears the shader's modified flags and tags the LightManager for shaders that
       * emit (:110-113). The shim Shader keeps no such flags, and painterly samples no lights
       * (SPEC §6). */

      /* Update the global jump table.
       * Each compiled shader starts with a jump node that has offsets local
       * to the shader, so copy those and add the offset into the global node list. */
      const int base = shader->id * jump_node_size;
      svm_nodes[base + 0] = NODE_SHADER_JUMP;
      *reinterpret_cast<SVMNodeShaderJump *>(&svm_nodes[base + 1]) = SVMNodeShaderJump{
          .offset_surface = shader_svm_nodes[i][1] - jump_node_size + node_offset,
          .offset_volume = shader_svm_nodes[i][2] - jump_node_size + node_offset,
          .offset_displacement = shader_svm_nodes[i][3] - jump_node_size + node_offset};
      node_offset += shader_svm_nodes[i].size() - jump_node_size;
    }

    /* Copy the nodes of each shader into the correct location. */
    int *dst = svm_nodes + num_shaders * jump_node_size;
    for (int i = 0; i < num_shaders; i++) {
      const int shader_size = shader_svm_nodes[i].size() - jump_node_size;

      std::copy_n(&shader_svm_nodes[i][jump_node_size], shader_size, dst);
      dst += shader_size;
    }

    if (progress.get_cancel()) {
      return;
    }

    device_update_common(device, dscene, scene, progress);

    /* Upstream resets its update flags here (:142). */
  }

  /* SVMShaderManager::device_update_shader (scene/svm.cpp:37-55). */
  void device_update_shader(Scene *scene,

  {

      return;

    SVMCompiler compiler(scene, progress);
    compiler.background = (shader == background_shader);
    compiler.compile(shader, *svm_nodes, 0, &summary);

    LOG_DEBUG << "Compilation summary:\n"
              << "Shader name: " << shader->name << "\n"
              << summary.full_report();
  }

  /* ShaderManager::device_update_common (scene/shader.cpp:612-748), reduced to the members of
   * the shim Shader and ShaderManager. */

                            DeviceScene *dscene,
                            Scene *scene,
                            Progress & /*progress*/)
  {
    dscene->shaders.clear();

    if (scene->shaders.empty()) {
      return;

    KernelShader *kshader = dscene->shaders.resize(scene->shaders.size());

    for (Shader *shader : scene->shaders) {
      uint flag = 0;

      /* Left out: SD_MIS_FRONT, SD_MIS_BACK and SD_HAS_EMISSION (:629-641) and

        flag |= SD_HAS_TRANSPARENT_SHADOW;
      }

      if (shader->has_volume) {

        /* todo: this could check more fine grained, to skip useless volumes
         * enclosed inside an opaque bsdf.
         */
        flag |= SD_HAS_TRANSPARENT_SHADOW;

      /* in this case we can assume transparent surface */

        flag |= SD_HAS_ONLY_VOLUME;
      }
      if (shader->has_volume && shader->has_volume_spatial_varying) {

      }
      if (shader->has_volume_attribute_dependency) {
        flag |= SD_NEED_VOLUME_ATTRIBUTES;
      }
      if (shader->has_bssrdf_bump) {
        flag |= SD_HAS_BSSRDF_BUMP;
      }
      if (shader->get_volume_sampling_method() == VOLUME_SAMPLING_EQUIANGULAR) {
        flag |= SD_VOLUME_EQUIANGULAR;
      }
      if (shader->get_volume_sampling_method() == VOLUME_SAMPLING_MULTIPLE_IMPORTANCE) {
        flag |= SD_VOLUME_MIS;
      }
      if (shader->get_volume_interpolation_method() == VOLUME_INTERPOLATION_CUBIC) {
        flag |= SD_VOLUME_CUBIC;
      }
      if (shader->has_bump_from_displacement) {
        flag |= SD_HAS_BUMP_FROM_DISPLACEMENT;
      }
      if (shader->has_bump_from_surface) {
        flag |= SD_HAS_BUMP_FROM_SURFACE;
      }
      if (shader->get_displacement_method() != DISPLACE_BUMP) {
        flag |= SD_HAS_DISPLACEMENT;
      }
      if (shader->get_use_bump_map_correction()) {
        flag |= SD_USE_BUMP_MAP_CORRECTION;
      }

      if (shader->has_light_path_node) {
        flag |= SD_HAS_LIGHT_PATH_NODE;
      }

      /* regular shader. Left out: pass_id, constant_emission and cryptomatte_id (:699-708),
       * which no painterly pass uses; they stay 0. */

     * (kernel/util/colorspace.h:34-37). */

    kfilm->rgb_to_y = make_float4(rgb_to_y);
  }

/* The painterly closure collector (card T6.7). Cycles' SVM writes a shader's closures into
 * ShaderData (kernel/svm/closure.h, kernel/closure/alloc.h); this maps them to painterly lobes
 * and emission (SPEC §6, "Materials are lobe mixtures"). It runs after svm_eval_nodes() and
 * reads ShaderData only: no kernel array, no random number.
 *
 * Contract of the evaluation it reads (M6b's painterly_trace_pixel keeps it):
 * - svm_eval_nodes<painterly_svm_surface_feature_mask, SHADER_TYPE_SURFACE> at a surface hit, or
 *   <painterly_svm_background_feature_mask, SHADER_TYPE_SURFACE> on a miss, with
 *   path_visibility 0 and path_flag 0: bsdf_alloc_maybe_emission() then allocates closures
 *   (kernel/closure/alloc.h:96-118) and no PATH_RAY_TERMINATE limits them
 *   (kernel/closure/bsdf_transparent.h:43-48);
 * - ShaderData prepared as surface_shader_eval() prepares it (num_closure 0, num_closure_left
 *   kernel_data.max_closures, lcg_state 0), and SD_BACKFACING clear: the glass lobe decides
 *   inside and outside itself (SPEC §6), so its IOR must be the authored one that Cycles inverts
 *   on back faces (kernel/svm/closure.h:761, 816);
 * - the collector reads the ShaderData that svm_eval_nodes() wrote, never a copy: a microfacet
 *   closure's Fresnel payload is a pointer into that object's closure array
 *   (kernel/closure/alloc.h:34-53). */

#include "kernel/closure/bsdf_util.h"

 * mask without ray-traced nodes, which the generated svm_eval_nodes() leaves out (card T6.2);
 * a miss uses the mask of Cycles' background evaluation (kernel/integrator/shade_background.h:86).
 * The surface mask allocates BSDF closures, emission and the extra Voronoi features
 * (kernel/svm/closure.h:239-271, kernel/svm/voronoi.h:1151-1177). */
inline constexpr uint painterly_svm_surface_feature_mask = KERNEL_FEATURE_NODE_MASK_SURFACE &
                                                           ~KERNEL_FEATURE_NODE_RAYTRACE;
inline constexpr uint painterly_svm_background_feature_mask =
    KERNEL_FEATURE_NODE_MASK_SURFACE_BACKGROUND;
static_assert((painterly_svm_surface_feature_mask &
               (KERNEL_FEATURE_NODE_BSDF | KERNEL_FEATURE_NODE_EMISSION |
                KERNEL_FEATURE_NODE_VORONOI_EXTRA)) ==
              (KERNEL_FEATURE_NODE_BSDF | KERNEL_FEATURE_NODE_EMISSION |
               KERNEL_FEATURE_NODE_VORONOI_EXTRA));
static_assert((painterly_svm_background_feature_mask & KERNEL_FEATURE_NODE_EMISSION) != 0);

/* The material of one hit, as one SVM evaluation gives it: the lobe list and emission colour of
 * SPEC §6, the per-hit counterpart of KernelPainterlyMaterial. */
struct PainterlySvmMaterial {
  /* One lobe per collected closure, in closure order (at most MAX_CLOSURE). */
  KernelPainterlyLobe lobes[MAX_CLOSURE];
  int num_lobes; /* >= 1 */
  /* ShaderData::closure_emission_background if SD_EMISSION is set, else zero. */
  double3 emission;
  /* Closures that the policy maps to no lobe (painterly_svm_lobe_kind() returns false). */
  int num_dropped;
};

/* The closure policy (Opus decision, card T6.7): the painterly lobe kind of a Cycles closure
 * type, by Cycles' own closure categories (kernel/svm/types.h:535-574). Returns false for a
 * closure that has no painterly lobe.
 * - Diffuse family and BSSRDF -> LOBE_DIFFUSE. The family is CLOSURE_IS_BSDF_DIFFUSE: diffuse,
 *   Oren-Nayar, Burley, diffuse ramp, sheen, diffuse toon, translucent and rough translucent.
 *   Painterly has no subsurface transport; a BSSRDF becomes its diffuse limit, as Cycles itself
 *   falls back to a diffuse closure for radii below BSSRDF_MIN_RADIUS
 *   (kernel/closure/bssrdf.h:322-336). Translucent light leaves on the far side in Cycles; the
 *   painterly diffuse lobe reflects it on the near side.
 * - Microfacet glass and refraction -> LOBE_GLASS (Snell-only, SPEC §6).
 * - Other transmission (thin-glass transmission, hair transmission) and transparent ->
 *   LOBE_TRANSPARENT: they continue without bending the ray.
 * - The glossy family (CLOSURE_IS_BSDF_GLOSSY) -> LOBE_MIRROR.
 * - Ray portal, holdout and volume closures -> no lobe (dropped). */
ccl_device_inline bool painterly_svm_lobe_kind(const ClosureType type, ccl_private int *kind)
{
  if (CLOSURE_IS_BSDF_DIFFUSE(type) || CLOSURE_IS_BSSRDF(type)) {
    *kind = LOBE_DIFFUSE;
    return true;
  }
  if (CLOSURE_IS_GLASS(type) || CLOSURE_IS_REFRACTION(type)) {
    *kind = LOBE_GLASS;
    return true;
  }
  if (CLOSURE_IS_BSDF_TRANSMISSION(type) || CLOSURE_IS_BSDF_TRANSPARENT(type)) {
    *kind = LOBE_TRANSPARENT;
    return true;
  }
  if (CLOSURE_IS_BSDF_GLOSSY(type)) {
    *kind = LOBE_MIRROR;
    return true;
  }
  return false;
}

/* The reflection colour of a microfacet closure: its Fresnel reflectance at normal incidence,
 * from the Fresnel payload. Painterly mirrors have no Fresnel (SPEC §6), so the payload's colour
 * at cos(theta) = 1 tints the lobe. Thin-film iridescence is not represented.
 * - NONE: the colour is already in the closure weight (Glossy BSDF, kernel/svm/closure.h:679;
 *   multiscatter GGX, bsdf_microfacet.h:1025-1036).
 * - DIELECTRIC (Principled coat): F0 of its IOR.
 * - GENERALIZED_SCHLICK (Principled specular): f0 times the reflection tint. f0 is the end of the
 *   mix that starts at normal incidence (bsdf_microfacet.h:299-326).
 * - F82_TINT (Principled metallic, Metallic BSDF): f0 (bsdf_util.h:178-184 at cosi = 1).
 * - CONDUCTOR (Metallic BSDF, physical): fresnel_conductor() at cosi = 1. */
ccl_device_inline Spectrum painterly_svm_reflection_color(const ccl_private MicrofacetBsdf *bsdf)
{
  switch (bsdf->fresnel_type) {
    case MicrofacetFresnel::DIELECTRIC:
      return make_spectrum(F0_from_ior(bsdf->ior));
    case MicrofacetFresnel::DIELECTRIC_TINT:
      return F0_from_ior(bsdf->ior) *
             ((const ccl_private FresnelDielectricTint *)bsdf->fresnel)->reflection_tint;
    case MicrofacetFresnel::CONDUCTOR:
      return fresnel_conductor(1.0f, ((const ccl_private FresnelConductor *)bsdf->fresnel)->ior);
    case MicrofacetFresnel::GENERALIZED_SCHLICK: {
      const ccl_private FresnelGeneralizedSchlick *fresnel =
          (const ccl_private FresnelGeneralizedSchlick *)bsdf->fresnel;
      return fresnel->f0 * fresnel->reflection_tint;
    }
    case MicrofacetFresnel::F82_TINT:
      return ((const ccl_private FresnelF82Tint *)bsdf->fresnel)->f0;
    default:
      return one_spectrum();
  }
}

/* The transmission colour of a microfacet glass: the payload's transmission tint (Glass BSDF:
 * its Color, kernel/svm/closure.h:823-825; Principled transmission: sqrt(Base Color),
 * kernel/svm/closure.h:405-410). Painterly glass is Snell-only with TIR (SPEC §6): it neither
 * reflects nor weighs by 1 - F, so a white Glass BSDF is smallpaint's glass with unit weight. */
ccl_device_inline Spectrum painterly_svm_transmission_color(const ccl_private MicrofacetBsdf *bsdf)
{
  switch (bsdf->fresnel_type) {
    case MicrofacetFresnel::DIELECTRIC_TINT:
      return ((const ccl_private FresnelDielectricTint *)bsdf->fresnel)->transmission_tint;
    case MicrofacetFresnel::GENERALIZED_SCHLICK:
      return ((const ccl_private FresnelGeneralizedSchlick *)bsdf->fresnel)->transmission_tint;
    default:
      return one_spectrum();
  }
}

/* weight * color per channel, in double. Exact: the product of two floats has at most 48
 * significand bits, and double has 53. */
ccl_device_inline double3 painterly_svm_lobe_weight(const Spectrum weight, const Spectrum color)
{
  return make_double3(double(weight.x) * double(color.x),
                      double(weight.y) * double(color.y),
                      double(weight.z) * double(color.z));
}

/* Maps the closures of `sd` to `material` (see the policy above):
 * - each closure in sd->closure[0, num_closure), in order. CLOSURE_NONE_ID slots are skipped:
 *   Cycles leaves them when a setup moves the weight elsewhere or gives up
 *   (kernel/closure/bssrdf.h:347-350, kernel/closure/bsdf_sheen.h:43-48). Fresnel payloads sit
 *   past num_closure (kernel/closure/alloc.h:34-53) and are never read as closures;
 * - diffuse, transparent and non-microfacet glossy lobes take the closure weight; a microfacet
 *   mirror takes weight * painterly_svm_reflection_color(); a glass lobe takes
 *   weight * painterly_svm_transmission_color() and the closure's IOR;
 * - if no closure gives a lobe, one LOBE_DIFFUSE lobe of weight 0: smallpaint's light is a
 *   diffuse sphere with cl = 0 whose path keeps bouncing (SPEC §6, "Emitters are surfaces"), and
 *   a painterly material has at least one lobe (KernelPainterlyMaterial::num_lobes). */
ccl_device void painterly_svm_collect(const ccl_private ShaderData *ccl_restrict sd,
                                      ccl_private PainterlySvmMaterial *ccl_restrict material)
{
  material->num_lobes = 0;
  material->num_dropped = 0;
  material->emission = (sd->flag & SD_EMISSION) ?
                           make_double3(double(sd->closure_emission_background.x),
                                        double(sd->closure_emission_background.y),
                                        double(sd->closure_emission_background.z)) :
                           make_double3(0.0);

  for (int i = 0; i < sd->num_closure; i++) {
    const ccl_private ShaderClosure *sc = &sd->closure[i];
    if (sc->type == CLOSURE_NONE_ID) {
      continue;
    }

    int kind;
    if (!painterly_svm_lobe_kind(sc->type, &kind)) {
      material->num_dropped++;
      continue;
    }

    ccl_private KernelPainterlyLobe *lobe = &material->lobes[material->num_lobes++];
    lobe->kind = kind;
    lobe->ior = 0.0;
    if (kind == LOBE_GLASS) {
      const ccl_private MicrofacetBsdf *bsdf = (const ccl_private MicrofacetBsdf *)sc;
      lobe->weight = painterly_svm_lobe_weight(sc->weight, painterly_svm_transmission_color(bsdf));
      lobe->ior = double(bsdf->ior);
    }
    else if (kind == LOBE_MIRROR && CLOSURE_IS_BSDF_MICROFACET(sc->type)) {
      const ccl_private MicrofacetBsdf *bsdf = (const ccl_private MicrofacetBsdf *)sc;
      lobe->weight = painterly_svm_lobe_weight(sc->weight, painterly_svm_reflection_color(bsdf));
    }
    else {
      lobe->weight = painterly_svm_lobe_weight(sc->weight, one_spectrum());
    }
  }

  if (material->num_lobes == 0) {
    material->lobes[0].kind = LOBE_DIFFUSE;
    material->lobes[0].weight = make_double3(0.0);
    material->lobes[0].ior = 0.0;
    material->num_lobes = 1;
  }
}

### For later cards
- `cycles_svm` dispatches the four closure cases. Later cards append their cases after them.
- `cycles_scene` registers `diffuse_bsdf`, `glossy_bsdf`, `glass_bsdf`, `refraction_bsdf`, `transparent_bsdf`,
  `principled_bsdf`, `background_shader`, `add_closure` and `mix_closure` (`painterly_cycles_shader_node_types()`).
- Every member of `BsdfBaseNode` and `BsdfNode` is a fragment now. A card that extracts another BSDF class (Metallic, Sheen,

  `device_update_post()`, `device_update_lookup_tables()`, then `PainterlyShaderManager::bind_kernel_globals(dscene,
  globals)`, and binds the other kernel arrays itself.
- `painterly/kernel/svm/collect.h`: `PainterlySvmMaterial` (`lobes`, `num_lobes`, `emission`, `num_dropped`),

/* One line per lobe, "<kind> <r> <g> <b> <ior>", then "emission <r> <g> <b>" and
 * "dropped <n>". %.17g prints a double that reads back to the same bits, so two descriptions are
 * equal iff the materials are. */
std::string describe(const std::vector<KernelPainterlyLobe> &lobes,
                     const double3 emission,
                     const int num_dropped)
{
  const char *const kinds[] = {"none", "diffuse", "mirror", "glass", "transparent"};
  std::string text;
  char line[256];
  for (const KernelPainterlyLobe &l : lobes) {
    std::snprintf(line,
                  sizeof(line),
                  "%s %.17g %.17g %.17g %.17g\n",
                  (l.kind >= 1 && l.kind <= 4) ? kinds[l.kind] : kinds[0],
                  l.weight.x,
                  l.weight.y,
                  l.weight.z,
                  l.ior);
    text += line;
  }
  std::snprintf(
      line, sizeof(line), "emission %.17g %.17g %.17g\n", emission.x, emission.y, emission.z);
  text += line;
  text += "dropped " + std::to_string(num_dropped) + "\n";
  return text;
}

/* lookup_table_read_3D(kg, 1, 1, z, offset, 16, 16, 16) (kernel/util/lookup_table.h:14-74) on
 * the raw `table`, operation by operation. x = y = 1 land on the last grid point, where t = 0
 * and the read returns that entry (:20-23, :37-40); z interpolates between two of them. */
float reference_lookup_corner(const float *table, const float z)
{
  const float zs = saturatef(z) * 15;
  const int index = min(float_to_int(zs), 15);
  const int nindex = min(index + 1, 15);
  const float t = zs - index;
  const float data0 = table[16 * 16 * index + 16 * 15 + 15];
  if (t == 0.0f) {
    return data0;
  }
  const float data1 = table[16 * 16 * nindex + 16 * 15 + 15];
  return (1.0f - t) * data0 + t * data1;
}

/* A Principled BSDF with GGX, Roughness 1, IOR 1.5 and Base Color (0.5, 0.25, 0.125); every
 * other input keeps its default (scene/shader_nodes.cpp:2627-2693). */

{

  set_enum(principled, "distribution", "ggx");

  principled->input("IOR")->set(1.5f);
  principled->input("Base Color")->set(make_float3(0.5f, 0.25f, 0.125f));
  return principled;
}

/* The specular and diffuse weights of rough_principled() seen head-on, derived from upstream
 * (kernel/svm/closure.h:426-521):
 * - specular: weight 1; its Fresnel payload has f0 = F0_from_ior(1.5) times Specular Tint 1
 *   (:438-457; F0_from_ior, kernel/closure/bsdf_util.h:290-293);
 * - its albedo: GGX with alpha = Roughness^2 = 1 seen at cos 1 reads ggx_gen_schlick_ior_s at
 *   x = rough = 1, y = cos = 1 and z = sqrt((1.5 - 1) / (1.5 + 1))
 *   (kernel/closure/bsdf_microfacet.h:518-523), then F = mix(f0, 1, s) (:530,
 *   util/math_float3.h:451-454);
 * - diffuse: Base Color times closure_layering_weight(F, 1) = 1 - F
 *   (kernel/closure/bsdf_util.h:440-444; kernel/svm/closure.h:468-470, 515). */
struct PrincipledReference {
  float f0;
  float diffuse;
};

PrincipledReference principled_reference()
{
  const float ior = 1.5f;
  const float f0 = sqr((ior - 1.0f) / (ior + 1.0f));
  const float z = sqrtf(fabsf((ior - 1.0f) / (ior + 1.0f)));
  const float s = reference_lookup_corner(table_ggx_gen_schlick_ior_s, z);
  const float F = f0 + s * (1.0f - f0);
  return PrincipledReference{f0, 1.0f - F};
}

        break;

        principled->input("Base Color")->set(make_float3(0.25f, 0.0625f, 1.0f));
        break;
      case 4:

        break;
      case 5:
        principled->input("Emission Color")->set(make_float3(0.5f, 0.25f, 1.0f));
        principled->input("Emission Strength")->set(2.0f);
        break;
    }
    add_surface(*scene, std::move(graph), principled, "BSDF");
  }
  compile(*scene);
  const PrincipledReference r = principled_reference();

  /* The specular layer is a mirror lobe of f0 (its Fresnel payload at normal incidence). Under it,

   * the layering (kernel/svm/closure.h:470). */
  evaluate(*scene, 0, e);

        describe({lobe(LOBE_MIRROR, d3(r.f0, r.f0, r.f0)),
                  lobe(LOBE_DIFFUSE, d3(0.5f * r.diffuse, 0.25f * r.diffuse, 0.125f * r.diffuse))},
                 make_double3(0.0),
                 0));
  CHECK(e.trace.other_arrays == 4);

  /* Specular IOR Level 0: f0 = 0, eta = 1, no specular layer (kernel/svm/closure.h:426-438). The

  evaluate(*scene, 1, e);

        describe({lobe(LOBE_DIFFUSE, d3(0.5f, 0.25f, 0.125f))}, make_double3(0.0), 0));

  evaluate(*scene, 2, e);

        describe({lobe(LOBE_MIRROR, d3(0.5f, 0.25f, 0.125f))}, make_double3(0.0), 0));

  /* Transmission Weight 1: one glass of weight 1 whose transmission tint is sqrt(Base Color)
   * (kernel/svm/closure.h:405-410); the layers below get weight 0. */
  evaluate(*scene, 3, e);
  CHECK(describe(e.material) ==
        describe({lobe(LOBE_GLASS, d3(0.5f, 0.25f, 1.0f), 1.5)}, make_double3(0.0), 0));

  /* Alpha 0.5: a transparent closure of 1 - 0.5 first, then every layer at weight 0.5

  evaluate(*scene, 4, e);
  CHECK(describe(e.material) ==
        describe(

  /* Emission Color * Emission Strength, not attenuated without coat or sheen

  evaluate(*scene, 5, e);

        describe({lobe(LOBE_MIRROR, d3(r.f0, r.f0, r.f0)),
