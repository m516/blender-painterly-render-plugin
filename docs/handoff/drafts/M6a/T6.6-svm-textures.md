# T6.6 — Texture and texture-coordinate SVM nodes (Noise, White Noise, Voronoi, Checker, Gradient, Wave, Magic, Brick, TexCoord) and their node classes
Milestone: M6a · Depends on: T3.1, T3.2, T3.3, T6.1, T6.2, T6.3, T6.4, T6.5 · Parallel-safe: no

## Goal
After this card:
- Cycles' evaluators for 14 more SVM node cases are vendored verbatim and dispatched by the generated `svm_eval_nodes()`
  (`cycles_svm`, T6.3):
  - the eight textures `NODE_TEX_NOISE`, `NODE_TEX_WHITE_NOISE`, `NODE_TEX_VORONOI`, `NODE_TEX_CHECKER`, `NODE_TEX_GRADIENT`,
    `NODE_TEX_WAVE`, `NODE_TEX_MAGIC` and `NODE_TEX_BRICK`. They read the stack, `util/hash.h` and math only;
  - the cases that `TextureCoordinateNode::compile` emits (`scene/shader_nodes.cpp:4076-4258`): `NODE_TEX_COORD` (Normal,
    Object, Camera, Window, Reflection), `NODE_ATTR` (Generated, UV) and `NODE_GEOMETRY` (Generated and Reflection of a
    background shader), each with its `*_DERIVATIVE` variant. They read `ShaderData`, the kernel arrays `objects`,
    `attributes_map`, `attributes_float2`, `attributes_float3`, `tri_vindex`, and `KernelData::cam`.
- The 32 headers that these evaluators need are vendored: the 11 evaluator headers, `kernel/svm/noise.h`,
  `kernel/svm/fractal_noise.h`, and their include closure (`kernel/geom/*`, `kernel/camera/*`, `kernel/sample/*`, three
  `kernel/util/` headers, `kernel/bvh/util.h`, `kernel/integrator/state.h`). T6.5 already vendored 16 of them; this card adds
  the other 16 ("Vendored files"). No patch and no new shim.
- `cycles_scene` (T6.4) gains the eight texture node classes and `TextureMapping`, as 40 fragments of
  `scene/shader_nodes.cpp`, and `transform_transposed_inverse()` as a fragment of `util/transform.cpp` in a new generated unit
  `transform`. M6b can create every texture node by its Cycles type name.
- `src/test/cycles_svm_test_scene.h` holds a minimal Cycles scene in Cycles' kernel layout (two objects, two triangles, the
  Generated and UV attributes, a camera), which this card's TexCoord doctests and later M6a cards use.
- Doctests evaluate every texture and every texture coordinate at fixed points and compare, bit for bit, with an independent
  evaluation of the same upstream formula. Graph doctests check registration, socket defaults, the automatic TexCoord link,
  and the `TextureMapping` transforms.
- `THIRD_PARTY_NOTICES.md` and `LICENSES/` cover the two non-Apache licences in the 32 headers: BSD-3-Clause (code adapted
  from Open Shading Language: `kernel/svm/noise.h`, which this card vendors, and `kernel/camera/projection.h` and
  `kernel/sample/mapping.h`, which T6.5 vendored without a notice row) and MIT (Inigo Quilez's Voronoi code in
  `kernel/svm/voronoi.h`, which this card vendors).

M6a builds Cycles' shader VM as standalone vendored libraries. Nothing in the painterly engine uses these nodes yet: M6b wires
them into `painterly_trace_pixel`, `PainterlyScene` and the Blender sync.

## Decisions (Opus, 2026-10-09)
1. **Scope.** This card vendors the kernel evaluators and extracts the host node classes. It does not run
   `SVMCompiler::compile()`: compiling a graph is T6.5's, and the per-node golden renders against Blender's Cycles are M6b's
   (`docs/plan.md`, M6 node ports). The doctests encode the node structs by hand, as the node `compile()` bodies would.
   `TextureCoordinateNode`, `GeometryNode` and `AttributeNode` are already in `cycles_scene` (T6.4, core node set).
2. **`transform_transposed_inverse()`.** `TextureMapping::compute_transform()` calls it for the Normal mapping type
   (`scene/shader_nodes.cpp:131-135`). Upstream defines it in `util/transform.cpp:15-19`, which T3.2 left unvendored because
   `util/boundbox.h` qualifies calls with `ccl::`, and T3.2 left the choice to Opus. T6.4 also never vendors
   `util/transform.cpp` or `util/boundbox.h`. Decision: it becomes a T6.2 `function` fragment of `util/transform.cpp`,
   compiled into `cycles_scene` from a new generated unit `transform` (`fragment_units.toml`). No patch, no namespace alias.
   - This decision extends the M6a design's list of fragmented upstream files (`scene/shader_nodes.cpp`, `scene/svm.cpp` and
     the `SVM_CASE` blocks of `kernel/svm/svm.h`) by a fourth: `util/transform.cpp`. Later cards and reviewers treat
     `util/transform.cpp` as fragmented by design.
   - Why a fragment and not the whole file: M6a calls one of its five definitions (`util/transform.cpp:15-19`; the other
     four, `:23-203`, convert to quaternions, decompose motion transforms and build the viewplane transform), and the whole
     file includes `util/boundbox.h` (`:8`), which T3.2 and T6.4 keep out.
   - A later card that vendors `util/transform.cpp` whole first runs
     `tools/vendor_sync.py remove-fragment util/transform_cpp/function/transform_transposed_inverse` and removes the unit
     `transform` (T6.2 rule 3 forbids a file that is both vendored and fragmented).
3. **How the doctests know the right value.** Every expected value is an evaluation of the upstream formula that does not run
   the code under test:
   - by hand, written next to the check, when the inputs make every intermediate result exactly representable in float32.
     Nothing rounds then, so the order of operations, the SSE paths and FMA contraction cannot change the result;
   - otherwise by a reference function in the test file that repeats the upstream formula operation by operation. A reference
     function may call `util/` helpers (`util/hash.h`, `util/math*.h`, vendored by T3.2) but never a `kernel/svm/` function.
     Its C library calls (`sinf`, `cosf`, `fmodf`, `atan2f`, `sqrtf`) take their arguments through `opaque()`, a `volatile`
     copy, so that the compiler cannot evaluate them at compile time, which may round differently from the run-time call the
     kernel makes (as T6.3's `painterly_test_libm_powf`).
   - The points are chosen accordingly:
     - Noise is checked only at the centre of a lattice cell (all coordinates `n + 0.5`) and at lattice points. There every
       Perlin gradient is a sum of two of ±0.5 and every corner weighs 1/8, so the scalar formula (`noise.h:181-207`) and
       the SSE code the kernel compiles (`noise.h:433-454`) agree exactly. Elsewhere they mix in different orders and round
       differently. The Color output is not checked: it samples at random offsets in [100, 200] (`noisetex.h:32-37`).
     - Voronoi is checked with randomness 0 (feature points on cell corners, Euclidean distance of dyadic offsets), and with
       randomness 1 under the Chebychev metric, whose distance uses only per-component operations and `max`.
     - Wave is checked without distortion (`wave.h:63-65` would sample noise at general points).
   - The in-VM comparison is `PainterlySvmTestProgram::check_equal()` (T6.3): exact equality.
4. **No random numbers.** No vendored function on these paths reads `lcg_state`; the only use in the 32 headers,
   `kernel/util/image_3d.h:223`, is compiled only with `WITH_NANOVDB` (`:210-257`), which nothing defines. The same
   conditional is the only way to `kernel/util/nanovdb.h` (`:13-15`): T6.5 vendored that file, and nothing compiles it.
   The doctests still set `lcg_state = 0` through `painterly_svm_test_shader_data()`.
5. **Feature mask.** The 2D, 3D and 4D Voronoi features run only if the node feature mask has
   `KERNEL_FEATURE_NODE_VORONOI_EXTRA` (`voronoi.h:1151, 1162, 1174`); otherwise they output zeros. Cycles' surface mask has
   it (`kernel/features.h:87-99`), and so does T6.3's `painterly_svm_test_node_feature_mask`. M6b must evaluate with a mask
   that has it.
6. **Licences.** Three of the 32 headers carry `SPDX-License-Identifier: BSD-3-Clause` (code adapted from Open Shading
   Language, copyright Sony Pictures Imageworks Inc., et al.): `kernel/svm/noise.h`, which this card vendors, and
   `kernel/camera/projection.h` and `kernel/sample/mapping.h`, which T6.5 vendored and gave no notice row.
   `kernel/svm/voronoi.h:13-28` marks its Voronoi code `SPDX-License-Identifier: MIT`, copyright (c) 2013 Inigo Quilez.
   `THIRD_PARTY_NOTICES.md` gets one row for each licence, with the full texts in `LICENSES/`.

```cpp
/* SPDX-FileCopyrightText: 2026 The Painterly Authors
 * SPDX-License-Identifier: GPL-3.0-or-later */

/* Cycles' texture and texture-coordinate SVM nodes (card T6.6), run through the generated
 * svm_eval_nodes() of cycles_svm on hand-encoded byte code (cycles_svm_test_support.h, T6.3).
 *
 * Every expected value is an evaluation of the upstream formula that does not run the code
 * under test:
 * - by hand, in the comment next to it, when the inputs make every intermediate result exactly
 *   representable in float32. No operation rounds then, so neither the order of operations, nor
 *   the SSE code paths, nor FMA contraction can change the result;
 * - otherwise by a reference function in this file that repeats the upstream formula operation
 *   by operation. A reference function may call util/ helpers (util/hash.h, util/math*.h,
 *   vendored by card T3.2) but never a kernel/svm/ function. Its C library calls take their
 *   arguments through opaque(), so that the compiler cannot evaluate them at compile time, which
 *   may round differently from the run-time call that the kernel makes.
 * check_equal() compares inside the VM with exact equality (T6.3). Evaluation draws no random
 * number: lcg_state is 0 (painterly_svm_test_shader_data, T6.3). */

#include "cycles_svm_test_scene.h"

#include <cfloat>
#include <cmath>

#include <doctest/doctest.h>

CCL_NAMESPACE_BEGIN

namespace {

/* run_program_and_check() of card T6.3 for a caller-supplied ShaderData, with the expected
 * number of fetches from kernel arrays other than svm_nodes. */
void run_and_check(KernelGlobalsCPU &globals,
                   PainterlySvmTestProgram &program,
                   ShaderData &sd,
                   const int other_arrays)
{
  program.add_node(NODE_END);
  const PainterlySvmTrace trace = painterly_svm_test_run_shader_data(globals, program, sd);
  CHECK(program.fetched_trace(trace.svm_nodes) == program.expected_trace(0));
  CHECK(trace.other_arrays == other_arrays);
  CHECK(program.failed_checks(trace.svm_nodes) == "");
}

/* A program for shader 0 whose jump entry points at the first node added (T6.3). */
PainterlySvmTestProgram new_program()
{
  PainterlySvmTestProgram program;
  const int start = program.size();
  program.set_jump(0, start, start, start);
  return program;
}

/* Writes `value` to stack slots slot..slot+2. */
void add_vector(PainterlySvmTestProgram &program, const SVMStackOffset slot, const float3 value)
{
  program.add_node(NODE_VALUE_V, SVMNodeValueV{.out_offset = slot, .value = value});
}

SVMInputFloat c(const float value)
{
  return painterly_svm_input_constant(value);
}

SVMInputFloat3 c3(const float x, const float y, const float z)
{
  return painterly_svm_input_constant3(x, y, z);
}

float opaque(const float x)
{
  volatile float copy = x;
  return copy;
}

float3 opaque3(const float3 v)
{
  return make_float3(opaque(v.x), opaque(v.y), opaque(v.z));
}

/* ---- Reference functions ---- */

/* svm_gradient() (kernel/svm/gradient.h:14-57) for NODE_BLEND_RADIAL,
 * NODE_BLEND_QUADRATIC_SPHERE and NODE_BLEND_SPHERICAL, then saturatef() (gradient.h:65). */
float gradient_reference(const float3 p, const NodeGradientType type)
{
  const float x = opaque(p.x);
  const float y = opaque(p.y);
  const float z = opaque(p.z);
  if (type == NODE_BLEND_RADIAL) {
    return saturatef(atan2f(y, x) / M_2PI_F + 0.5f);
  }
  const float r = fmaxf(0.999999f - sqrtf(x * x + y * y + z * z), 0.0f);
  return saturatef((type == NODE_BLEND_QUADRATIC_SPHERE) ? r * r : r);
}

/* svm_magic() (kernel/svm/magic.h:14-100) for depth 2. */
float3 magic_depth2_reference(const float3 p_in, const float scale_in, const float distortion_in)
{
  const float3 p = opaque3(p_in);
  const float scale = opaque(scale_in);
  float distortion = opaque(distortion_in);

  const float px = fmodf(p.x * scale, M_2PI_F);
  const float py = fmodf(p.y * scale, M_2PI_F);
  const float pz = fmodf(p.z * scale, M_2PI_F);

  float x = sinf((px + py + pz) * 5.0f);
  float y = cosf((-px + py - pz) * 5.0f);
  float z = -cosf((-px - py + pz) * 5.0f);

  /* n > 0 */
  x *= distortion;
  y *= distortion;
  z *= distortion;
  y = -cosf(x - y + z);
  y *= distortion;
  /* n > 1 */
  x = cosf(x - y - z);
  x *= distortion;

  /* distortion != 0 */
  distortion *= 2.0f;
  x /= distortion;
  y /= distortion;
  z /= distortion;

  return make_float3(0.5f - x, 0.5f - y, 0.5f - z);
}

/* svm_wave() (kernel/svm/wave.h:15-77) with distortion 0, which skips wave.h:63-65. */
float wave_reference(const NodeWaveType type,
                     const NodeWaveBandsDirection bands_dir,
                     const NodeWaveRingsDirection rings_dir,
                     const NodeWaveProfile profile,
                     const float3 p_in,
                     const float phase_in)
{
  float3 p = opaque3(p_in);
  const float phase = opaque(phase_in);

  p = (p + 0.000001f) * 0.999999f;

  float n;
  if (type == NODE_WAVE_BANDS) {
    if (bands_dir == NODE_WAVE_BANDS_DIRECTION_X) {
      n = p.x * 20.0f;
    }
    else if (bands_dir == NODE_WAVE_BANDS_DIRECTION_Y) {
      n = p.y * 20.0f;
    }
    else if (bands_dir == NODE_WAVE_BANDS_DIRECTION_Z) {
      n = p.z * 20.0f;
    }
    else {
      n = (p.x + p.y + p.z) * 10.0f;
    }
  }
  else {
    float3 rp = p;
    if (rings_dir == NODE_WAVE_RINGS_DIRECTION_X) {
      rp *= make_float3(0.0f, 1.0f, 1.0f);
    }
    else if (rings_dir == NODE_WAVE_RINGS_DIRECTION_Y) {
      rp *= make_float3(1.0f, 0.0f, 1.0f);
    }
    else if (rings_dir == NODE_WAVE_RINGS_DIRECTION_Z) {
      rp *= make_float3(1.0f, 1.0f, 0.0f);
    }
    n = len(rp) * 20.0f;
  }

  n += phase;

  if (profile == NODE_WAVE_PROFILE_SIN) {
    return 0.5f + 0.5f * sinf(n - M_PI_2_F);
  }
  if (profile == NODE_WAVE_PROFILE_SAW) {
    n /= M_2PI_F;
    return n - floorf(n);
  }
  n /= M_2PI_F;
  return fabsf(n - floorf(n + 0.5f)) * 2.0f;
}

/* brick_noise() (kernel/svm/brick.h:14-21). */
float brick_noise_reference(uint n)
{
  n = (n + 1013) & 0x7fffffff;
  n = (n >> 13) ^ n;
  const uint nn = (n * (n * n * 60493 + 19990303) + 1376312589) & 0x7fffffff;
  return 0.5f * ((float)nn / 1073741824.0f);
}

/* A brick's color in svm_node_tex_brick() (kernel/svm/brick.h:100-107) when the point is not in
 * the mortar (f = 0): (1 - tint) * color1 + tint * color2, then times (1 - 0) plus mortar times
 * 0, which changes nothing. */
float3 brick_color_reference(const uint noise_input,
                             const float bias,
                             const float3 color1,
                             const float3 color2)
{
  const float tint = saturatef(brick_noise_reference(noise_input) + bias);
  const float facm = 1.0f - tint;
  return make_float3(facm * color1.x + tint * color2.x,
                     facm * color1.y + tint * color2.y,
                     facm * color1.z + tint * color2.z);
}

/* grad3() of kernel/svm/noise.h:142-149. */
float grad3_reference(const int hash, const float x, const float y, const float z)
{
  const int h = hash & 15;
  const float u = h < 8 ? x : y;
  const float vt = ((h == 12) || (h == 14)) ? x : z;
  const float v = h < 4 ? y : vt;
  return ((h & 1) ? -u : u) + ((h & 2) ? -v : v);
}

/* grad1() of kernel/svm/noise.h:28-33. */
float grad1_reference(const int hash, const float x)
{
  const int h = hash & 15;
  const float g = 1 + (h & 7);
  return ((h & 8) ? -g : g) * x;
}

/* perlin_3d() (kernel/svm/noise.h:181-207) at (X + 0.5, Y + 0.5, Z + 0.5). There fade() is
 * exactly 0.5, every corner gradient is a sum of two of +-0.5, and each corner weighs 1/8, so the
 * result is a multiple of 1/8 and exact in any order of operations, including the SSE order of
 * noise.h:433-454 that the kernel compiles. */
float perlin_3d_half_integer_reference(const int X, const int Y, const int Z)
{
  float sum = 0.0f;
  for (int dz = 0; dz <= 1; dz++) {
    for (int dy = 0; dy <= 1; dy++) {
      for (int dx = 0; dx <= 1; dx++) {
        const uint hash = hash_uint3(uint(X + dx), uint(Y + dy), uint(Z + dz));
        sum += grad3_reference(int(hash), 0.5f - dx, 0.5f - dy, 0.5f - dz);
      }
    }
  }
  return sum * 0.125f;
}

/* perlin_1d() (kernel/svm/noise.h:35-42) at X + 0.5: fade() is 0.5, so the mix is the mean of
 * the two gradients, exact in any order. */
float perlin_1d_half_integer_reference(const int X)
{
  return (grad1_reference(int(hash_uint(uint(X))), 0.5f) +
          grad1_reference(int(hash_uint(uint(X + 1))), -0.5f)) *
         0.5f;
}

/* voronoi_f1() (kernel/svm/voronoi.h:479-510) with the Chebychev metric (voronoi.h:57-95), as
 * fractal_voronoi_x_fx() (voronoi.h:939-992) runs it for detail 0 and scale 1: one octave, the
 * position divided by 1. Only per-component operations and max occur, so the result is the same
 * in any order. The search visits the cells in upstream's order and keeps the first minimum. */
struct VoronoiReference {
  float distance;
  float3 color;
  float3 position;
};

VoronoiReference voronoi_f1_chebychev_reference(const float3 coord_in, const float randomness)
{
  const float3 coord = opaque3(coord_in);
  const float3 cell_position_f = floor(coord);
  const float3 local_position = coord - cell_position_f;
  const int3 cell_position = make_int3(cell_position_f);

  float min_distance = FLT_MAX;
  int3 target_offset = make_int3(0);
  float3 target_position = make_float3(0.0f, 0.0f, 0.0f);
  for (int k = -1; k <= 1; k++) {
    for (int j = -1; j <= 1; j++) {
      for (int i = -1; i <= 1; i++) {
        const int3 cell_offset = make_int3(i, j, k);
        const float3 point_position = make_float3(cell_offset) +
                                      hash_int3_to_float3(cell_position + cell_offset) *
                                          randomness;
        const float distance_to_point = reduce_max(fabs(point_position - local_position));
        if (distance_to_point < min_distance) {
          target_offset = cell_offset;
          min_distance = distance_to_point;
          target_position = point_position;
        }
      }
    }
  }

  VoronoiReference result;
  result.distance = reduce_max(fabs(target_position - local_position));
  result.color = hash_int3_to_float3(cell_position + target_offset);
  result.position = target_position + cell_position_f;
  return result;
}
```
