# T6.5 — The SVM compiler from fragments, `PainterlyShaderManager`, graph → byte code → evaluation, and experiment 007 part 2 (gate G2-svm)

## Goal
After this card:
- Cycles' `SVMCompiler` is complete in `cycles_scene`, from verbatim upstream text. Card T6.4 extracted `scene/svm.cpp:172-550`.
  This card adds the constructor (`:157-170`) and the graph compiler (`:552-1279`): 15 fragments. Every definition in
  `scene/svm.cpp:157-1279` is then a fragment, and T6.4's generated `svm` unit compiles them all.
- `PainterlyShaderManager` (`src/painterly/scene/svm/shader_manager.h`) ports what Cycles' device update does around the
  compiler: `ShaderManager::device_update_pre` (`scene/shader.cpp:520-598`), `SVMShaderManager::device_update_specific`
  with its jump-table packing (`scene/svm.cpp:57-146`, packing at `:95-134`), and `ShaderManager::device_update_common`
  (`scene/shader.cpp:612-748`). Every function cites the upstream lines it ports and says what it leaves out.
- `time_dt()` (`util/time.cpp:31-35`), with which `SVMCompiler::compile` and `Progress` measure time, is a fragment too,
  compiled into `cycles_scene` from a new generated unit `time`. `util/time.cpp` is not vendored whole.
- Cycles' closure evaluators are vendored: `kernel/svm/closure.h` whole, with its include closure (45 new files). The
  generated `svm_eval_nodes()` gains the three cases that `EmissionNode::compile` emits: `NODE_EMISSION_WEIGHT`,
  `NODE_CLOSURE_SET_WEIGHT` and `NODE_CLOSURE_EMISSION`. A build check in `ALL`, `cycles_svm_closure_headers_check`
  (T6.3's pattern), compiles `kernel/svm/closure.h` in every build, the wheel builds included.
- The util shims gain what the new code calls: `string_printf()` (`SVMCompiler::Summary::full_report`) and `LOG_DEBUG`.
- Doctests run the whole chain: a shader graph Value → Math → Emission (cycles_scene, T6.4) is compiled by `SVMCompiler`,
  packed by `PainterlyShaderManager` and evaluated by the generated `svm_eval_nodes()` (cycles_svm, T6.2 and T6.3). They
  read `ShaderData::closure_emission_background`. Byte code, fetch traces and emission are compared exactly with values
  derived from upstream code, and 16 Math operations with an independent float64 reference.
- Experiment 007 (X-svm) gets its part 2, pre-registered in this card. It decides gate G2-svm.

M6a builds Cycles' shader VM as standalone vendored libraries. Nothing in the painterly engine uses these yet: M6b wires them
into `painterly_trace_pixel`, `PainterlyScene` and the Blender sync.

## Decisions (Opus, 2026-10-09)
1. **Experiment 007, part 2.** X-svm is one experiment, numbered 007 (M6a design). Card T6.3 registered and ran its part 1
   (stack nodes on hand-encoded byte code). This card registers part 2 in the same directory: one `### Part 2 (card T6.5)`
   subsection at the end of each of the five README sections, its own script `probe_part2.py` and its own results file
   `results_part2.json`. Part 1's text, `probe.py` and `results.json` stay as they are. Gate G2-svm is decided on both parts.
2. **The closure evaluators arrive with the compiler.** The end-to-end check reads `sd->closure_emission_background`, which
   only the closure evaluators write. `kernel/svm/closure.h` is vendored whole (the M6a design fragments only
   `scene/shader_nodes.cpp`, `scene/svm.cpp` and the cases of `kernel/svm/svm.h`), with its include closure: 45 new files,
   among them all 26 `kernel/closure/*.h` and 9 `kernel/geom/*.h`. Two files that only inactive conditionals reach
   stay unvendored, now and in later cards (`util/guiding.h`, `kernel/util/nanovdb.h`; "Vendored files"). This card adds
   only the three cases that `EmissionNode::compile` emits. Later cards find these files vendored and `add` only what is
   missing.
   - Only test translation units include the generated `svm_eval_nodes.h`, and the wheel builds build no tests. So that
     every build compiles the new kernel headers, as T6.3's `cycles_svm_headers_check` does for its 22, the OBJECT library
     `cycles_svm_closure_headers_check` (in `ALL`) compiles `src/cycles/svm_closure_headers_check.cpp`: `kernel/globals.h`,
     then `kernel/svm/closure.h`, which reaches the 42 other new kernel headers. It is a build check, not a shim, and
     defines nothing. T6.3's `svm_headers_check.cpp` stays as it is (T6.3's pytest pins its include list).
3. **`SVMCompiler` is complete.** With T6.4's 29 fragments, the 15 of this card make every definition in
   `scene/svm.cpp:157-1279` a fragment (44 in all). T6.4's generated `svm` unit compiles them in upstream order; this card adds
   the two headers they need, `util/progress.h` and `util/queue.h` (`scene/svm.cpp:25-26`), to that unit's `includes`.
4. **The device update is ported, not vendored.** `SVMShaderManager` and `ShaderManager::device_update_*` need a Device, a
   TaskPool, the LightManager, scene statistics, the emission estimate and the BSDF lookup tables. `PainterlyShaderManager`
   ports them with upstream's names and code, and leaves out exactly what the shims do not have; each omission is a comment
   that cites the upstream lines.
   - It is header-only and in no build target during M6a; M6b moves it into a library. If
     `src/painterly/scene/CMakeLists.txt` exists (card T3.13's `painterly_scene`, when the worktree was cut after it), do not
     add the header to it: M6b does. It derives from the shim `ShaderManager` like `SVMShaderManager` does, because
     `device_update_common` reads the protected `rgb_to_y`.
   - It is Apache-2.0 with Blender's copyright line, like the shims, because it is upstream code adapted. Like every shim
     that copies upstream code, it carries a "Modified by the Painterly project" notice.
5. **Shim growth, only in shims that T3.3 and T6.4 created; no new shim file.** Each changed shim keeps upstream's SPDX lines
   and a "Modified by the Painterly project" notice that names what it keeps (`THIRD_PARTY_NOTICES.md`, Cycles row).
   - `scene/scene.h`: `Scene` gains `shaders` and `dscene` (`scene/scene.h:158, 186`); `DeviceScene` keeps `svm_nodes`,
     `shaders` and `data` (`scene/devicescene.h:77-78, 101`) as host arrays.
   - `scene/shader.h`/`.cpp`: `Shader` gains the members that `SVMCompiler` and `PainterlyShaderManager` read, upstream's
     enums, a reference count, `set_graph()`, an out-of-line destructor (so that `unique_ptr<ShaderGraph>` is deleted where
     `ShaderGraph` is complete) and an empty `estimate_emission()` (painterly samples no lights, SPEC §6).
   - `util/string.h`/`.cpp`: `string_printf()`, which `SVMCompiler::Summary::full_report` calls eight times
     (`scene/svm.cpp:1254-1264`). The declaration with `PRINTF_ATTRIBUTE` is `util/string.h:27-33`, the definition
     `util/string.cpp:23-53`, both copied from the checkout. No vendored header declares it: upstream declares it only in
     `util/string.h`, which is shimmed.
   - `util/log.h`: `LOG_DEBUG` (`scene/svm.cpp:1022`, and `:52`, which `PainterlyShaderManager` ports), defined like T6.4's
     `LOG_TRACE`; the notice names it with the other kept macros.
6. **Two compilation paths in the doctests.** Cycles prepares every graph with `ShaderGraph::finalize`
   (`scene/shader_graph.cpp:374-402`), and its constant folding turns a graph of constants into one constant emission. The
   doctests compile each test graph both ways: through `PainterlyShaderManager::device_update_pre` (folded, Cycles' path) and
   without `finalize`, setting only what `finalize` sets for a lone closure: its `SurfaceMixWeight` is 0 + 1
   (`transform_multi_closure`, `scene/shader_graph.cpp:1149-1187`). Only the unfolded program makes the SVM itself evaluate
   Value and Math. A graph whose inputs vary per shading point compiles the same way in Cycles, because nothing folds.
7. **`time_dt()` is a fragment, not a shim.** `SVMCompiler::compile` reads the clock (`scene/svm.cpp:1184, 1229`) and times
   its stages with `scoped_timer` (`util/time.h:33-60`), and `Progress` reads it in its constructor (`util/progress.h:25`).
   All of them call `time_dt()`, defined in `util/time.cpp:31-35`. That file is not vendored whole:
   `time_human_readable_from_seconds()` (`:133-144`) needs `string_printf()`, and `time_human_readable_to_seconds()`
   (`:146-190`) needs `string_split()` and calls `::pow` (`:171`) without including `<cmath>`.
   - As card T6.6 does for `transform_transposed_inverse()` of `util/transform.cpp`, `time_dt()` becomes a T6.2 `function`
     fragment, assembled into a new generated unit `time` (`src/cycles/fragment_units.toml`) and compiled into
     `cycles_scene`. It stays verbatim, and `check --upstream` re-extracts it.
   - A later card that needs another function of `util/time.cpp` adds it as one more fragment to the unit `time`.
   - A later card that vendors `util/time.cpp` whole instead (T6.2 rule 3 forbids vendoring and fragmenting one file) does
     all of the following, and lists each file under its "Modify":
     1. `tools/vendor_sync.py remove-fragment util/time_cpp/function/time_dt`, before it `add`s `util/time.cpp`;
     2. in `src/cycles/fragment_units.toml`, deletes the ten lines that "Fragments and manifests" item 3 appended (the

     3. in `src/cycles/CMakeLists.txt`, deletes this card's block that starts `# T6.5: time_dt()` (its three comment
        lines, the `add_custom_command` and the `target_sources` line), and adds
        `${PAINTERLY_CYCLES_VENDOR}/util/time.cpp` to the sources of `cycles_util`, so that `time_dt()` is defined once;

8. **Licence notices of the new non-Apache files are deferred to cards T6.6 and T6.7.** 14 of the 45 files carry code under
   another licence than the Cycles row's Apache-2.0:
   - BSD-3-Clause, "Adapted code from Open Shading Language" (Sony Pictures Imageworks): `kernel/camera/projection.h`,

   Each file keeps its own SPDX lines (they are vendored verbatim). Card T6.6 creates `LICENSES/BSD-3-Clause-osl.txt` and the

/* Modified by the Painterly project: adapted from SVMShaderManager (scene/svm.cpp:37-153) and

#pragma once

/* PainterlyShaderManager: Cycles' SVM shader manager for painterly (card T6.5). Header-only and
 * in no build target during M6a; M6b moves it into a library.
 *
 * Cycles compiles shaders in SVMShaderManager (scene/svm.cpp:33-153) and in the
 * ShaderManager::device_update_* members (scene/shader.cpp:520-760). They need a Device, a
 * TaskPool, the LightManager, scene statistics and the BSDF lookup tables, so they are not
 * vendored (card T6.4). This class ports them. Each function names the upstream lines it ports;
 * code is upstream's except where a comment says what is left out and why. SVMCompiler itself is
 * vendored verbatim (scene/svm.cpp:157-1279, fragments of cards T6.4 and T6.5). */

class PainterlyShaderManager final : public ShaderManager {
 public:
  /* The world shader, or nullptr. Cycles takes it from the scene's Background node
   * (scene->background->get_shader(scene), scene/svm.cpp:49), which the shim Scene does not
   * have. */
  const Shader *background_shader = nullptr;

  /* ShaderManager::device_update_pre (scene/shader.cpp:520-598): numbers the shaders, finalizes
   * their graphs and records what each graph contains. */
  void device_update_pre(Device * /*device*/,
                         DeviceScene *dscene,
                         Scene *scene,
                         Progress & /*progress*/)
  {
    /* Upstream returns unless need_update() (:527). Painterly keeps no update flags and prepares
     * every shader on every call; ShaderGraph::finalize() changes a graph only once
     * (scene/shader_graph.cpp:381). */
    uint id = 0;
    for (Shader *shader : scene->shaders) {
      shader->id = id++;
    }

    /* :536-541 assert Cycles' default shaders, which the shim Scene does not have. */

    /* Preprocess shader graph. */
    bool has_volumes = false;

    for (Shader *shader : scene->shaders) {
      /* Upstream preprocesses only shaders whose is_modified() is true (:547). The shim Shader
       * is not a Node and keeps no modified flags. */
      ShaderNode *output = shader->graph->output();
      shader->has_bump_from_displacement = (shader->get_displacement_method() != DISPLACE_TRUE) &&
                                           output->input("Surface")->link &&
                                           output->input("Displacement")->link;
      shader->has_bssrdf_bump = shader->has_bump_from_displacement;

      shader->graph->finalize(scene,
                              shader->has_bump_from_displacement,
                              shader->get_displacement_method() == DISPLACE_BOTH);

      shader->has_surface = output->input("Surface")->link != nullptr;
      shader->has_surface_transparent = false;
      shader->has_surface_raytrace = false;
      shader->has_surface_bssrdf = false;
      shader->has_surface_spatial_varying = false;
      shader->has_volume = output->input("Volume")->link != nullptr;
      shader->has_volume_spatial_varying = false;
      shader->has_volume_attribute_dependency = false;
      shader->has_displacement = output->input("Displacement")->link != nullptr;
      shader->has_bump_from_surface = false;

      /* Determine both properties. */
      shader->has_light_path_node = false;
      shader->has_aov_output_node = false;
      shader->has_time_dependency = false;
      for (ShaderNode *node : shader->graph->nodes) {
        if (node->special_type == SHADER_SPECIAL_TYPE_LIGHT_PATH) {
          /* TODO: check if the light path node is linked to the volume output. */
          shader->has_light_path_node = true;
        }
        else if (node->special_type == SHADER_SPECIAL_TYPE_OUTPUT_AOV) {
          shader->has_aov_output_node = true;
        }
        else if (node->special_type == SHADER_SPECIAL_TYPE_SCENE_TIME) {
          shader->has_time_dependency = true;
        }
      }

      if (shader->reference_count()) {
        has_volumes |= shader->has_volume;
      }
    }

    /* Set this early as it is needed by volume rendering passes. Upstream also tags the scene
     * (:594-595), which painterly does not track. */
    KernelIntegrator *kintegrator = &dscene->data.integrator;
    kintegrator->use_volumes = has_volumes;
  }

  /* ShaderManager::device_update_post (scene/shader.cpp:600-610) without the copies to a
   * device. */
  void device_update_post(Device *device, DeviceScene *dscene, Scene *scene, Progress &progress)
  {
    device_update_specific(device, dscene, scene, progress);
  }

  /* SVMShaderManager::device_free and ShaderManager::device_free_common (scene/svm.cpp:148-153,
   * scene/shader.cpp:750-760) without the lookup tables, which painterly does not upload. */
  void device_free(Device * /*device*/, DeviceScene *dscene, Scene * /*scene*/) override
  {
    dscene->shaders.clear();
    dscene->svm_nodes.clear();
  }

 protected:
  /* SVMShaderManager::device_update_specific (scene/svm.cpp:57-146). */
  void device_update_specific(Device *device,
                              DeviceScene *dscene,
                              Scene *scene,
                              Progress &progress) override
  {
    /* Upstream returns unless need_update() (:62-64), and times and logs the update (:66-70,
     * :74-76, :144-145). Painterly updates every time and keeps no statistics. */
    const int num_shaders = scene->shaders.size();

    /* test if we need to update */
    device_free(device, dscene, scene);

    /* Build all shaders, one after the other: upstream compiles them in parallel on a TaskPool
     * (:81-89), into the same per-shader arrays. */
    vector<array<int>> shader_svm_nodes(num_shaders);
    for (int i = 0; i < num_shaders; i++) {
      device_update_shader(scene, scene->shaders[i], progress, &shader_svm_nodes[i]);
    }

    if (progress.get_cancel()) {
      return;
    }

    /* The global node list contains a jump table (one jump node per shader)
     * followed by the nodes of all shaders. */
    const int jump_node_size = 1 + sizeof(SVMNodeShaderJump) / sizeof(int);
    int svm_nodes_size = num_shaders * jump_node_size;
    for (int i = 0; i < num_shaders; i++) {
      /* Since we're not copying the local jump node, the size ends up lower. */
      svm_nodes_size += shader_svm_nodes[i].size() - jump_node_size;
    }

    /* A host array: resize() where upstream allocates a device_vector (:104). */
    int *svm_nodes = dscene->svm_nodes.resize(svm_nodes_size);

    int node_offset = num_shaders * jump_node_size;
    for (int i = 0; i < num_shaders; i++) {
      Shader *shader = scene->shaders[i];

      /* Upstream clears the shader's modified flags and tags the LightManager for shaders that
       * emit (:110-113). The shim Shader keeps no such flags, and painterly samples no lights
       * (SPEC §6). */

      /* Update the global jump table.
       * Each compiled shader starts with a jump node that has offsets local
       * to the shader, so copy those and add the offset into the global node list. */
      const int base = shader->id * jump_node_size;
      svm_nodes[base + 0] = NODE_SHADER_JUMP;
      *reinterpret_cast<SVMNodeShaderJump *>(&svm_nodes[base + 1]) = SVMNodeShaderJump{
          .offset_surface = shader_svm_nodes[i][1] - jump_node_size + node_offset,
          .offset_volume = shader_svm_nodes[i][2] - jump_node_size + node_offset,
          .offset_displacement = shader_svm_nodes[i][3] - jump_node_size + node_offset};
      node_offset += shader_svm_nodes[i].size() - jump_node_size;
    }

    /* Copy the nodes of each shader into the correct location. */
    int *dst = svm_nodes + num_shaders * jump_node_size;
    for (int i = 0; i < num_shaders; i++) {
      const int shader_size = shader_svm_nodes[i].size() - jump_node_size;

      std::copy_n(&shader_svm_nodes[i][jump_node_size], shader_size, dst);
      dst += shader_size;
    }

    if (progress.get_cancel()) {
      return;
    }

    device_update_common(device, dscene, scene, progress);

    /* Upstream resets its update flags here (:142). */
  }

  /* SVMShaderManager::device_update_shader (scene/svm.cpp:37-55). */
  void device_update_shader(Scene *scene,
                            Shader *shader,
                            Progress &progress,
                            array<int> *svm_nodes)
  {
    if (progress.get_cancel()) {
      return;
    }
    assert(shader->graph);

    SVMCompiler::Summary summary;
    SVMCompiler compiler(scene, progress);
    compiler.background = (shader == background_shader);
    compiler.compile(shader, *svm_nodes, 0, &summary);

    LOG_DEBUG << "Compilation summary:\n"
              << "Shader name: " << shader->name << "\n"
              << summary.full_report();
  }

  /* ShaderManager::device_update_common (scene/shader.cpp:612-748), reduced to the members of
   * the shim Shader and ShaderManager. */
  void device_update_common(Device * /*device*/,
                            DeviceScene *dscene,
                            Scene *scene,
                            Progress & /*progress*/)
  {
    dscene->shaders.clear();

    if (scene->shaders.empty()) {
      return;
    }

    /* A host array: resize() where upstream allocates a device_vector (:623). */
    KernelShader *kshader = dscene->shaders.resize(scene->shaders.size());
    bool has_transparent_shadow = false;

    for (Shader *shader : scene->shaders) {
      uint flag = 0;

      /* Left out: SD_MIS_FRONT, SD_MIS_BACK and SD_HAS_EMISSION (:629-641) and
       * SD_HAS_CONSTANT_EMISSION (:690-693). They come from the emission estimate, which painterly
       * does not compute (Shader::estimate_emission, shim scene/shader.h). */
      if (shader->has_surface_transparent && shader->get_use_transparent_shadow()) {
        flag |= SD_HAS_TRANSPARENT_SHADOW;
      }
      if (shader->has_surface_raytrace) {
        flag |= SD_HAS_RAYTRACE;
      }
      if (shader->has_volume) {
        flag |= SD_HAS_VOLUME;
        /* todo: this could check more fine grained, to skip useless volumes
         * enclosed inside an opaque bsdf.
         */
        flag |= SD_HAS_TRANSPARENT_SHADOW;
      }
      /* in this case we can assume transparent surface */
      if (shader->has_volume_connected && !shader->has_surface) {
        flag |= SD_HAS_ONLY_VOLUME;
      }
      if (shader->has_volume && shader->has_volume_spatial_varying) {
        flag |= SD_HETEROGENEOUS_VOLUME;
      }
      if (shader->has_volume_attribute_dependency) {
        flag |= SD_NEED_VOLUME_ATTRIBUTES;
      }
      if (shader->has_bssrdf_bump) {
        flag |= SD_HAS_BSSRDF_BUMP;
      }
      if (shader->get_volume_sampling_method() == VOLUME_SAMPLING_EQUIANGULAR) {
        flag |= SD_VOLUME_EQUIANGULAR;
      }
      if (shader->get_volume_sampling_method() == VOLUME_SAMPLING_MULTIPLE_IMPORTANCE) {
        flag |= SD_VOLUME_MIS;
      }
      if (shader->get_volume_interpolation_method() == VOLUME_INTERPOLATION_CUBIC) {
        flag |= SD_VOLUME_CUBIC;
      }
      if (shader->has_bump_from_displacement) {
        flag |= SD_HAS_BUMP_FROM_DISPLACEMENT;
      }
      if (shader->has_bump_from_surface) {
        flag |= SD_HAS_BUMP_FROM_SURFACE;
      }
      if (shader->get_displacement_method() != DISPLACE_BUMP) {
        flag |= SD_HAS_DISPLACEMENT;
      }
      if (shader->get_use_bump_map_correction()) {
        flag |= SD_USE_BUMP_MAP_CORRECTION;
      }

      if (shader->has_light_path_node) {
        flag |= SD_HAS_LIGHT_PATH_NODE;
      }

      /* regular shader. Left out: pass_id, constant_emission and cryptomatte_id (:699-708),
       * which no painterly pass uses; they stay 0. */
      *kshader = KernelShader{};
      kshader->flags = flag;
      kshader++;

      has_transparent_shadow |= (flag & SD_HAS_TRANSPARENT_SHADOW) != 0;
    }

    /* Left out: the BSDF lookup tables (:714-729). They need scene/shader.tables and the
     * LookupTables of scene/tables.h, which no M6a node before the closure evaluators reads. */

    /* integrator */
    KernelIntegrator *kintegrator = &dscene->data.integrator;
    kintegrator->transparent_shadows = has_transparent_shadow;

    /* film: of the color space (:736-747), only rgb_to_y (:742). The shim ShaderManager keeps
     * no other color-space member (card T6.4); NODE_CONVERT reads rgb_to_y
     * (kernel/util/colorspace.h:34-37). */
    KernelFilm *kfilm = &dscene->data.film;
    kfilm->rgb_to_y = make_float4(rgb_to_y);
  }
};

## Expected byte code
Derived by reading upstream code; the doctests check every word. `value_math_emission(v, "multiply", c, false, color)` is the
graph Value(v) → Math.Value1, Math(multiply, Value2 = c unlinked, Value3 = 0) → Emission.Strength, Emission.Color = color →
Output.Surface. Node ids follow creation order: Output 0 (the graph constructor creates it), Value 1, Math 2, Emission 3.

**Unfolded** (`prepare_unfolded`; `SVMCompiler::compile`, `scene/svm.cpp:1174-1236`), for v = 0.75, c = 4,
color = (0.25, 0.5, 1):
- Words 0-3: the local jump node `NODE_SHADER_JUMP {0, 0, 0}` (`:1176-1179`). There is no bump shader
  (`has_bump_from_displacement` is false), so the surface start goes to word 1 (`:1204-1206`).
- Surface (`compile_type`, `:1036-1172`). `has_surface` selects `KERNEL_FEATURE_NODE_MASK_SURFACE` (`:1110-1112`);
  `generate_multi_closure` (`:845-997`) reaches `generate_closure_node(Emission)` (`:758-807`), which first generates the
  dependencies of Strength, {Value, Math}, with `generate_svm_nodes` (`:606-756`). Math is the only sink, Value its producer:
  - Value (`ValueNode::compile`, `scene/shader_nodes.cpp:5241-5244`): `output("Value")` takes the first free stack slot, 0
    (`stack_find_offset`, `:206-238`). Words 4-6: `NODE_VALUE_F {value = 0.75, out_offset = 0}`.
  - Math (`scene/shader_nodes.cpp:6970-6981`): Value1 is linked, so `input_float` returns
    `SVM_INPUT_STACK_OFFSET_MASK | 0`; Value2 and Value3 are unlinked constants (`:310-322`); the result takes slot 1, since
    slot 0 is still in use. Words 7-12: `NODE_MATH {multiply, stack 0, 4, 0, result_offset = 1}`. `stack_clear_users` then
    frees slot 0 (`:402-422`).
  - The closure's `SurfaceMixWeight` is 1 and unlinked, so `mix_weight_offset` stays `SVM_STACK_INVALID` (`:776-786`).
  - Emission (`scene/shader_nodes.cpp:3072-3099`): Strength is linked, so words 13-17 are
    `NODE_EMISSION_WEIGHT {color = (0.25, 0.5, 1) as constants, strength = stack 1}` and words 18-19
    `NODE_CLOSURE_EMISSION {mix_weight_offset = SVM_STACK_INVALID}`.
  - `OutputNode::compile` emits nothing outside displacement (`:6576-6587`); word 20 is `NODE_END` (`svm.cpp:1169-1171`).
- Volume and displacement: no link, so only `NODE_END`, words 21 and 22. The jump node is `{4, 21, 22}`; 23 words in all.
- `Summary`: `num_svm_nodes` = 23 − 4 = 19 and `peak_stack_usage` = 2, slots 0 and 1 (`:1228-1232`).
- `KernelData::svm_usage` marks exactly `NODE_END`, `NODE_SHADER_JUMP`, `NODE_VALUE_F`, `NODE_MATH`,
  `NODE_EMISSION_WEIGHT` and `NODE_CLOSURE_EMISSION` (`:169`, `:436`, `:1176`; `scene/svm.h:105`).
- Evaluation: slot 1 = 0.75 · 4 = 3, emission = (0.25, 0.5, 1) · 3 = (0.75, 1.5, 3), all exact in float. The fetch trace
  (T6.3's support header records each `svm_nodes` index read) is the jump entry's type and struct word, then each node's
  type and first struct word, then `NODE_END`: `0 1 4 5 7 8 13 14 18 19 20` (`kernel/svm/svm.h:112-136`; `svm_node_get`,
  `kernel/svm/util.h:204-213`).

**Folded** (`device_update_pre` → `ShaderGraph::finalize`): Value and Math fold into Strength = 3 (`ValueNode` and
`MathNode::constant_fold`, `scene/shader_nodes.cpp:5236-5239, 6939-6947`), `clean()` removes them, and the lone closure gets
`SurfaceMixWeight` 0 + 1. Emission has no link, so words 4-7 are `NODE_CLOSURE_SET_WEIGHT {rgb = color · strength =
(0.75, 1.5, 3)}` (`:3085-3092`), 8-9 `NODE_CLOSURE_EMISSION`, 10-12 three `NODE_END`; jump `{4, 11, 12}`; trace
`0 1 4 5 8 9 10`.

**Two unfolded shaders packed** (`device_update_specific`, `scene/svm.cpp:95-134`): words 0-7 are the two jump nodes;
shader 0's 19 node words follow at 8-26 with its offsets moved by 8 − 4, `{8, 25, 26}`; shader 1's at 27-45, `{27, 44, 45}`.
Shader 1 is v = 0.5, c = 8: emission (1, 2, 4). Traces `0 1 8 9 11 12 17 18 22 23 24` and
`4 5 27 28 30 31 36 37 41 42 43`.

**`KernelShader::flags`** of every shader here, as `PainterlyShaderManager` computes them:
`SD_VOLUME_MIS | SD_USE_BUMP_MAP_CORRECTION`. Of the conditions that the port keeps, only `:671-673` and `:686-688` of
`device_update_common` hold, from the defaults `volume_sampling_method = multiple_importance` and
`use_bump_map_correction = true` (`scene/shader.cpp:52, 58-61`). These are the port's flags, not upstream's. Upstream would
also set flags from `Shader::estimate_emission()` (`scene/shader.cpp:239-281`), which the port leaves out (Decision 5; the
shim's `estimate_emission()` is empty):
- `SD_HAS_EMISSION` and `SD_MIS_FRONT | SD_MIS_BACK` (`:629-641`): the estimate is (0.25, 0.5, 1) for the unfolded shaders
  and (0.75, 1.5, 3) for the folded one, nonzero, and its largest component exceeds 0.5 under the default
  `emission_sampling_method = auto` (`:40-49, 254-280`);
- `SD_HAS_CONSTANT_EMISSION` (`:690-693`) for the folded shader, whose Emission node has no linked input (`:132-163, 242`).

**Independent reference** (`reference_math()`): for 16 Math operations, the float32 result equals the operation computed in
double and rounded once to float32.
- +, −, ×, ÷ and √ of float32 operands: IEEE 754 makes Cycles' float32 result the exact value correctly rounded, and rounding
  the double result again gives the same float because double has 53 ≥ 2 · 24 + 2 significand bits (Figueroa, "When is
  double rounding innocuous?", SIGNUM Newsletter 30(3), 1995). Fraction is `a − floorf(a)`, a subtraction of two floats.
- abs, floor, ceil, trunc, fmod, min, max, the comparisons and sign are exact in both precisions.
- Cycles' values at 0 are part of each definition: division and modulo by 0 give 0 (`util/math_base.h:594-597, 608-611`),
  sqrt of x ≤ 0 gives 0 (`:538-541`), the sign of 0 is 0 (`:491-497`).
- Comparison is IEEE `==`, so +0 equals −0 (`fminf`/`fmaxf` may return either zero for equal zeros). No result is NaN: the
  inputs are finite, and no operation here makes NaN from finite inputs. Opus's prototype found 0 mismatches on all 16
  operations, 861 mismatches of 4162 when its reference computed division as `x` times the float reciprocal of `y`, and
  4150 when it swapped the operands of subtraction.

/* Value -> Math -> Emission -> Output.Surface. Value `value` feeds Math.Value1. Math.Value2 is
 * `value2`, linked from a second Value node if `link_value2`, else an unlinked default.
 * Math.Value3 keeps its default 0. Math feeds Emission.Strength; Emission.Color is `color`. */
unique_ptr<ShaderGraph> value_math_emission(const float value,
                                            const char *math_type,
                                            const float value2,
                                            const bool link_value2,
                                            const float3 color)
{
  unique_ptr<ShaderGraph> graph = make_unique<ShaderGraph>();
  ShaderNode *value_node = create_node_by_name(*graph, "value");
  ShaderNode *math = create_node_by_name(*graph, "math");
  ShaderNode *emission = create_node_by_name(*graph, "emission");
  value_node->set(parameter(value_node, "value"), value);
  math->set(parameter(math, "math_type"), ustring(math_type));
  if (link_value2) {
    ShaderNode *value2_node = create_node_by_name(*graph, "value");
    value2_node->set(parameter(value2_node, "value"), value2);
    graph->connect(value2_node->output("Value"), math->input("Value2"));
  }
  else {
    math->input("Value2")->set(value2);
  }
  emission->input("Color")->set(color);
  graph->connect(value_node->output("Value"), math->input("Value1"));
  graph->connect(math->output("Value"), emission->input("Strength"));
  graph->connect(emission->output("Emission"), graph->output()->input("Surface"));
  return graph;
}

/* Adds a referenced shader with `graph` to the scene. */
Shader *add_shader(Scene &scene, unique_ptr<ShaderGraph> &&graph)
{

  shader->set_graph(std::move(graph));
  shader->reference();
  scene.shaders.push_back(std::move(shader));
  return scene.shaders[scene.shaders.size() - 1];
}

/* Prepares an unfinalized graph as device_update_pre and ShaderGraph::finalize would for a lone
 * surface closure, without constant folding: the shader id is its index, the surface is linked
 * (scene/shader.cpp:533, 558), and the closure's SurfaceMixWeight is 0 + 1
 * (ShaderGraph::transform_multi_closure, scene/shader_graph.cpp:1149-1187). */
void prepare_unfolded(Scene &scene)
{
  uint id = 0;
  for (Shader *shader : scene.shaders) {
    shader->id = id++;
    shader->has_surface = true;
    ShaderNode *closure = shader->graph->output()->input("Surface")->link->parent;
    closure->input("SurfaceMixWeight")->set(1.0f);
  }
}

/* The words that SVMCompiler::add_node(shader_node, type, node) appends (scene/svm.h:95-112). */
template<typename T> void push_node(vector<int> &words, const ShaderNodeType type, const T &node)
{
  words.push_back(type);
  const size_t first = words.size();
  words.resize(first + sizeof(T) / sizeof(int));
  std::memcpy(&words[first], &node, sizeof(T));
}

/* The surface program that SVMCompiler emits for value_math_emission(value, type, value2, false,
 * color) without constant folding (card T6.5, "Expected byte code"). */
void push_unfolded_surface(vector<int> &words,
                           const float value,
                           const NodeMathType math_type,
                           const float value2,
                           const float3 color)
{
  push_node(words, NODE_VALUE_F, SVMNodeValueF{.value = value, .out_offset = 0});
  push_node(words,
            NODE_MATH,
            SVMNodeMath{.math_type = math_type,
                        .value1 = painterly_svm_input_stack(0),
                        .value2 = painterly_svm_input_constant(value2),
                        .value3 = painterly_svm_input_constant(0.0f),
                        .result_offset = 1});
  push_node(
      words,
      NODE_EMISSION_WEIGHT,
      SVMNodeEmissionWeight{.color = painterly_svm_input_constant3(color.x, color.y, color.z),
                            .strength = painterly_svm_input_stack(1)});
  push_node(words,
            NODE_CLOSURE_EMISSION,
            SVMNodeClosureEmission{.mix_weight_offset = SVM_STACK_INVALID});
  words.push_back(NODE_END);
}

vector<int> to_vector(const array<int> &words)
{
  return vector<int>(words.data(), words.data() + words.size());
}

/* Evaluates the surface shader `shader_id` of `dscene` with the generated svm_eval_nodes(), as

{

  globals.svm_nodes.data = reinterpret_cast<const uint *>(dscene.svm_nodes.data());
  globals.svm_nodes.width = int(dscene.svm_nodes.size());
  globals.shaders.data = dscene.shaders.data();
  globals.shaders.width = int(dscene.shaders.size());
  globals.data = dscene.data;

/* KernelShader::flags of the shaders in these tests. Of the conditions that PainterlyShaderManager
 * ports, only the defaults volume_sampling_method = multiple_importance and
 * use_bump_map_correction = true hold (scene/shader.cpp:52, 58-61; device_update_common,
 * scene/shader.cpp:671-673, 686-688). For these shaders upstream would also set SD_HAS_EMISSION,
 * SD_MIS_FRONT and SD_MIS_BACK (:629-641), and for the folded one SD_HAS_CONSTANT_EMISSION
 * (:690-693), all from Shader::estimate_emission() (:239-281), which the port leaves out. */
constexpr int default_shader_flags = SD_VOLUME_MIS | SD_USE_BUMP_MAP_CORRECTION;

/* The value of Math operation `type` on float32 inputs a and b, computed in double precision and
 * rounded to float32 once: a reference that shares no code with Cycles.
 * - +, -, *, / and sqrt: IEEE 754 makes Cycles' float32 result the exact value correctly rounded.
 *   Rounding the double result again gives the same float, because double has 53 >= 2 * 24 + 2
 *   significand bits (Figueroa, "When is double rounding innocuous?", SIGNUM 1995). Fraction is
 *   a - floor(a), a subtraction of two floats.
 * - abs, floor, ceil, trunc, fmod, min, max, the comparisons and sign are exact.
 * - Cycles' definitions at 0 are part of the operation: division and modulo by 0 give 0
 *   (util/math_base.h:594-597, 608-611), sqrt of x <= 0 gives 0 (:538-541), sign of 0 is 0
 *   (:491-497). */
float reference_math(const NodeMathType type, const float a, const float b)
{
  const double x = a;
  const double y = b;
  switch (type) {
    case NODE_MATH_ADD:
      return float(x + y);
    case NODE_MATH_SUBTRACT:
      return float(x - y);
    case NODE_MATH_MULTIPLY:
      return float(x * y);
    case NODE_MATH_DIVIDE:
      return (b != 0.0f) ? float(x / y) : 0.0f;
    case NODE_MATH_MINIMUM:
      return (a < b) ? a : b;
    case NODE_MATH_MAXIMUM:
      return (a > b) ? a : b;
    case NODE_MATH_LESS_THAN:
      return (a < b) ? 1.0f : 0.0f;
    case NODE_MATH_GREATER_THAN:
      return (a > b) ? 1.0f : 0.0f;
    case NODE_MATH_ABSOLUTE:
      return float(std::fabs(x));
    case NODE_MATH_SQRT:
      return (a > 0.0f) ? float(std::sqrt(x)) : 0.0f;
    case NODE_MATH_FLOOR:
      return float(std::floor(x));
    case NODE_MATH_CEIL:
      return float(std::ceil(x));
    case NODE_MATH_TRUNC:
      return float(std::trunc(x));
    case NODE_MATH_FRACTION:
      return float(x - std::floor(x));
    case NODE_MATH_MODULO:
      return (b != 0.0f) ? float(std::fmod(x, y)) : 0.0f;
    case NODE_MATH_SIGN:
      return (a > 0.0f) ? 1.0f : ((a < 0.0f) ? -1.0f : 0.0f);
    default:
      return std::numeric_limits<float>::quiet_NaN();
  }
}

TEST_CASE("cycles svm compiler: device_update_pre folds the graph and the folded program agrees")
{
  const unique_ptr<Scene> scene = make_scene();
  Shader *shader = add_shader(
      *scene, value_math_emission(0.75f, "multiply", 4.0f, false, make_float3(0.25f, 0.5f, 1.0f)));
  Progress progress;
  PainterlyShaderManager &manager = shader_manager(*scene);
  manager.device_update_pre(nullptr, &scene->dscene, scene.get(), progress);

  /* ShaderGraph::finalize: Value and Math fold into Emission.Strength = 3, clean() removes them,
   * and the lone closure gets SurfaceMixWeight 0 + 1 (scene/shader_graph.cpp:374-402). */

TEST_CASE("cycles svm compiler: Math through compiler and SVM equals an independent reference")
{
  /* The operations whose float32 result reference_math() gives exactly, by Cycles name
   * (NODE_DEFINE(MathNode), scene/shader_nodes.cpp:6867-6909). */
  struct Operation {
    const char *name;
    NodeMathType type;
  };
  const Operation operations[] = {{"add", NODE_MATH_ADD},
                                  {"subtract", NODE_MATH_SUBTRACT},
                                  {"multiply", NODE_MATH_MULTIPLY},
                                  {"divide", NODE_MATH_DIVIDE},
                                  {"minimum", NODE_MATH_MINIMUM},
                                  {"maximum", NODE_MATH_MAXIMUM},
                                  {"less_than", NODE_MATH_LESS_THAN},
                                  {"greater_than", NODE_MATH_GREATER_THAN},
                                  {"absolute", NODE_MATH_ABSOLUTE},
                                  {"sqrt", NODE_MATH_SQRT},
                                  {"floor", NODE_MATH_FLOOR},
                                  {"ceil", NODE_MATH_CEIL},
                                  {"trunc", NODE_MATH_TRUNC},
                                  {"fraction", NODE_MATH_FRACTION},
                                  {"modulo", NODE_MATH_MODULO},
                                  {"sign", NODE_MATH_SIGN}};
  static_assert(std::size(operations) == 16);

  /* The inputs: every pair of ten special values (zeros of both signs, units, a half, dyadic
   * values, the largest, the smallest normal and the smallest subnormal float), then the finite
   * pairs among 4096 pairs of hashed float bit patterns. */
  const float special[] = {0.0f,
                           -0.0f,
                           1.0f,
                           -1.0f,
                           0.5f,
                           -2.5f,
                           3.0f,
                           std::numeric_limits<float>::max(),
                           std::numeric_limits<float>::min(),
                           std::numeric_limits<float>::denorm_min()};
  vector<std::pair<float, float>> inputs;
  for (const float a : special) {
    for (const float b : special) {
      inputs.emplace_back(a, b);
    }
  }
  const uint num_hashed = 4096;
  for (uint i = 0; i < num_hashed; i++) {
    const float a = __uint_as_float(hash_uint2(i, 0));
    const float b = __uint_as_float(hash_uint2(i, 1));
    if (std::isfinite(a) && std::isfinite(b)) {
      inputs.emplace_back(a, b);
    }
  }
  CHECK(inputs.size() == 4162);

  for (const Operation &operation : operations) {
    const std::string name = operation.name;
    CAPTURE(name);
    int mismatches_unfolded = 0;
    int mismatches_folded = 0;
    for (const auto &[a, b] : inputs) {
      const float expected = reference_math(operation.type, a, b);
      Progress progress;

      /* Compiled without folding: the SVM computes the operation. */
      const unique_ptr<Scene> unfolded = make_scene();
      add_shader(*unfolded,
                 value_math_emission(a, operation.name, b, true, make_float3(1.0f, 1.0f, 1.0f)));
      prepare_unfolded(*unfolded);
      shader_manager(*unfolded).device_update_post(
          nullptr, &unfolded->dscene, unfolded.get(), progress);
      PainterlySvmTrace trace;
      const ShaderData sd_unfolded = eval_surface(unfolded->dscene, 0, trace);
      /* Emission is Color (1, 1, 1) times the result: exact. */
      if (!(sd_unfolded.closure_emission_background.x == expected)) {
        mismatches_unfolded++;
      }

      /* Prepared as Cycles prepares it: MathNode::constant_fold computes the operation on the host
       * (scene/shader_nodes.cpp:6939-6947). A zero strength discards the emission
       * (scene/shader_nodes.cpp:3106-3114), which leaves the emission 0. */
      const unique_ptr<Scene> folded = make_scene();
      add_shader(*folded,
                 value_math_emission(a, operation.name, b, true, make_float3(1.0f, 1.0f, 1.0f)));
      shader_manager(*folded).device_update_pre(nullptr, &folded->dscene, folded.get(), progress);
      shader_manager(*folded).device_update_post(nullptr, &folded->dscene, folded.get(), progress);
      const ShaderData sd_folded = eval_surface(folded->dscene, 0, trace);
      if (!(sd_folded.closure_emission_background.x == expected)) {
        mismatches_folded++;
      }
    }
    CHECK(mismatches_unfolded == 0);
    CHECK(mismatches_folded == 0);
  }
}
