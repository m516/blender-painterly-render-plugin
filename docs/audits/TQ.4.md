# TQ.4 — Code-quality audit: the M6a milestone review

Auditors: two read-only Sonnet readers (the C++ half; the Python, generator and build half). Opus re-checked the three
Medium findings at their cited lines, and the claim about `static.yml`. Tree audited: `846f166`. This is the M6a milestone
review's audit (PLAN-TO-FINAL M6a.11), run on 2026-10-25. Scope: the ten M6a commits
- `203c431` (T6.1), `7483c1f` (T6.2), `d9efc3f` (T6.2-fix), `398abc9` (T6.3), `522f9bf` (M3-FIX-NODE24), `5fcd69d` (T6.4),
  `c02fab8` (T6.5), `b9f72f4` (T6.6), `e06f00a` (T6.7), `bb41b02` (T6.8).

The sprint's batch audits and landing readers had already filed M6a-FIX-SVMT, -VS1, -X011 and M8-FIX-NOTICES. This audit
excluded those; where a finding touches one, it says so.

## Method

- As TQ.3: static reading of the commits, tests first, plus read-only Python on committed text and on the pinned upstream
  checkout in `.cache/vendor/` (data only). Nothing was built or run.
- C++ half: an include-closure walk with the compiler's search order; line diffs of the shims and of `PainterlyShaderManager`
  against `.cache/vendor/blender-v5.2.2`; comment numbers re-derived. Paths under `third_party/` (including `fragments/`)
  are cited only to show how our code uses them.
- Python, generator and build half: both generators and `vendor_sync.offline_problems` and `check_fragments` run in memory;
  every fragment compared with the pinned blob (`git cat-file`); an `ast` and text scan of the 16 in-scope Python files; a
  text-level include closure of every source built with tests off; the workflows, CMake and experiment 011 read.
- Searched for: tests that cannot fail (each finding names the mutation that survives), code the build never compiles,
  silent failure paths, stale-build paths, numbers in comments that do not match the code, CLAUDE.md rule 2 and 3
  violations, CI coverage.
- Severity scale as in TQ.1 and TQ.3: **Medium**, a gap that lets regressions through, or a reproducibility problem with real
  cost; **Low**, consistency or hygiene. Line numbers are at `846f166`.

## Verdict

No finding blocks the M6a review. There are three Medium findings: F1 (assertions never run in any build), F2 with F14
(opcodes without a case end evaluation silently), and F13 (Clang and arm64 never compile 20 vendored files nor the
generated switch). The other 23 are Low.

Repository visibility is PUBLIC (`gh repo view`), so F20's Pages upload of the whole repository exposes nothing new. That
workflow is the owner's (commit 8c91752 by Micah), and it moves to M8's release review with F19.

The fix items are BACKLOG M6a-FIX-TQ4a, -TQ4b and -TQ4c. F3, F6(c) and F11 go to the M6b brief, card B1; F4 and F5 to card B2.
