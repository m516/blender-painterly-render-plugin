# T3.3 — Vendor Cycles `graph/` (Node/NodeType reflection) with an OIIO-free shim
Milestone: M3 · Depends on: T3.2 · Parallel-safe: no · **Gate G2 lives here**

## Goal
After this card, Cycles' reflection (`graph/node.h`, `graph/node_type.h`, `graph/node_enum.h`) compiles **unmodified** in our
namespace, so scene classes can use `NODE_DECLARE` / `NODE_DEFINE` / `SOCKET_*` exactly as Cycles does.

## Vendored files
- `graph/node.h`, `graph/node.cpp`, `graph/node_type.h`, `graph/node_type.cpp`, `graph/node_enum.h`.
- `util/md5.h` and `util/md5.cpp`.
- `util/path.h` (pure; `util/md5.cpp` includes it).
- Any further *pure* util headers the compiler requires. Use the closure tool.
- Before writing the shims below, check what T3.2 left (VENDORED.toml, and the shims listed in T3.2's report):
  - if T3.2 vendored any of `util/param.h`, `util/string.h`, `util/thread.h` or their sources `util/string.cpp`,
    `util/thread.cpp`, which this card shims, first un-vendor each with `tools/vendor_sync.py remove <dest>` (T3.1);
  - if T3.2 already shimmed one of them, extend that shim instead of creating it.

## Create or extend (shims in `src/cycles/shim/util/`, shadowing upstream paths; see T3.2 "Layout")
Create each shim below, or extend it if T3.2 already created it.
- `param.h`:
  - `ustring`: interned, immutable string. It has `ustring()`, `ustring(const char*)`, `ustring(std::string_view)`, `c_str()`, `string()`, `size()`, `empty()`, `==`/`!=`/`<`, `hash()`, and `std::hash<ustring>`.
  - `ustringhash` (alias or compatible type).
  - A `TypeDesc` subset with `TypeFloat`, `TypeColor`, … *only if used*. The constants in Cycles' `param.h` show what to mirror.
  - Implement interning with a global `std::unordered_set<std::string>` behind a `std::mutex`. Pointer equality is identity.
- `string.h`: `using string_view = std::string_view;` plus the declarations used by vendored files (`string_startswith`, `string_printf`, …), implemented in `src/cycles/shim/util/string.cpp`.
- `thread.h`: Cycles' API without TBB. `thread_mutex`, `thread_scoped_lock`, `thread_condition_variable` and the `thread` class.
  `thread_spin_lock` is a small `std::atomic_flag` spin lock with the same interface.
  - Implement `thread` in `src/cycles/shim/util/thread.cpp`, mirroring Cycles' `util/thread.cpp`: an explicit ≥ 2 MB stack on macOS/Linux-musl via pthreads, `std::thread` elsewhere.
- `path.cpp` (`src/cycles/shim/util/path.cpp`), starting with `Shim: replaces Cycles util/path.cpp without OIIO`. It defines
  only `FILE *path_fopen(const string &path, const string &mode)`, as upstream does (`std::fopen`; on Windows `_wfopen` of
  the UTF-16 path). That is the one `util/path.h` function vendored code calls (`util/md5.cpp:319`,
  `MD5Hash::append_file`).
- `src/test/test_graph.cpp` (doctest). Define a test node type with `NODE_DECLARE`/`NODE_DEFINE` and sockets of type bool, int, float, enum, transform and float3. Assert:
  - defaults;
  - set/get round trips;
  - `NodeType::find`;
  - enum lookup by name;
  - `is_modified()` / `tag_modified()` behaviour.
