- Diffuse, expression for expression:
  1. `*K += 1; u1 = vdc(*K)`.
  2. `u2 = (u2_mode == U2_SAME) ? u1 : rng_unit(seed, PURPOSE_U2, depth, row, col, pass)`.
  3. `r = sqrt(1.0 - u1*u1)`, `phi = 2 * SMALLPAINT_PI*u2`, `s = (cos(phi)*r, sin(phi)*r, u1)`.
  4. `d = N + transform_direction_3x3(spiral_frame, s)`.
  5. `d = d * pow(len(d), -alpha)`.
  6. `cost = dot(d, N)`.
- Mirror and glass mirror smallpaint's code exactly, including `N*-1` and the order of `n = 1 / n`.
