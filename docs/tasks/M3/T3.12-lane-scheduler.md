- `src/painterly/util/thread_pool.h` / `src/painterly/util/thread_pool.cpp`, in a static library `painterly_util` (`src/painterly/util/CMakeLists.txt`, linked to `cycles_util`):
  ```cpp
  /* Fixed pool of worker threads (Cycles' util/thread shim from T3.3, >= 2 MB stacks) with a blocking parallel_for over [0, n). Work items are
   * claimed with an atomic counter. Results must not depend on which worker runs which item. */
  class PainterlyThreadPool {
   public:
    explicit PainterlyThreadPool(int num_threads);   /* 0 = std::thread::hardware_concurrency() */
    ~PainterlyThreadPool();
    int num_threads() const;
    void parallel_for(int64_t n, const std::function<void(int64_t index, int worker)> &fn);
  };
  ```
- `src/painterly/integrator/buffers.h` / `.cpp` (in `painterly_integrator`, below; the integrator never includes `painterly/session/`):
  ```cpp
  struct PainterlyRenderBuffers {
    int width = 0, height = 0;
    std::vector<double> combined;     /* H*W*3 sums, row-major, row 0 = top */
    std::vector<uint64_t> k_consumed; /* H*W */
    std::vector<int32_t> object_id;   /* H*W */
    int passes_done = 0;
    void reset(int width, int height);
  };
  ```
- `src/painterly/integrator/path_trace.h` / `.cpp`. With `buffers.cpp` it forms the static library `painterly_integrator`
  (`src/painterly/integrator/CMakeLists.txt`, linked to `painterly_util` and `painterly_bvh`):
  ```cpp
  class PainterlyPathTrace {
   public:
    PainterlyPathTrace(const PainterlyGlobalsCPU &kg, PainterlyRenderBuffers &buffers, PainterlyThreadPool &pool);
    /* Render passes [pass_begin, pass_end) (SPEC §3 order). Returns false if `cancel` was observed.
     * CHAIN_IMAGE: single-threaded, K continues across calls. ROW/LANE: parallel over chains. */
    bool render_passes(int pass_begin, int pass_end, const std::atomic<bool> &cancel);
    /* Fill buffers.object_id (unjittered primary hits), parallel over rows. */
    void render_object_id();
   private:
    uint64_t image_chain_K_ = 0;
  };
  ```
  - Each worker has its own `std::vector<PainterlyPathVertex>` scratch of size `max_depth`.
  - **ROW/LANE**: units are (row, lane_in_row); ROW is one lane of length W. Per unit, per pass:
    `K = painterly_chain_start(...)`, then for each col in the lane: `r = painterly_trace_pixel(...)`, `painterly_film_accumulate`, `buffers.k_consumed[pixel] += r.k_consumed`.
  - Check `cancel` before each unit and between passes inside a unit.
  - On cancel, `passes_done` does not advance. Partial contributions may remain; document this.
  - On success: `passes_done = pass_end`.
- `src/test/test_path_trace.cpp` (analytic scenes, so the result does not depend on the ISA), on the 32×32 analytic
  smallpaint scene of `src/test/smallpaint_scene_fixture.h` (T3.11). For each chain ∈ {image, row, lane:5, lane:16}
  separately, the combined and k_consumed buffers are bitwise identical across threads ∈ {1, 2, 7} and across batching
  `render_passes(0,4)` vs `(0,1),(1,2),(2,4)`. Different chains are not compared with each other.
