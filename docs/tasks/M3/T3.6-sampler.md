## Create `src/painterly/kernel/sample/sampler.h`
All functions are `ccl_device_inline`. Exact signatures:
```cpp
/* Reverse the low 23 bits of k (bits above 23 are ignored). SPEC §2. */
ccl_device_inline uint painterly_bitrev23(uint k);
/* vdc(K) = bitrev23(K mod 2^23) * 2^-23; exact in double. SPEC §2. */
ccl_device_inline double painterly_vdc(uint64_t K);
/* SPEC §2 stateless RNG. */
ccl_device_inline uint painterly_rng_u32(uint seed, uint purpose, uint depth, uint a, uint b, uint c);
ccl_device_inline double painterly_rng_unit(uint seed, uint purpose, uint depth, uint a, uint b, uint c);
ccl_device_inline double painterly_rng_signed(uint seed, uint purpose, uint depth, uint a, uint b, uint c);
/* SPEC §3: K0 for CHAIN_ROW (lane_in_row = 0) and CHAIN_LANE, after k0_phase_lock_bits. */
ccl_device_inline uint64_t painterly_chain_start(const KernelPainterlyIntegrator &p, int row, int lane_in_row, int pass);
```
- `rng_unit = rng_u32 * 2^-32`, computed as `double(u) * 0x1p-32`. `rng_signed = 2 * unit - 1`, exactly SPEC §2.
  It must be bit-identical to the oracle's helpers.
- The 2^22 mask and the 2^23 period are named constants with SPEC citations:
  `PAINTERLY_K0_BITS = 22`, `PAINTERLY_VDC_BITS = 23`.
