# T3.16 — Exact parity: the native core reproduces smallpaint_oracle bit for bit
Milestone: M3 · Depends on: T3.15 · Parallel-safe: no

## Goal
Prove that the whole core (camera, sampler, bounces, ghosts, integrator, scheduler, film) equals the reference oracle **bitwise** on
analytic scenes. This is the strongest guarantee in the project; treat any mismatch as a bug to find, never as a tolerance to add.

## Create
- `tests/core/scenes.py`:
  - `apply_reference_knobs() -> dict` returns the smallpaint-unit knobs, the single source of their values, each commented with its
    smallpaint line: `diffuse_gain = float32(0.1)`, `emission_gain = 2`, `ray_epsilon = float32(1e-4)`, `max_depth = 20`,
    `spiral_frame = "smallpaint"` (F = I, SPEC §1). T4.3 moves it to `addon/sync/reference.py`. The values go to `set_integrator`
    unchanged: a float socket accepts any real number, `int` and numpy scalars included (T3.15), and stores its float32 value.
  - `build_smallpaint_scene(scene, *, size, ghost="all"|"lights"|"none", ior=1.5)` builds SPEC §9 with:
    - `add_material(lobes=[...], emission=...)`: diffuse objects `[("diffuse", cl, 0.0)]`; mirror `[("mirror", (1,1,1), 0.0)]`;
      glass `[("glass", (1,1,1), ior)]`; light `[("diffuse", (0,0,0), 0.0)]` with emission (120,120,120). smallpaint ignores `cl` for
      mirror and glass, and a unit tint is exact.
    - `add_sphere`/`add_plane` in SPEC §9 order with object_id = list index; ghost policy mapped per sphere (`lights`: only the emissive sphere is ghost);
    - `set_camera_smallpaint(size, size)`. The integrator socket `jitter` (a fraction of the image side, SPEC §7) stays at its
      default; tests read it as `jitter = scene.get_integrator()["jitter"]`. The oracle gets `--jitter repr(2 * float(np.float32(jitter)))`,
      the image-plane value the core computes (T3.13), and so stays bit-identical;
    - `scene.set_integrator(**apply_reference_knobs())`, and no other knob: every socket not in that dict keeps its default.
  - `ORACLE_EXACT_KNOBS`, derived from `apply_reference_knobs()`: the oracle options `diffuse_gain`, `emission_gain`, `ray_epsilon`
    (`--ray-epsilon`, T3.4) and `max_depth` with the same values, floats printed with `repr(float(np.float32(x)))`, plus
    `halton="exact"`. `spiral_frame` has no oracle option: the oracle's frame is always F = I.
- `tests/core/test_oracle_parity.py`, parametrized (size 48, passes 3, seeds 0 and 7). Oracle `--threads 1`; core threads 1 and 4, batch 1 and 2.
  It loads `scenes.py` by file path with `importlib.util.spec_from_file_location("scenes", Path(__file__).with_name("scenes.py"))`:
  pytest runs with `--import-mode=importlib` (pyproject.toml), which puts no test directory on `sys.path`, so `import scenes`
  fails at collection. Add no conftest.
  - Chains `image`, `row`, `lane:16`, `lane:5`. The core uses `chain=lane, lane_length=L`.
  - Ghost `all`, `lights`, `none`.
  - `alpha` ∈ {0, 0.5}; `u2` ∈ {same, independent}; `continue_after_emitter` ∈ {True, False}.
  - Use a pairwise selection that covers every value of every axis against chain `lane:16` and `image`, not the full product. Fast tests take about 30 s total.
  - Each test builds the scene with `build_smallpaint_scene(scene, size=..., ghost=...)`, then sets its own knobs with
    `scene.set_integrator(chain=..., lane_length=..., seed=..., alpha=..., u2_mode=..., continue_after_emitter=...)`. The oracle
    gets `ORACLE_EXACT_KNOBS`, `--jitter repr(2 * float(np.float32(jitter)))` with `jitter = scene.get_integrator()["jitter"]`,
    `--size`, `--passes`, `--threads 1`, and the same per-test values: `--chain` (`lane:L` for `chain="lane", lane_length=L`),
    `--seed`, `--alpha`, `--u2`, `--continue-after-emitter` and `--ghost`.
  - Assert, as `np.array_equal`:
    - `session.combined() == oracle.sum`;
    - `session.k_consumed() == oracle.k_consumed`;
    - `session.object_id() == oracle.object_id`.
- One `@pytest.mark.slow` test: size 400, passes 8, the default reference config: the core scene from
  `build_smallpaint_scene` plus `scene.set_integrator(chain="image")`, and the oracle with `ORACLE_EXACT_KNOBS`, `--chain image` and
  `--jitter repr(2 * float(np.float32(scene.get_integrator()["jitter"])))`. Bitwise equal.

## If parity fails
Debug by bisection:
1. Compare the object-id map first (camera and intersection).
2. Then `max_depth = 1` (emission only).
3. Then `max_depth = 2` (first bounce).
4. Then larger depths.
Each mismatch is a real defect in the core or the oracle. Report it precisely: the first mismatching pixel, depth and expression.
Fix it in the core if the core deviates from SPEC. If the SPEC or the oracle is ambiguous, stop and escalate.
