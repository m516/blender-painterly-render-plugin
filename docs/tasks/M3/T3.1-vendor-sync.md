# T3.1 — `tools/vendor_sync.py`: pinned, hash-checked vendoring of Cycles sources
Milestone: M3 · Depends on: M2 · Parallel-safe: no

## Goal
After this card:
- Vendored Cycles files under `third_party/cycles/` are reproducible from one pinned upstream revision.
- Each file is verified by sha256. Changes are expressed only as patch files.
- `make vendor-check` proves the tree matches the manifest.

## Read first
- `CLAUDE.md` rules 1 and 5 and "Network notes"
- `docs/plan.md` "Architecture"

## Upstream pin
- Repository: https://github.com/blender/blender.git
- Tag `v5.2.2`, commit `d13f752e3b9c4f8c261cda552b1021f8bcc0382c`
- Paths `intern/cycles/**` and `extern/sse2neon/**`

## Create
- `tools/vendor_sync.py` (stdlib + git CLI), with subcommands:
  - `fetch`:
    1. `git clone --depth 1 --branch v5.2.2 --filter=blob:none --sparse https://github.com/blender/blender.git .cache/vendor/blender-v5.2.2`;
    2. `git sparse-checkout set intern/cycles extern/sse2neon`;
    3. verify that `git rev-parse HEAD` equals the pinned commit.
    It is idempotent.
  - `sync`: for every entry in `third_party/cycles/VENDORED.toml`, copy `upstream_path` → `third_party/cycles/<dest>`, then apply `third_party/cycles/patches/*.patch` in lexical order with `git apply`.
  - `check`, in two steps:
    1. Without network: the sha256 of each vendored file equals the `sha256` in VENDORED.toml. That hash is of the *post-patch* file; record `upstream_sha256` too.
    2. With `--upstream` (needs fetch): re-derive every file from upstream + patches and compare byte-for-byte.
  - `add <upstream_path>... [--dest-prefix ...]`: append entries to VENDORED.toml, then sync.
  - `closure <seed headers...>`: print the transitive `#include "..."` closure inside `intern/cycles`. Missing headers are listed separately; they are shim candidates.
- `third_party/cycles/VENDORED.toml`: `[upstream]` with repo, tag, commit; then `[[file]]` entries with `upstream_path`, `dest`, `upstream_sha256`, `sha256`, `patched` (bool). Start with the list empty.
- `third_party/cycles/README.md`:
  - Apache-2.0 licence and provenance.
  - "Never hand-edit. Change upstream pin or add a patch in patches/ and run `tools/vendor_sync.py sync`."
  - Patched files carry the comment `Modified by the Painterly project` inside the patch.
- `third_party/cycles/patches/.gitkeep`
- `tests/core/test_vendored.py`: runs `tools/vendor_sync.py check` (offline mode) and asserts exit code 0.

## Modify
- `Makefile`: `vendor-check:` → `.venv/bin/python tools/vendor_sync.py check`; add it to `check`.

## Acceptance

- `tools/vendor_sync.py closure util/hash.h util/math.h util/types.h util/transform.h` lists about 45 files and no missing ones.
- `make check` passes.
