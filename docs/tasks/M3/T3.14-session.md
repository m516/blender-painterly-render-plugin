## Create `src/painterly/session/session.h/.cpp` and `src/painterly/session/CMakeLists.txt` (static lib `painterly_session`; links `painterly_integrator` and `painterly_scene`)
```cpp
/* Python state strings: 'idle', 'rendering', 'done', 'cancelled', 'error'. */
enum class PainterlySessionState { STATE_IDLE, STATE_RENDERING, STATE_DONE, STATE_CANCELLED, STATE_ERROR };
struct PainterlySessionProgress { PainterlySessionState state; int passes_done; int passes_total; double elapsed; std::string error; };
class PainterlySession {
 public:
  PainterlySession(const PainterlyScene &scene, int threads);   /* copies nothing yet */
  ~PainterlySession();                                 /* cancels and joins */
  void start(int passes, int batch);          /* snapshot: scene.device_update(device_scene_) on the caller thread, then render on a worker thread */
  bool wait(double timeout_seconds);          /* < 0: wait forever. True if the state is no longer STATE_RENDERING */
  void cancel();
  PainterlySessionProgress progress() const;
  PainterlyRenderBuffers buffers_copy() const;         /* consistent copy taken under the mutex between batches */
};
```
- The render thread runs `render_object_id()` once, then `render_passes(b, min(b + batch, passes))` per batch.
  - After each batch it publishes `passes_done` and a buffer snapshot under the mutex. Copy only the finished batch state; avoid tearing.
- Exceptions on the render thread → `STATE_ERROR` with the message.
- `start()` while `STATE_RENDERING` throws `std::logic_error`.
- `src/test/test_session.cpp`:
  - start/wait on a 32×32 analytic `PainterlyScene` built in `test_session.cpp` through the `PainterlyScene` API (the SPEC §9 objects via `add_material`/`add_sphere`/`add_plane`, `set_camera_smallpaint(32, 32)`) gives `STATE_DONE` with `passes_done == passes`;
  - after `cancel()` during a 1000-pass render, `wait()` returns True with `STATE_CANCELLED` and `passes_done < passes`; record and
    report the latency from `cancel()` to the return of `wait()` (no threshold);
  - the destructor during a render is safe;
  - the buffers equal a direct `PainterlyPathTrace` run.
