## Create `src/painterly/kernel/camera/camera.h`
```cpp
/* smallpaint's PI macro (smallpaint_painterly.cpp:33). It is NOT M_PI: it is needed for bit-identical parity. */
constexpr double SMALLPAINT_PI = 3.1415926536;

/* Primary ray for pixel (row, col) of `pass`. jittered=false gives the unjittered ray used by the object-id pass.
 * Directions are unit length (smallpaint normalizes primary rays, painterly.cpp:293). */
ccl_device_inline PainterlyRay painterly_camera_generate_ray(PainterlyGlobals kg, int row, int col, int pass, bool jittered);
```
- **PAINTERLY_CAMERA_SMALLPAINT** reproduces `camcr(row, col)` expression for expression, with `float fovx = SMALLPAINT_PI / 4;`,
  `float fovy = (h / w) * fovx;` and **`tan((double)fovx)` / `tan((double)fovy)`** (SPEC §7, oracle change 14).
  - Then `cam.x = cam.x + rng_signed(seed, PURPOSE_JITTER_X, 0, row, col, pass) * jitter`, the same for y, and finally `d = normalize(cam - o)` with `o = 0`.
- **PAINTERLY_CAMERA_PERSPECTIVE**.
  1. Raster point `(col + 0.5 + jx, row + 0.5 + jy, 0, 1)`, where `jx`/`jy` = `rng_signed(...) * jitter` in pixels, or 0 if not jittered.
  2. `p = raster_to_camera · point`; `Pc = p.xyz / p.w`; `dc = normalize(Pc)`.
  3. World ray: `o = translation(camera_to_world)`, `d = normalize(R · dc)`, where R is the 3×3 part.
- **PAINTERLY_CAMERA_ORTHOGRAPHIC**: `Pc` as above; camera-space origin `(Pc.x, Pc.y, 0)`, direction `(0, 0, −1)`; transform to world and normalize d.
