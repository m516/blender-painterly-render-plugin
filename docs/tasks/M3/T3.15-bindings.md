## Modify / Create
- `src/blender/python.cpp`: bind `version_info`, `selftest`, `integrator_sockets`, `Scene` and `Session`. The Python names are the contract's; they bind the C++ classes `PainterlyScene` and `PainterlySession`. Bind `Session.__init__` with `nb::keep_alive<1, 2>()`. `PainterlySession` holds a reference to its `PainterlyScene` until `start()` takes the snapshot (T3.14), so the Python `Scene` must outlive the `Session`.
  - `integrator_sockets()` merges `NodeType` socket data (name, type, default, enum items in C++ enum value order) with `painterly_integrator_ui_info()`.
  - `Scene.set_integrator(**knobs)`:
    - looks up sockets by name;
    - converts Python values by socket type, with enums given by identifier string;
    - a `float` socket accepts any real number, i.e. any object with `__float__` (`int`, `float` and numpy scalars included), and
      stores its float32 value. Convert as `PyFloat_AsDouble` does, never with a strict `PyFloat_Check` or
      `nb::isinstance<nb::float_>` test: T3.16 and T4.3 pass numpy float32 scalars and `int`s;
    - raises `ValueError` on unknown names, wrong types, enum identifiers that are not in the socket's items, and values that
      break a kernel precondition of `painterly/kernel/types.h`: `lane_length < 1`, or `k0_phase_lock_bits` outside 0…22
      (SPEC §3: K0 has 22 bits; `1u << q` is undefined from q = 32). These are the pyi's "bad values"; every other range is a
      UI limit (T3.13).
  - `get_integrator()` returns the current values.
  - Array inputs require the exact dtype, C-contiguous, and the stated shapes. Wrong input raises `TypeError` or `ValueError` with a clear message; there is no silent conversion.
  - `Session.wait` and `start` release the GIL. `combined()`, `k_consumed()` and `object_id()` return new numpy arrays copied from `buffers_copy()`.
- `tests/core/test_api_contract.py`:
  - every public function and class in `_painterly.pyi` exists on the module with matching parameter names (TypedDicts and type
    aliases are excluded). Parse the `.pyi` with `ast`, then use `inspect`/`__nb_signature__` or nanobind stubgen.
  - Every `integrator_sockets()` entry has all `SocketInfo` keys, and enum items match.
  - Wrong dtypes and shapes raise.
  - A float socket set to `np.float32(0.1)`, to `0.1` and to the `int` `2` reads back from `get_integrator()` as
    `float(np.float32(0.1))`, `float(np.float32(0.1))` and `2.0`, compared with `==`.
  - `set_integrator(lane_length=0)` and `set_integrator(k0_phase_lock_bits=23)` raise ValueError.
- `src/blender/CMakeLists.txt`: link `painterly_session` etc. Keep the export map and static runtime flags.
