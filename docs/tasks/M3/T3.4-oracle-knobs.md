# T3.4 — Oracle: expose the remaining smallpaint constants as knobs (bit-identical defaults)
Milestone: M3 · Depends on: T3.3 · Parallel-safe: no

## Goal
The native core reflects its knobs as float32 sockets, so parity tests must run the oracle with the *same* values.
- `0.1` becomes the float32 value 0.100000001490116…
- `2` stays exactly 2.
- `1e-4` becomes 9.99999974737875e-05.

This card adds CLI knobs to the oracle. Their **defaults are the original literals**, so default output is byte-identical to today's.

## Read first
- `src/app/smallpaint_oracle.cpp`, `src/app/CHANGES.md`
- `docs/spec.md` §4, §5, §6

## Modify
- `src/app/smallpaint_oracle.cpp`. Add globals and CLI flags; each default equals the literal it replaces:
  - `--diffuse-gain` (double, default `0.1`): replaces the `*0.1` in the three diffuse lines, keeping the expression shape `cost*(tmp.x*cl.x)*g_diffuse_gain`.
  - `--emission-gain` (double, default `2`): replaces `* 2` on the emission line.
  - `--eps` (double, default `1e-4`): replaces the `eps` constant. Make `eps` a mutable global, used everywhere it is used now.
  - `--max-depth` (int, default `20`): replaces `if (depth >= 20)`.
  - Parse doubles with `std::strtod` so that a printed float32 value round-trips exactly.
- `src/app/CHANGES.md`: append the new entries.
- `tests/oracle/test_oracle_contract.py`: add `test_new_knobs_default_identity`. Passing the defaults explicitly (`diffuse_gain=0.1, emission_gain=2, eps=1e-4, max_depth=20`) must give byte-identical `sum.npy` to omitting them.
