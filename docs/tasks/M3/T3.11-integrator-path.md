## Algorithm (normative; SPEC §6)
Forward walk:
```
ray = painterly_camera_generate_ray(kg, row, col, pass, true); n = 0
for depth = 0, 1, ...:
  if depth >= max_depth: break                        # child contributes 0 (painterly.cpp:190)
  if !painterly_scene_intersect: scratch[n++] = {END, 0.0 + painterly_background_radiance(kg, ray.d)*emission_gain}; break
  P = ray.o + ray.d * isect.t; N = normal; ray.o = P
  mat = materials[...]; e = mat.emission
  if isect.kind == HIT_ANALYTIC && analytic[isect.index].spot.enabled:
    e = e * painterly_spot_attenuation(analytic[isect.index].spot, N)   # N = normalize(P - c), SPEC §5
  e_term = per channel 0.0 + (e * emission_gain)       # painterly.cpp:200; non-spot hits keep smallpaint's op order
  if !continue_after_emitter && mat.emission > 0: scratch[n++] = {END, e_term}; break
  lobe = painterly_select_lobe(kg, mat, row, col, pass, depth)        # weight already divided by p
  DIFFUSE:     cost = painterly_diffuse_bounce(...); scratch[n++] = {DIFFUSE, e_term, cost, lobe.weight}
  MIRROR:      painterly_mirror_bounce(N, &ray); scratch[n++] = {PASS, e_term, 0, lobe.weight}
  GLASS:       N_glass = (isect.kind == HIT_TRIANGLE) ? painterly_triangle_shading_normal(kg, isect, ray, false) : N
               if !painterly_glass_bounce(N_glass, lobe.ior, &ray): scratch[n++] = {END, e_term}; break
               scratch[n++] = {PASS, e_term, 0, lobe.weight}
  TRANSPARENT: (ray.o is already P; ray.d unchanged); scratch[n++] = {PASS, e_term, 0, lobe.weight}
```
Backward evaluation:
```
L = (0,0,0)
for i = n-1 … 0:
  Li = scratch[i].emission_term
  DIFFUSE: Li.x = Li.x + cost*(L.x*color.x)*diffuse_gain  (same for y, z)    # painterly.cpp:209-211, same op order
  PASS:    Li = Li + L * color    (per channel Li.x + (L.x*color.x); color = (1,1,1) is exact: smallpaint's `clr + tmp`)
  END:     (nothing)
  L = Li
```
- `background * emission_gain` uses the same `0.0 + (x * g)` form.
- The emitter test is `emission.x > 0 || emission.y > 0 || emission.z > 0`.
- Analytic hits use `painterly_analytic_normal`. Triangle hits use `painterly_triangle_shading_normal(…, kp.two_sided != 0)` (`KernelPainterlyIntegrator::two_sided`, SPEC §6), except for the glass lobe, which uses `painterly_triangle_shading_normal(…, false)`.

## Create `src/test/smallpaint_scene_fixture.h` and `src/test/test_path.cpp`
`smallpaint_scene_fixture.h` builds a `PainterlyGlobalsCPU` by hand for the smallpaint GUI scene: analytic only, smallpaint camera
32×32, integrator `chain` per test, `seed = 0`, `u2_mode = U2_SAME`, `k0_phase_lock_bits = 0`, `alpha = 0`, `max_depth = 20`,
`diffuse_gain = double(0.1f)`, `emission_gain = 2.0`, `continue_after_emitter = 1`, `ray_epsilon = double(1e-4f)`, `two_sided = 1`,
and `spiral_frame` = the 3×3 identity (SPEC §1 `smallpaint`; a zero F would give d = N). Camera `jitter = 2.0 * double(float(1.0 / 1400))`
(T3.13). Materials as in T3.16: diffuse `cl`, mirror and glass weight (1, 1, 1) with glass ior 1.5, light diffuse (0, 0, 0) with
emission (120, 120, 120), each with `svm_offset = -1`. T3.12 reuses it.
The header is included by two translation units of the one `painterly_tests` executable (`test_path.cpp` here,
`test_path_trace.cpp` in T3.12, which may not edit it). So it defines only types and `inline` functions, with no non-inline
function and no namespace-scope variable. It provides a non-copyable, non-movable `struct SmallpaintSceneFixture` that owns
every array its `PainterlyGlobalsCPU` points to, constructed from `chain` and `lane_length` (T3.12 uses image, row, lane:5 and
lane:16).
`test_path.cpp` checks on it that:
- 100 consecutive pixels of one chain produce finite radiance;
- K increases by the number of diffuse vertices;
- `max_depth = 1` gives exactly `emission * gain` for primary hits on the light and 0 elsewhere;
- a spot ghost sphere's e_term equals emission·gain on its axis, 0 outside the cone, and is unchanged when spot.enabled == 0.

`test_path.cpp` also builds, by hand, a closed triangle-mesh slab (or a mesh sphere) with a glass lobe: with `two_sided = 1`, a ray
that enters and leaves it gives the same exit direction (exact equality) as with `two_sided = 0` (SPEC §6).
Full bit-parity with the oracle is tested end to end in T3.16.
