## Create
- `.python-version` containing `3.13`.
- `pyproject.toml` (root):
  ```toml
  [build-system]
  requires = ["scikit-build-core>=1.1", "nanobind>=3.1"]
  build-backend = "scikit_build_core.build"

  [project]
  name = "painterly-core"
  version = "0.1.0"
  description = "Native core (_painterly) of the Painterly render engine for Blender"
  requires-python = ">=3.12"
  license = "GPL-3.0-or-later"

  [tool.scikit-build]
  wheel.py-api = "cp312"            # stable ABI: one wheel serves Blender's Python 3.13
  cmake.build-type = "Release"
  build-dir = "build/{wheel_tag}"
  [tool.scikit-build.cmake.define]
  PAINTERLY_BUILD_TESTS = "OFF"
  PAINTERLY_BUILD_ORACLE = "OFF"

  [tool.uv]
  package = false                   # `uv sync` installs deps only; the C++ module is built by `make build`

  [tool.uv.workspace]
  members = ["analysis"]

  [tool.uv.sources]
  painterly-analysis = { workspace = true }

  [dependency-groups]
  dev = ["pytest>=8", "ruff", "clang-format==<pin a version that parses .clang-format>", "numpy==2.3.4",
         "nanobind>=3.1", "scikit-build-core>=1.1", "cmake>=3.28", "ninja"]
  analysis = ["painterly-analysis"]
  blender = ["bpy==5.2.2"]

  [tool.pytest.ini_options]
  testpaths = ["tests", "analysis/tests"]
  markers = ["slow: takes more than ~10 s"]

  [tool.ruff]
  line-length = 100
  target-version = "py312"
  [tool.ruff.lint]
  select = ["E", "F", "W", "I", "UP", "B", "SIM", "NPY"]
  ```
  Keep the layout above. Only fill the clang-format pin and adjust versions if the resolver demands it; record any change in your report.

- `CMakeLists.txt` (root):
  - `cmake_minimum_required(VERSION 3.26)`; `project(painterly VERSION 0.1.0 LANGUAGES C CXX)`.
  - C++20, no extensions, `CMAKE_POSITION_INDEPENDENT_CODE ON`, `CMAKE_CXX_VISIBILITY_PRESET hidden`, `CMAKE_VISIBILITY_INLINES_HIDDEN ON`.
  - Options `PAINTERLY_BUILD_MODULE` (ON), `PAINTERLY_BUILD_TESTS` (ON), `PAINTERLY_BUILD_ORACLE` (ON).
  - Deterministic floating point for every target:
    `if(MSVC) add_compile_options(/fp:precise) else() add_compile_options(-ffp-contract=off -fno-fast-math) endif()`,
    with the comment "# SPEC §6: bit-identical oracle parity requires no FMA contraction".
  - `add_subdirectory(src)`.
- `src/CMakeLists.txt`:
  - `add_subdirectory(blender)` if PAINTERLY_BUILD_MODULE;
  - `add_subdirectory(test)` if PAINTERLY_BUILD_TESTS (call `enable_testing()` at the root before this);
  - `add_subdirectory(app)` if PAINTERLY_BUILD_ORACLE. Create `src/app/CMakeLists.txt` with only a comment for now: `# smallpaint_oracle target is added by T1.1`.
- `src/blender/CMakeLists.txt`:
  - Find Python with `find_package(Python 3.12 REQUIRED COMPONENTS Interpreter Development.Module)`.
  - Locate nanobind with `execute_process(COMMAND "${Python_EXECUTABLE}" -m nanobind --cmake_dir OUTPUT_STRIP_TRAILING_WHITESPACE OUTPUT_VARIABLE nanobind_ROOT)` followed by `find_package(nanobind CONFIG REQUIRED)`.
  - `nanobind_add_module(_painterly STABLE_ABI NB_STATIC NB_DOMAIN painterly python.cpp)`.
  - `target_compile_definitions(_painterly PRIVATE PAINTERLY_VERSION="${PROJECT_VERSION}")`.
  - `install(TARGETS _painterly LIBRARY DESTINATION .)`.
- `src/blender/python.cpp`:
  - The SPDX header `// SPDX-License-Identifier: GPL-3.0-or-later` and a one-line description.
  - `NB_MODULE(_painterly, m)` exporting `version_info() -> dict` with keys:
    - `version` (PAINTERLY_VERSION);
    - `compiler` (`__VERSION__` or `_MSC_FULL_VER` as a string);
    - `build_type` (`NDEBUG` ? "Release" : "Debug");
    - `stable_abi` (bool, from `Py_LIMITED_API` being defined).
  - Module docstring: "Native core of the Painterly render engine (mirrors Cycles' _cycles)."
- `src/test/CMakeLists.txt`:

- `Makefile`, with recipe lines indented by tabs and these targets:
  - `env`: `uv sync --group dev --group analysis`
  - `env-blender`: `uv sync --group dev --group analysis --group blender`
  - `build`: `cmake -S . -B $(BUILD_DIR) -G Ninja -DCMAKE_BUILD_TYPE=Release -DPython_EXECUTABLE=$(abspath .venv/bin/python)`, then `cmake --build $(BUILD_DIR)`. Use the venv's cmake and ninja: `PATH := $(abspath .venv/bin):$(PATH)`.
  - `test-cpp`: `ctest --test-dir $(BUILD_DIR) --output-on-failure`
  - `test-py`: `.venv/bin/python -m pytest -m "not slow" -q`
  - `test`: `test-cpp test-py` (each depends on `build`)
  - `test-slow`: `.venv/bin/python -m pytest -q`
  - `lint`:
    - `.venv/bin/ruff check .`
    - `.venv/bin/ruff format --check .`
    - `git ls-files 'src/*.cpp' 'src/*.h' | xargs -r .venv/bin/clang-format --dry-run --Werror`
  - `format`: ruff format plus `clang-format -i` on the same file set
  - `check`: `lint build test`
  - `clean`: remove `build/`
  - Variables: `BUILD_DIR ?= build/dev`; export `PAINTERLY_BUILD_DIR=$(BUILD_DIR)`.
