# T0.4 — Continuous integration (Linux)
Milestone: M0 · Depends on: T0.3 · Parallel-safe: no

## Goal
Every push runs lint, build and tests on GitHub Actions (ubuntu-24.04).

## Create
- `.github/workflows/ci.yml`:
  - Triggers: `push` and `pull_request`. Uses `concurrency` to cancel superseded runs on the same ref.
  - One job, `linux`, on `ubuntu-24.04`. Steps:
    1. `actions/checkout@v4`
    2. `astral-sh/setup-uv` (pin to an existing major tag; verify with `git ls-remote --tags https://github.com/astral-sh/setup-uv.git`, because api.github.com is blocked here) with `enable-cache: true`
    3. `sudo apt-get install -y ninja-build`, kept only if the venv's ninja is not used
    4. `make env`
    5. `make lint`
    6. `make build`
    7. `make test`
  - Cache `build/dev/_deps` (FetchContent downloads) keyed on `hashFiles('**/CMakeLists.txt')`.

## Acceptance
- `.venv/bin/python -c "import yaml,sys; yaml.safe_load(open('.github/workflows/ci.yml'))"` succeeds. If PyYAML is missing, add `pyyaml` to the `dev` group and re-run `make env`.
- `make check` still passes locally.
