## Goal
After this card the repository has the licence files, the ignore and format configuration, and a README.
Later cards build on these.

## Read first
- `CLAUDE.md`
- `docs/plan.md`, sections "Architecture", "Repository layout" and "Distribution"

## Create
- `LICENSE`: the verbatim GPL-3.0 text from https://www.gnu.org/licenses/gpl-3.0.txt. Download to `.cache/` first, then copy.
- `LICENSES/MIT-smallpaint.txt`: the MIT licence text naming "Károly Zsolnai-Fehér" (smallpaint) and "Michael Oppitz" (GUI port).
  - Add a header line: "smallpaint was relicensed under MIT by its author on 2020-02-26 (https://users.cg.tuwien.ac.at/zsolnai/gfx/smallpaint/)".
- `LICENSES/Apache-2.0.txt`: verbatim from https://www.apache.org/licenses/LICENSE-2.0.txt. Covers Cycles and Embree.
- `LICENSES/BSD-3-Clause-nanobind.txt`: verbatim from https://raw.githubusercontent.com/wjakob/nanobind/master/LICENSE.
- `THIRD_PARTY_NOTICES.md`: a table with columns Component | Licence | Where used | Upstream URL. Rows:
  - smallpaint (MIT; `third_party/smallpaint`, `src/app/smallpaint_oracle.cpp`);
  - Cycles (Apache-2.0; `third_party/cycles`, vendored verbatim, pinned to Blender v5.2.2 `intern/cycles`; modified files carry a "Modified by the Painterly project" notice);
  - Embree 4.4.1 (Apache-2.0; fetched at build time, statically linked);
  - nanobind (BSD-3-Clause);
  - doctest (MIT).
  - After the table, one paragraph: "The combined work is distributed under GPL-3.0-or-later (see LICENSE)."
- `README.md` with these sections:
  - Title "Painterly — smallpaint's beautiful bug as a Blender render engine".
  - A 3-sentence description.
  - Status: "pre-alpha; under construction per docs/plan.md".
  - Layout: a short tree copied from docs/plan.md "Repository layout".
  - Development: `make env`, `make build`, `make check`.
  - Credits: Károly Zsolnai-Fehér for smallpaint and its painterly bug; Michael Oppitz for the GUI port; the Blender Foundation and Cycles authors for the template.
  - Licence: GPL-3.0-or-later; see THIRD_PARTY_NOTICES.md.
- `.gitignore`:
  - `.venv/`, `build/`, `dist/`, `wheelhouse/`, `.cache/`
  - `__pycache__/`, `*.py[cod]`, `.pytest_cache/`, `.ruff_cache/`
  - `experiments/**/out/`, `*.blend1`, `.DS_Store`
- `.editorconfig`: utf-8, LF, final newline, trim trailing whitespace. Indent 4 spaces for py/toml/md; 2 spaces for C/C++ (Cycles style); tabs for Makefile.
- `.clang-format`: verbatim copy of https://projects.blender.org/blender/blender/raw/tag/v5.2.2/.clang-format.
  - Prepend one comment line: `# Copied from Blender v5.2.2 (.clang-format) so C++ follows Cycles style.`

## Steps

2. Create the files above. Do not add anything else.
