# T0.3 — Import the smallpaint sources and reference images
Milestone: M0 · Depends on: T0.2 · Parallel-safe: no

## Goal
After this card:
- The smallpaint sources live in `third_party/smallpaint/`: the 2018 GUI archive and the 2016 standalone release.
- The reference images live in `tests/data/reference/`.
- Every imported file is pinned by sha256, and a test verifies the hashes.

## Read first
- `CLAUDE.md` rule 5 (untrusted archives)
- `docs/spec.md` §9

## Inputs
- GUI archive: `/root/.claude/uploads/98b29052-844f-5778-93d6-f67301038886/50e77c20-smallpaint.zip`. Copy it to `.cache/downloads/smallpaint_gui.zip`.
- Standalone archive: https://users.cg.tuwien.ac.at/zsolnai/wp/wp-content/uploads/2014/02/smallpaint_old.zip. Download it to `.cache/downloads/smallpaint_old.zip`.
- Extract each archive into its own new empty directory (`.cache/extract/gui/`, `.cache/extract/standalone/`). Never run anything from them.

## Create
- `third_party/smallpaint/README.md`. Include:
  - provenance (URLs, archive sha256s, the date fetched);
  - licence (MIT, see `LICENSES/MIT-smallpaint.txt`);
  - a table of every imported file with its sha256;
  - the sentence "Files are byte-identical to the archives (line endings untouched). Never edit; see CLAUDE.md rule 1."
- From the GUI archive into `third_party/smallpaint/` (keep the relative paths below `Smallpaint/`, unchanged bytes):
  - `smallpaint_painterly/smallpaint_painterly.cpp`
  - `smallpaint_fixed/smallpaint_fixed.cpp`
  - `smallpaint_bvh/*` (all files)
  - `src_gui/main.h`, `src_gui/mainrenderdistributor.cpp`, `src_gui/helperfunctions.cpp`, `src_gui/sceneGeometries.h`, `src_gui/Smallpaint.pro`
  - `README.txt`, `HOWTOAddYourOwnRenderer.txt`
- From the standalone archive into `third_party/smallpaint/standalone/`: every `.cpp`/`.h`/`.hpp` source file at its archive-relative path. List them in the README.
- `tests/data/reference/smallpaint_painterly.ppm` and `tests/data/reference/smallpaint_fixed.ppm`, copied from `Smallpaint/test_images/`.
- `tests/data/reference/README.md`. State:
  - the provenance;
  - that these 400×400 P6 images were rendered by the 2017 GUI build (dated 2017-03-22);
  - that `smallpaint_painterly.ppm` is the golden reference (SPEC §0);
  - that `smallpaint_bvh.ppm` and `smallpaint_pssmlt.ppm` in the archive are byte-identical copies of `smallpaint_fixed.ppm` and are deliberately not imported.
- `tests/data/MANIFEST.sha256`: `sha256sum` format for every file under `third_party/smallpaint/` and `tests/data/reference/`, except the two READMEs and the manifest itself. Paths are relative to the repo root.
- `tests/core/test_third_party_hashes.py`: parse MANIFEST.sha256 and assert that every listed file exists and matches. Use hashlib; no tolerances.

## Acceptance
- `make test` passes, including `test_third_party_hashes.py`.
- `sha256sum -c tests/data/MANIFEST.sha256` reports OK for every line.
- `head -c 15 tests/data/reference/smallpaint_painterly.ppm | od -c` shows `P6\n400 400\n255\n`.
- Report the standalone archive's file list and the parameters you see in its `smallpaint_painterly.cpp`:
  - image size, spp, refraction index;
  - the right-sphere radius and position;
  - the light radius;
  - the sphere normal formula;

  Opus compares them with SPEC §9.
