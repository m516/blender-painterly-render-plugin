## Design
P=64, 8 pairs, size 400, `scene=gui`. The positive control is `chain=image, ghost=all` and is shared with the previous
experiment's cache. Each variant changes exactly one option:

| variant | option |
|---|---|
| ghost_none | `ghost=none` |
| ghost_lights | `ghost=lights` (what Blender can do by default: only lights ghost) |
| alpha_025 / alpha_05 / alpha_1 | `alpha=0.25 / 0.5 / 1` |
| u2_independent | `u2=independent` |
| u2_base3 | `u2=base3` (what fixing the Halton typo would look like) |
| per_path_start | `chain=lane:1` |
| stop_at_emitter | `continue_after_emitter=False` |

## Hypotheses to pre-register (derive each from the cited research numbers)
- **H1.** `ghost_none` and `alpha_1` drop the back-wall (region 4) mean luminance far below the positive control.
  - Positive control: r4 mean luminance 144.4 at P=64 (experiment 001 / M1 review pilot). The research figure '193' was the ghost=lights value.
  - Pilot (2 pairs): ghost_none 12.9, alpha_1 5.5.
  - Test: `separated` "less" on region-4 mean luminance.
- **H2.** `u2_independent`, `u2_base3` and `per_path_start` lower `all.pattern_corr`.
  - Research: about 0 to 0.11, vs 0.47–0.63.
  - Test: `separated` "less" on `all.pattern_corr`, Holm over the three.
- **H3.** `alpha` is a continuous control: back-wall luminance decreases monotonically over α ∈ {0, 0.25, 0.5, 1}.
  - Test: adjacent pairs with `separated`, Holm.
- **H4** (re-derived by Opus after the review). `stop_at_emitter` changes **both** region means and texture.
  - Mechanism: the light is a black diffuse surface, so continuing after an emitter hit consumes K draws (zero throughput, nonzero K).
    Stopping cuts K draws per pixel per pass from about 16.3 to about 5.1 (pilot). That changes the K stride between neighbouring pixels,
    which sets both the deterministic pattern and the region means of this estimator.
  - Test: `compare_ensembles` on the diffuse key family. Distinguishable means **at least one** key rejected; refutation of 'unchanged' is expected.
  - Report K draws per pixel per pass for both configs, from `k_consumed`.
- **H5.** `ghost_lights` keeps most of the look.
  - Report the ratio of the ensemble means for `all.pattern_corr` and each region mean vs the positive control.
  - Decision: `compare_ensembles` on all keys. Distinguishable is expected, and the size of the gap is the deliverable: it is the
    parity target for Blender scenes, where only lights ghost.

For every variant also report the effect size per metric key: `(mean_v − mean_pos) / pooled_sd`.


## Design rules (apply to every comparison in this experiment)
- **Key family.** `compare_ensembles` uses `metrics.DIFFUSE_KEY_FAMILY(keys)` (46 keys for the GUI scene), never all keys. The power
  guard in `compare_ensembles` raises if a family is too large for the ensemble size.
- **Estimation over verdicts.** Report `ensemble.effect_summary` (mean ± sd, relative difference, Cohen's d) for every comparison.
  "Indistinguishable" may only be written together with `min_attainable_p` and the largest observed |relative difference|.
- **Seeds.** Every configuration owns a disjoint seed block (`base_seed = 16 * block index`), as in experiment 001.
  - The positive control `chain=image, passes=64` is experiment 001's `img64` (block 0, seeds 0–15) and is reused from the cache.
  - New blocks start after 001's last block (9), at block 10, to keep seeds globally unique.
- **Two phases.** Phase A (this card's first commit): README with Background/Hypothesis/Method, `jobs.py`, and `analyze.py`.
  Validate `analyze.py` on a 2-pair smoke subset rendered at size 64 into a scratch cache (`PAINTERLY_CACHE`), not the real one.
  The orchestrator then renders `jobs.py` to completion. Phase B (a second commit `… results`): run `analyze.py`, then add Results and the DRAFT Conclusion.
