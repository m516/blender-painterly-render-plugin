## Design
P=64, 8 pairs, size 400, `scene=gui`. The positive control is `chain=image, ghost=all` and is shared with the previous
experiment's cache. Each variant changes exactly one option:

| variant | option |
|---|---|
| ghost_none | `ghost=none` |
| ghost_lights | `ghost=lights` (what Blender can do by default: only lights ghost) |
| alpha_025 / alpha_05 / alpha_1 | `alpha=0.25 / 0.5 / 1` |
| u2_independent | `u2=independent` |
| u2_base3 | `u2=base3` (what fixing the Halton typo would look like) |
| per_path_start | `chain=lane:1` |
| stop_at_emitter | `continue_after_emitter=False` |

## Hypotheses to pre-register (derive each from the cited research numbers)
- **H1.** `ghost_none` and `alpha_1` drop the back-wall (region 4) mean luminance far below the positive control.
  - Research: 193 → about 13–15.
  - Test: `separated` "less" on region-4 mean luminance.
- **H2.** `u2_independent`, `u2_base3` and `per_path_start` lower `all.pattern_corr`.
  - Research: about 0 to 0.11, vs 0.47–0.63.
  - Test: `separated` "less" on `all.pattern_corr`, Holm over the three.
- **H3.** `alpha` is a continuous control: back-wall luminance decreases monotonically over α ∈ {0, 0.25, 0.5, 1}.
  - Test: adjacent pairs with `separated`, Holm.
- **H4** (new; derived by Opus from SPEC §6). `stop_at_emitter` leaves every region mean unchanged, because the emitter's
  continuation has zero throughput. It still changes the texture, because it shifts K for every later pixel in the chain.
  - Test: `compare_ensembles` on the `r*.mean.*` keys must be indistinguishable, and on `r*.pattern_corr` and `all.pattern_corr` must be distinguishable.
- **H5.** `ghost_lights` keeps most of the look.
  - Report the ratio of the ensemble means for `all.pattern_corr` and each region mean vs the positive control.
  - Decision: `compare_ensembles` on all keys. Distinguishable is expected, and the size of the gap is the deliverable: it is the
    parity target for Blender scenes, where only lights ghost.

For every variant also report the effect size per metric key: `(mean_v − mean_pos) / pooled_sd`.
