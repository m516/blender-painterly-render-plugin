# T1.4 — Experiment harness: cached, resumable, time-budgeted oracle ensembles
Milestone: M1 · Depends on: T1.3 · Parallel-safe: no

## Goal
After this card, experiments declare their renders as data and run them in resumable chunks.
- Each chunk has a time budget, so no single command exceeds about 9 minutes.
- Results are cached on disk, keyed by the exact options.
- PNG previews are written without new dependencies.

## Read first
- `CLAUDE.md` section "Experiments"
- `analysis/painterly_analysis/{io,oracle,metrics,ensemble}.py`

## Create
- `analysis/painterly_analysis/experiment.py`
  - `@dataclass(frozen=True) class Job: name: str; options: tuple[tuple[str, object], ...]; seed: int`.
    Store options as a sorted tuple so jobs are hashable. Add `Job.make(name, seed, **options)`.
  - `job_key(job) -> str`: sha256 over a canonical JSON of {options, seed, oracle_version from the binary's `meta.json` contract ("1"), the oracle binary's sha256}. Use the first 16 hex characters.
  - `cache_root() -> Path`: `$PAINTERLY_CACHE` or `<repo>/.cache`, then `/renders`.
  - `run_jobs(jobs, *, budget_seconds: float | None = None, workers: int | None = None) -> RunStatus(completed: int, remaining: int, elapsed: float)`:
    - render every job whose cache directory lacks a `done` marker, in parallel via `oracle.run_many` with `threads=1` per job;
    - start no new job once `budget_seconds` has elapsed;
    - write `done` after a successful render.
  - `load(job) -> OracleRender`.
  - `ensemble(name, pairs, base_seed=0, **options) -> list[Job]`: seeds `base_seed … base_seed + 2·pairs − 1`.
  - `measure_ensemble(jobs, ref8, object_id=None) -> list[dict]`: consecutive jobs form pairs; calls `metrics.measure`. When `object_id` is None, use the first job's `object_id`.
  - `main()` CLI, `python -m painterly_analysis.experiment run <path/to/jobs.py> [--budget 540] [--workers N]`:
    - imports `JOBS: list[Job]` from the file;
    - prints `completed=… remaining=…`;
    - exits 0 when remaining is 0 and 3 otherwise, so callers loop until 0.
- `analysis/painterly_analysis/io.py`: add `write_png(path, img8)`, a minimal RGB8 PNG writer using `zlib` and `struct` (filter type 0, one IDAT chunk).
- `analysis/tests/test_experiment.py`:
  - `job_key` is stable and order-independent;
  - `run_jobs` with a 64² job renders once and the second call is a no-op;
  - with `budget_seconds=0` nothing starts.
  - `write_png`: decode the file again with zlib and assert the bytes round-trip.
- `experiments/README.md`:
  - the index, with columns # | Date | Slug | Question | Status | Conclusion (one line);
  - a short "How to run" section: `python -m painterly_analysis.experiment run experiments/NNN-…/jobs.py --budget 540`, repeated until exit code 0;
  - the 5-section README rule from CLAUDE.md.
