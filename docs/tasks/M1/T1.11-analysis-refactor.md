## Goal
Experiments 001–004 duplicate about 10 analysis helpers whose signatures have drifted. Move them into one tested module before the
Phase B analyses run.

This is a **refactor**: experiment 001's `analyze.py` must keep reproducing its committed `results.json` and figures byte for byte.

## Modify / Create
- `analysis/painterly_analysis/ensemble.py`:
  - A public `min_attainable_pvalue(n, m, alternative="two-sided", *, max_exact=…, n_resamples=…)`:
    - exact branch: two-sided `(2 if n == m else 1)/C(n+m, n)`, one-sided `1/C(n+m, n)`;
    - Monte Carlo branch: `1/(n_resamples+1)`.
    `compare_ensembles` uses it.
  - Reword the tie-tolerance docstring: "scaled to the float64 round-off of means of n + m values (γ_{n+m}·max|x|); mirror splits
    differ by far less in practice". Do not claim a strict bound.
- `analysis/painterly_analysis/metrics.py`: rename `DIFFUSE_KEY_FAMILY` → `diffuse_key_family`. A function gets a snake_case name.
- `analysis/painterly_analysis/metrics.py`: add `realization_free_key_family(keys)`. It keeps keys ending in `.mean.R/.mean.G/.mean.B`,
  `.structure_std` and `.spectral_slope`, plus `all.clip_fraction` (and the noise-corrected structure lag-1 once it moves from 004 into
  `metrics`). It drops `pattern_corr` and `block_rmse`.

    consumption exactly (Blender meshes, ghost-lights-only) is judged on the realization-free family.
