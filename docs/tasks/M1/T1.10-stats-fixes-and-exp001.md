## Modify
- `analysis/painterly_analysis/ensemble.py`:
  - **Tie tolerance.** Replace the tolerance with `tol = (n + m) * _EPS * float(np.max(np.abs(pooled)))` for permutation tests and
    `n * _EPS * max|x|` for sign flips. Comment it as the float64 summation round-off bound γ_{n+m} for means of n+m values
    (CLAUDE.md rule 2). The old tolerance scaled with |statistic| and dropped the mirror split, which halved extreme two-sided p-values.
  - **Power guard** in `compare_ensembles`:
    - Compute the smallest attainable p: exact branch `(2 if n == m else 1) / math.comb(n + m, n)` (two-sided); Monte Carlo branch `1 / (n_resamples + 1)`.
    - If `p_min > alpha / len(keys)`, raise `ValueError(f"{len(keys)} keys at alpha={alpha}: the smallest attainable p {p_min:.3g} exceeds the first Holm threshold {alpha/len(keys):.3g}, so no key can be rejected")`.
    - Add the field `Comparison.min_attainable_p`.
  - **Estimation helper.** `effect_summary(a: list[dict], b: list[dict], keys) -> dict[key, {mean_a, sd_a, mean_b, sd_b, diff, rel_diff, cohen_d}]`.
    `cohen_d` uses the pooled sd. Return `None` when the pooled sd is 0 (e.g. the light region is exactly 240); never NaN.
- `analysis/painterly_analysis/metrics.py`: export `DIFFUSE_KEY_FAMILY(keys) -> list[str]`, the keys whose region is in `DIFFUSE_REGION_IDS` plus all `all.*` keys.
  Docstring: this is the standard family for `compare_ensembles`; 46 keys for the GUI scene.
