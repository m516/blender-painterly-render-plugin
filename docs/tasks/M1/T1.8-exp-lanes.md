## Design
P=64, 8 pairs, size 400, `scene=gui`, `ghost=all`. Configs:
- `chain=lane:L` for L ∈ {1, 2, 4, 8, 16, 32, 64, 128};
- `chain=row`;
- `chain=image` (shared cache).

## Hypotheses to pre-register
- **H1.** `all.pattern_corr` is non-decreasing in L. Test adjacent L one-sided (`separated`), Holm over the 8 comparisons.
  - Derived from: research found row chains 0.63, 16-px lanes 0.55 and per-path starts 0.11.
- **H2.** Some finite L* gives an ensemble indistinguishable from `chain=row` on all keys (`compare_ensembles`).
  - Report the smallest such L, and the same against `chain=image`.
- **H3.** `chain=row`, which restarts each pass at a hashed K0, is indistinguishable from `chain=image`, which runs continuously.
  - Derived from: research found the start-index distribution reaches stationarity within about one pixel.

## Deliverable for the plan
Report a recommended default `lane_length` = L* from H2. If no L qualifies, report the L that maximizes `all.pattern_corr`
per unit of available parallelism (the number of lanes), with the numbers. Opus decides.
