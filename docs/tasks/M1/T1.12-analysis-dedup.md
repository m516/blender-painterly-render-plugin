## Modify
1. `analysis/painterly_analysis/metrics.py`
   - Add a module constant `HIGHPASS_SIZE = 9`, with the comment `# the plan's acceptance metrics: 9×9-box high-pass luminance`.
   - Use it as the default of `highpass(x, size=HIGHPASS_SIZE)` and of `measure(...)`'s high-pass parameter. Where
     `measure` derives the erosion radius as `highpass_size // 2`, keep that.
   - Export it in `__init__.py` / `__all__`.
2. `analysis/painterly_analysis/report.py`. Add these, with unit tests in `analysis/tests/test_report.py`:
   - `directional_pair_test(a, b, key, alpha) -> dict`, with keys
     `{comparison, key, p_less, p_greater, min_attainable_p, effect}`:
     - `comparison` is `"a_vs_b"`, built from the caller's labels. Accept `labels=(name_a, name_b)` as a keyword argument.
     - `p_less` and `p_greater` are one-sided exact permutation p-values.
     - `min_attainable_p` is `min_attainable_pvalue(n, m, "greater")`.
     - `effect` is `effect_summary` for the key.
     It replaces the identical `_pair_test` in 002 and 003 and the inline copy inside `adjacent_tests`.
     `adjacent_tests` calls it.
   - `ab8_of_pair(jobs) -> np.ndarray`: the uint8 mean of the first pair's two half renders, as the current `_ab8`
     copies compute it (read 002's `_ab8` and keep its exact arithmetic).
   - `block_preview(img8, factor) -> np.ndarray`: the current `_quarter`, generalized. 002-004 call it with factor 4,
     which is the current behaviour.
   - `mosaic(previews: Mapping[str, np.ndarray], columns: int) -> np.ndarray`: the current `_grid`, with the layout
     given as a column count. Read the three `_grid` copies. If their layouts differ, the function takes what is needed
     to reproduce each one exactly; report what that was.
   - `markdown_table` currently has no caller. Delete it and its test unless an analyze.py starts using it in this card.
3. `analysis/painterly_analysis/experiment.py`
   - Delete `measure_ensemble`. `report.ensemble_metrics` replaces it; update any docstring that names it.
   - `_load_jobs(path)` calls `report.load_jobs_module(path).JOBS`. Keep one loader.
     If importing `report` from `experiment` would create a cycle, move `load_jobs_module` into `experiment.py`,
     re-export it from `report`, and report that.
4. `experiments/00{1,2,3,4}-*/analyze.py`
   - Import `HIGHPASS_SIZE` from `painterly_analysis.metrics` instead of restating `HIGHPASS_SIZE = 9`.
   - 002-004: use `report.directional_pair_test`, `report.ab8_of_pair`, `report.block_preview` and `report.mosaic`.
     Delete the local copies.
