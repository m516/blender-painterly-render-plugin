# T1.2 — `painterly_analysis`: I/O, look metrics, and ensemble statistics (JAX)
Milestone: M1 · Depends on: T0.2 · Parallel-safe: yes (only `analysis/`)

## Goal
After this card there is one measurement library, used by every test and experiment, that quantifies the painterly look
and decides "indistinguishable / separated" statistically, with no hand-picked thresholds.

## Read first
- `docs/spec.md` §7 (display mapping) and §9 (object ids)
- `docs/plan.md` "Acceptance metrics"
- `CLAUDE.md` rules 2 and 6

## Create
`analysis/painterly_analysis/`:
- `__init__.py`: enable float64 for this package with `jax.config.update("jax_enable_x64", True)`.
  Comment: "analysis only; never imported inside Blender". Re-export the public API.
- `io.py`
  - `read_ppm(path) -> np.ndarray[uint8] (H,W,3)`, supporting P6 and P3 with maxval 255. `write_ppm(path, img8)` writes P6.
  - `smallpaint_display(sum_: np.ndarray, passes: int) -> np.ndarray[uint8]`: exactly SPEC §7,
    `np.minimum(np.floor(sum_).astype(np.int64) // passes, 255)`. Sums are non-negative, so floor equals C++ truncation;
    say so in a comment.
  - `@dataclass(frozen=True) class OracleRender: sum: np.ndarray; kcount: np.ndarray; objid: np.ndarray; meta: dict`
    with a property `passes`, plus `read_oracle(dir) -> OracleRender`.
- `oracle.py`
  - `oracle_binary() -> Path`: `$PAINTERLY_BUILD_DIR` (default `build/dev`) + `/src/app/smallpaint_oracle`.
  - `run_oracle(out_dir, **options) -> OracleRender`. Options map to CLI flags: `chain="lane:16"` → `--chain lane:16`,
    underscores → dashes, `continue_after_emitter=False` → `--continue-after-emitter no`.
  - `run_many(jobs: list[tuple[Path, dict]], workers: int | None = None) -> list[OracleRender]` using
    `concurrent.futures.ThreadPoolExecutor`. Each job is its own subprocess, so threads are fine. When parallel, pass `--threads 1`.
- `metrics.py`. Pure JAX. Every function documents units: images are display bytes as float64 unless noted.
  - `LUMA_REC709 = (0.2126, 0.7152, 0.0722)  # ITU-R BT.709 luma coefficients (definition)`
  - `luminance(rgb)`
  - `box_blur(x, size)`: centred mean, edge-replicate padding; `size` is odd.
  - `highpass(x, size=9)`: `x - box_blur(x, size)`.
  - `erode(mask, radius)`: a pixel survives iff its whole (2r+1)² square is inside the image and inside the mask.
  - `region_masks(objid, radius=3) -> dict[int, Array]`: non-empty eroded masks only.
  - `region_mean_rgb(img, mask) -> Array(3)`
  - `pearson(a, b, mask)`
  - `structure_std(hp_a, hp_b, mask)`: `sqrt(max(cov(hp_a, hp_b), 0))` over the mask, with `cov = mean((a-ā)(b-b̄))`.
  - `lag1_autocorrelation(x, mask, axis)`: Pearson of `x[p]` vs `x[p+1 along axis]` over pairs with both pixels in the mask.
  - `block_rmse(img, ref, block=25)`: crop to whole blocks, take per-channel block means, return the RMSE over blocks and channels.
  - `clip_fraction(img8)`: the fraction of pixels with any channel == 255.
  - `radial_spectral_slope(x, f_min=2, f_max=None)`:
    - apply a 2-D Hann window, then `|FFT|²`;
    - average radially over integer frequency radii in `[f_min, f_max]` (`f_max` defaults to `min(H,W)//4`);
    - return the least-squares slope of log power vs log radius.
  - `measure(sum_a, sum_b, passes, ref8, objid, *, highpass_size=9, erosion_radius=3, block=25) -> dict[str, float]`.
    `sum_a` and `sum_b` are two independent renders (oracle `sum` arrays) with the same `passes`. Define
    `a8 = smallpaint_display(sum_a, passes)`, `b8 = smallpaint_display(sum_b, passes)` and
    `ab8 = smallpaint_display(sum_a + sum_b, 2*passes)`. Keys:
    - per region id r:
      - `r{r}.mean.{R,G,B}` from ab8;
      - `r{r}.structure_std` from hp(lum a8) and hp(lum b8);
      - `r{r}.pattern_corr` = pearson(hp(lum ab8), hp(lum ref8));
      - `r{r}.lag1.x`, `r{r}.lag1.y` on hp(lum ab8);
    - global:
      - `all.pattern_corr` over the union of the diffuse-region masks;
      - `all.block_rmse` (ab8 vs ref8);
      - `all.clip_fraction` (ab8);
      - `all.spectral_slope` (hp(lum ab8)).
    Here "diffuse regions" means the SPEC §9 ids of type diffuse except the light: {2, 3, 4, 5, 6, 7, 8}.
  - Expose `DIFFUSE_REGION_IDS` with a comment citing SPEC §9.
- `ensemble.py`. Statistics for deciding look fidelity without hand-picked thresholds:
  - `permutation_pvalue(x, y, alternative="two-sided"|"greater"|"less", *, max_exact=100_000, n_resamples=100_000)`:
    - statistic `mean(x) - mean(y)`;
    - exact enumeration of all C(n+m, n) splits when that count ≤ `max_exact`, else Monte Carlo with `jax.random.PRNGKey(0)` and the `(k+1)/(N+1)` estimator.
  - `sign_flip_pvalue(x, alternative)`: one-sample test of mean 0, exact over all 2^n sign patterns when n ≤ 20.
  - `holm(pvalues: Mapping[str, float], alpha: float) -> dict[str, bool]`: Holm–Bonferroni reject decisions.
  - `student_t_cdf(t, dof)` via `jax.scipy.special.betainc`; `student_t_ppf(q, dof, xtol=1e-12)` by bisection.
  - `prediction_interval(samples, alpha) -> (lo, hi)`: `mean ± t_{1-α/2, n-1}·s·sqrt(1+1/n)`.
  - `@dataclass class Comparison: pvalues: dict; rejected: dict; @property indistinguishable -> bool (no key rejected)`.
  - `compare_ensembles(a: list[dict], b: list[dict], keys: Iterable[str], alpha=0.01) -> Comparison`: two-sided permutation test per key, then Holm.
  - `separated(pos: list[float], neg: list[float], alternative, alpha=0.01) -> bool`.
  - Module docstring: alpha is a *knob*, the family-wise error rate; the default 0.01 is a convention, not a fitted value.

`analysis/tests/`:
- `test_io.py`:
  - P6 round trip;
  - `smallpaint_display` on hand-computed cases, e.g. sum 511.9 at 2 passes gives 255, and sum 7.99 at 2 passes gives 3;
  - `read_ppm` on `tests/data/reference/smallpaint_painterly.ppm` gives shape (400,400,3) and dtype uint8.
- `test_metrics.py`:
  - `highpass` of a constant image is exactly 0;
  - `erode` on a known 7×7 mask;
  - `pearson(a, a) == 1` (rtol 1e-12, float64 round-off);
  - `structure_std(a, a)` equals the masked std of a;
  - `block_rmse(x, x) == 0`;
  - `radial_spectral_slope` of a synthetic field built with an exact radial power law `|F|² ∝ r^-2` (random phases, seed 0)
    is −2. Its tolerance is the least-squares fit residual you compute in the test; justify it in a comment.
- `test_ensemble.py`:
  - x = y gives p = 1;
  - fully separated groups of 8 and 8 give exactly `2 / C(16,8)` two-sided;
  - Holm on {a:0.005, b:0.01, c:0.03, d:0.04} at α=0.05 rejects exactly {a, b};
  - `student_t_ppf(0.975, 7)` is 2.3646242515927849 within `xtol`;
  - the sign-flip test on 8 positive values gives `1/256` one-sided.
