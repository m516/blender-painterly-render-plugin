## Create / move
- `src/blender/addon/sync/__init__.py`: defines `build_scene(depsgraph, settings, width, height)`, which raises
  `NotImplementedError("Blender scene sync arrives in M5")`.
- `src/blender/addon/sync/reference.py`:
  - Move `build_smallpaint_scene` and `apply_reference_knobs` here from `tests/core/scenes.py` (T3.16), with `bpy`-free code only.
    `tests/core/scenes.py` re-exports both, so the M3 tests keep passing unchanged. It loads `reference.py` by file path with
    `importlib.util.spec_from_file_location`: importing `reference.py` through the package would run `addon/__init__.py`, which
    imports `bpy`.
  - `build_smallpaint_scene` takes no `jitter` parameter: the integrator socket default supplies it, and tests read
    `scene.get_integrator()["jitter"]`.
  - `apply_reference_knobs() -> dict` returns the one cited dict of smallpaint-unit knobs — `diffuse_gain = float32(0.1)`,
    `emission_gain = 2`, `ray_epsilon = float32(1e-4)`, `max_depth = 20`, `spiral_frame = "smallpaint"` (F = I, SPEC §1).
    `build_smallpaint_scene` applies it, and `ORACLE_EXACT_KNOBS` (T3.16) derives from it. Every other knob keeps the user's
    value: chain, lane length, seed, u2 mode, phase lock, alpha, continue-after-emitter and `jitter`.
- `src/blender/addon/film.py`, pure numpy (no `bpy`; unit-testable):
  - `srgb_to_linear(x)`: the IEC 61966-2-1 EOTF. Its constants (0.04045, 12.92, 0.055, 1.055, 2.4) are definitions; cite the standard.
  - `display_referred(sum_rgb, passes) -> float32 (H,W,4)`: `srgb_to_linear(min(sum/passes/255, 1))`, alpha 1 (SPEC §8).
  - `scene_linear(sum_rgb, passes, exposure) -> float32 (H,W,4)`: `sum/passes/255*exposure`, alpha 1.
  - `to_blender_rows(rgba)`: flip rows, because Blender buffers start at the bottom row while ours start at the top (SPEC §0).
- `src/blender/addon/session.py`:
  - `render(engine, depsgraph)`:
    1. Resolve width and height from `scene.render.resolution_x/y * resolution_percentage / 100`.
    2. Build the core scene.
       - If `settings.reference_scene`: reference mode requires `w == h`. `build_smallpaint_scene` takes one `size` and moves
         unchanged, and the smallpaint camera's GUI quirk (SPEC §7) is harmless only for a square image. If `w != h`, report it
         with `engine.report({'ERROR'}, …)` and return without rendering. Otherwise use `reference.build_smallpaint_scene(…, size=w)`.
       - Otherwise call `sync.build_scene(depsgraph, settings, w, h)`. Until M5 it raises `NotImplementedError`, which is reported
         with `engine.report({'ERROR'}, …)`.
    3. Set integrator knobs from `scene.painterly`: generated socket properties by name, then the `apply_reference_knobs()` dict in
       reference mode. Pass vector properties as `tuple(prop)`: `set_integrator` raises on wrong types (T3.15).
    4. Start the session and keep a reference to it: `session = _painterly.Session(core_scene, settings.threads)`, then
       `session.start(settings.passes, settings.batch)`. `start()` returns None, and a dropped `Session` is destroyed, which
       cancels its render (T3.14).
    5. `result = engine.begin_result(0, 0, w, h, layer=depsgraph.view_layer.name)`.
    6. Loop: `session.wait(timeout)` with a timeout of 0.1 s (a named module constant, `POLL_SECONDS`, documented as UI responsiveness).
       - On `engine.test_break()`: `session.cancel()`.
       - Each time `passes_done` increases: read `p0 = session.progress()['passes_done']`, `sums = session.combined()`,
         `p1 = session.progress()['passes_done']`. If `p0 != p1`, skip this write (the next poll retries). Otherwise write
         `film.display_referred(sums, p0)` (or `scene_linear(sums, p0, exposure)`), then `engine.update_result(result)`,
         `engine.update_progress(p0/total)` and `engine.update_stats("", f"Pass {p0}/{total}")`. `passes_done` only grows, and
         T3.14 publishes it together with the buffers, so equal reads mean `sums` covers exactly `p0` passes.
    7. Final write, then `engine.end_result(result)`.
    8. Errors (state `error`) become `engine.report({'ERROR'}, msg)`.
  - Pixel write: `result.layers[0].passes["Combined"].rect.foreach_set(np.ascontiguousarray(rgba, np.float32).ravel())`.
    This is the fast memcpy path; never `rect = list`.
  - `seed_per_frame`: `seed + scene.frame_current` if enabled (SPEC §8).
- `tests/core/test_film.py`, without bpy. It loads `addon/film.py` by file path with `importlib.util.spec_from_file_location`, as
  `tests/core/scenes.py` loads `reference.py`:
  - `display_referred` on hand values (sum 255·passes → 1.0; 0 → 0);
  - monotonicity;
  - the flip;
  - `srgb_to_linear` at points with closed-form values: 0 → 0 and 1 → 1 (exact: `(1 + 0.055) / 1.055 == 1.0` in float64),
    0.04045 → 0.04045 / 12.92 (the linear branch at its threshold), and x = 1.055·0.5^(1/2.4) − 0.055 → 0.5, the last within
    float64 round-off with the bound derived in a comment. Never compare against printed decimal values: their rounding exceeds
    float64 round-off.
- `tests/blender/test_render_reference.py` (bpy module):
  1. Set engine PAINTERLY, `reference_scene = True`, chain `lane`, lane_length 16, 48×48, passes 2, `output_mode = scene_linear`, exposure 1.
  2. Run `bpy.ops.render.render()`.
  3. Read the Render Result back: save it as OpenEXR float32 to a temp file with `use_exr_half=False`, load it with
     `bpy.data.images.load`, and read `pixels` (bottom-up).
  4. Assert it is **exactly equal** to `film.to_blender_rows(film.scene_linear(core_sum, 2, 1))`, where `core_sum` comes from a direct
     `_painterly` render of the same configuration. It is the same core, so it is bit-identical. The EXR stores float32, which is exact.
