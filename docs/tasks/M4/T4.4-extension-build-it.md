# T4.4 — Build, install and render the extension in real Blender 5.2.2 (integration test)
Milestone: M4 · Depends on: T4.3 · Parallel-safe: no

## Goal
`make blender-it` builds the extension zip (wheel included), installs it into an isolated Blender user directory, renders the
reference scene headless, and checks the image against the oracle **bit for bit**.

## Create
- `tools/build_extension.py`:
  1. Run `make wheel`, or take `--wheel PATH`.
  2. Stage `src/blender/addon/` into `build/extension/painterly/`, plus `wheels/<wheel>`.
  3. Rewrite the staged `blender_manifest.toml` `wheels = ["./wheels/<file>"]` and `platforms = [<platform derived from the wheel tag>]`.
  4. Run `<blender> --command extension build --source-dir build/extension/painterly --output-dir dist/ --split-platforms`.
  5. Print the zip path.
- `tests/blender_it/run_reference.py`. It runs **inside** Blender (`blender -b --factory-startup --python-exit-code 1 --python … -- <out_dir>`):
  1. Set engine PAINTERLY, reference_scene, chain image, 64×64, passes 4, output scene_linear, exposure 1.
  2. Render and save an EXR (float32).
  3. Write the pixels (bottom-up float32) and metadata to `<out_dir>/blender.npy` and `.json`.
- `tests/blender_it/test_extension_it.py`. Mark it slow; skip if `make blender` has not fetched the binary.
  1. `BLENDER_USER_RESOURCES=<tmp>`.
  2. `blender --command extension install-file -r user_default -e <zip>`.
  3. Run `run_reference.py`.
  4. Run the oracle with the same config, using the SPEC §2 parity rule (`--halton exact`) and the T3.16 float32 knob values.
  5. Assert `blender.npy == to_blender_rows(scene_linear(oracle.sum, 4, 1))` exactly. This proves the extension, wheel, sync, film,
     orientation and core end to end.
- `Makefile`: `extension:` → `tools/build_extension.py`; `blender-it: extension` → pytest on `tests/blender_it -m slow`.

## Acceptance
- `make blender-it` passes. Report the zip size and the render time.
- `blender --command extension validate dist/*.zip` passes.
