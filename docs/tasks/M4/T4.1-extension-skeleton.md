# T4.1 — The extension skeleton: manifest, engine class, engine facade (mirrors Cycles' add-on)
Milestone: M4 · Depends on: M3 · Parallel-safe: no

## Goal
After this card:
- `src/blender/addon/` is a valid Blender 5.2 extension. It is pure Python and mirrors `intern/cycles/blender/addon/`.
- It registers a render engine `PAINTERLY` whose callbacks forward to a thin `engine.py` facade, as Cycles' `__init__.py` forwards to `engine.py`.

## Read first
- Cycles' add-on: https://raw.githubusercontent.com/blender/blender/v5.2.2/intern/cycles/blender/addon/__init__.py, `engine.py`
- Blender manual, extensions: https://docs.blender.org/manual/en/latest/advanced/extensions/getting_started.html (manifest fields)
- `bpy.types.RenderEngine` API: https://docs.blender.org/api/current/bpy.types.RenderEngine.html
- `src/blender/_painterly.pyi`

## Create `src/blender/addon/`
- `blender_manifest.toml`:
  - `schema_version = "1.0.0"`, `id = "painterly"`, `version = "0.1.0"`, `name = "Painterly"`
  - `tagline = "Painterly path tracing from smallpaint's beautiful Halton bug"` (≤ 64 chars, ending alphanumeric)
  - `maintainer = "Micah <micah112358@proton.me>"`, `type = "add-on"`, `tags = ["Render"]`
  - `blender_version_min = "5.2.0"`, `license = ["SPDX:GPL-3.0-or-later"]`
  - `copyright = ["2014-2020 Károly Zsolnai-Fehér", "2017-2018 Michael Oppitz", "2011-2026 Blender Foundation", "2026 The Painterly Authors"]`
  - `platforms` and `wheels` are **written by `tools/build_extension.py`** (T4.4); leave a comment placeholder.
  - `[build] paths_exclude_pattern = ["__pycache__/", "/tests/"]`
- `__init__.py`:
  - Mirror Cycles' `__init__.py` layout: the reload block, `from . import engine, version_update`, and the engine class.
  - The class is `class PainterlyRender(bpy.types.RenderEngine)` with:
    - `bl_idname = "PAINTERLY"`, `bl_label = "Painterly"`;
    - `bl_use_preview = False` (material previews come later; comment why);
    - `bl_use_eevee_viewport = True` (Material Preview shading uses EEVEE, as for Cycles);
    - `bl_use_shading_nodes_custom = False` (the standard Shader Editor and Principled BSDF are available);
    - `bl_use_postprocess` left unset.
  - `__init__` calls `super().__init__(*args, **kwargs)` and sets `self.session = None`.
  - `render(self, depsgraph)` → `engine.render(self, depsgraph)`.
  - `update_render_passes(self, scene, view_layer)` → `engine.register_passes(self, scene, view_layer)`.
  - `__del__` → `engine.free(self)`.
  - `register()`/`unregister()`, mirroring Cycles: `engine.init()`, then `properties.register()`, `ui.register()`, `operators.register()`,
    `presets.register()`, `version_update.register()`. Those submodules are stubs with empty `register`/`unregister` until T4.2.
- `engine.py`, the facade:
  - `init()`: import `_painterly` and check `_painterly.version_info()["version"]` against the manifest version. On mismatch raise
    `ImportError` with a clear message.
  - `free(engine)`, `render(engine, depsgraph)` (calls `session.render(engine, depsgraph)` from T4.3; a stub that reports "not implemented" for now), `register_passes(...)`.
- `session.py`: stub, filled by T4.3.
- `properties.py`, `ui.py`, `operators.py`, `presets.py`, `version_update.py`: stubs with `register()`/`unregister()`.
- `tests/blender/__init__.py`: none (importlib mode).
- `tests/blender/conftest.py`: a fixture `addon` that:
  - skips if `bpy` is not importable (`make env-blender` installs `bpy==5.2.2`);
  - imports the package from `src/blender/addon` as module `painterly` via `importlib.util.spec_from_file_location(..., submodule_search_locations=[...])`;
  - makes `_painterly` importable (build dir on sys.path);
  - calls `register()` and yields; `unregister()` on teardown.
- `tests/blender/test_registration.py`: after register, `"PAINTERLY"` is in `bpy.types.RenderEngine` subclasses' bl_idnames, and setting `scene.render.engine = "PAINTERLY"` works.
