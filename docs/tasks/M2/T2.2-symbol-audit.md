# T2.2 — `tools/symbol_audit.py`: enforce isolation on every platform
Milestone: M2 · Depends on: T2.1 · Parallel-safe: no

## Goal
A single tool, run by `make check` and by every wheel build, that fails if the native module leaks or imports anything
that could clash with Blender's process.

## Create
- `tools/symbol_audit.py` (Python 3.12+, stdlib only), CLI `symbol_audit.py <path-to-module-or-wheel> [--report json]`.
  If given a wheel, extract `_painterly*` from it into a temp dir.
  - **Linux** (ELF). Use `nm -D --defined-only` for exports, `readelf -d` for NEEDED, and `nm -D --undefined-only` for imports.
    1. The set of **all defined dynamic symbols**, of any type (T, W, V, D, B, u, i), must equal `{PyInit__painterly}`.
    2. NEEDED ⊆ `ALLOWED_NEEDED_LINUX`, a module constant of glibc libraries (`libc.so.6`, `libm.so.6`, `libpthread.so.0`,
       `libdl.so.2`, `librt.so.1`, `ld-linux-x86-64.so.2`, `ld-linux-aarch64.so.1`). Comment: "glibc is the manylinux_2_28
       baseline Blender itself requires".
    3. No undefined symbol may be a C++ mangled name (`_Z…`) or match `rtc`/`tbb`/`OIIO`/`OCIO`.
  - **macOS** (Mach-O). `nm -gU` exports must equal `{_PyInit__painterly}`. `otool -L` dependencies ⊆ `/usr/lib/libSystem.B.dylib` and `/usr/lib/libc++.1.dylib`.
  - **Windows** (PE). `dumpbin /exports` (or `llvm-objdump --private-headers` if dumpbin is absent) must show only `PyInit__painterly`.
    `dumpbin /dependents` ⊆ `ALLOWED_DLLS_WINDOWS`: `python3.dll`, `KERNEL32.dll`, and the api-ms-win-crt-* *system* DLLs only if the static CRT still needs them. Document this.
  - Print a human-readable report. Exit 0 on pass and 1 on fail, listing each violation.
- `tests/core/test_symbol_audit.py`: run the tool on the built module and assert exit code 0. Skip only when the OS has no audit implementation; that is never on Linux.

## Modify
- `Makefile`: add `audit: build` → `.venv/bin/python tools/symbol_audit.py $(BUILD_DIR)/src/blender/_painterly*`, and add `audit` to `check`.

## Acceptance

- Temporarily remove `-Wl,--version-script=…` locally, rebuild, and confirm that `tools/symbol_audit.py` FAILS with a list of leaked symbols. Restore the flag before committing.
