# T2.1 — Static, namespaced Embree inside a fully isolated `_painterly`
Milestone: M2 · Depends on: M1 · Parallel-safe: no

## Goal
After this card:
- `_painterly` links Embree 4.4.1 **statically**, with Embree's API in its own namespace, INTERNAL tasking (no TBB),
  and only triangle and instance geometry.
- The module exports exactly one symbol, `PyInit__painterly`.
- It links the C++ runtime statically: libstdc++/libgcc on Linux, `/MT` on Windows.
- `_painterly.selftest()` proves that Embree works and that its `t` is parametric along an unnormalized direction, which SPEC §4 relies on.

Why: Blender 5.2 already has Cycles, Embree 4.4.1 and oneTBB in its process, and on macOS it exports thousands of `ccl::`
symbols. We must share **nothing** with it (docs/plan.md "Isolation from Blender's own libraries").

## Read first
- `docs/plan.md` "Architecture"
- Embree's CMake options: `git clone --depth 1 --branch v4.4.1 https://github.com/RenderKit/embree.git .cache/src/embree`.
  Read `CMakeLists.txt`, `common/cmake/*.cmake` and README "Embree API namespace".

## Create
- `cmake/painterly_embree.cmake`:
  - Set Embree cache options with `FORCE` before `FetchContent_MakeAvailable`:
    - `EMBREE_STATIC_LIB=ON`
    - `EMBREE_API_NAMESPACE=painterly_embree`
    - `EMBREE_LIBRARY_NAME=painterly_embree`
    - `EMBREE_TASKING_SYSTEM=INTERNAL`
    - `EMBREE_ISPC_SUPPORT=OFF`
    - `EMBREE_TUTORIALS=OFF`
    - `EMBREE_GEOMETRY_TRIANGLE=ON`, `EMBREE_GEOMETRY_INSTANCE=ON`; every other `EMBREE_GEOMETRY_*` OFF
    - `EMBREE_RAY_MASK=ON`
    - `EMBREE_BACKFACE_CULLING=OFF`
    - `EMBREE_STAT_COUNTERS=OFF`
    - `EMBREE_INSTALL_DEPENDENCIES=OFF`
    - `EMBREE_ZIP_MODE=OFF`
  - `EMBREE_MAX_ISA` comes from a **knob**, `PAINTERLY_EMBREE_MAX_ISA`. Default `AVX2` on x86_64 (runtime dispatch over SSE2…AVX2) and the arm64 equivalent on arm64 (read Embree's docs for the correct value).
  - Fetch with `FetchContent_Declare(embree GIT_REPOSITORY https://github.com/RenderKit/embree.git GIT_TAG v4.4.1 GIT_SHALLOW TRUE)`.
  - Mark Embree's targets `EXCLUDE_FROM_ALL` where possible.
  - Expose an interface target `painterly::embree` that carries the include dirs, the library and its internal static libs.
- `src/blender/exports.map`: `{ global: PyInit__painterly; local: *; };`.
- `src/blender/exports_macos.txt`: `_PyInit__painterly`.
- `src/blender/selftest.h` and `src/blender/selftest.cpp`:
  - `CCL_NAMESPACE_BEGIN` … `END`. Until vendoring arrives in M3, define the macros locally in `selftest.h` under `#ifndef CCL_NAMESPACE_BEGIN`.
  - `struct SelftestResult { std::string embree_version; bool hit; float t; unsigned prim_id; };`
  - `SelftestResult selftest_embree();`:
    - build a device (`rtcNewDevice(nullptr)`) and a scene with one triangle (0,0,0), (1,0,0), (0,1,0);
    - intersect a ray from (0.25, 0.25, 1) with the **unnormalized** direction (0, 0, −2), `tnear 0`, `tfar inf`;
    - release everything.
  - Use `RTC_NAMESPACE_USE` only inside the `.cpp`.

## Modify
- Root `CMakeLists.txt`:
  - Before any target, set `CMAKE_MSVC_RUNTIME_LIBRARY` to `MultiThreaded$<$<CONFIG:Debug>:Debug>` (policy CMP0091 NEW) with the comment "# static CRT: never bind to Blender's MSVC runtime".
  - `list(APPEND CMAKE_MODULE_PATH ${CMAKE_SOURCE_DIR}/cmake)` and `include(painterly_embree)`.
- `src/blender/CMakeLists.txt`:
  - Add `selftest.cpp` and link `painterly::embree`.
  - Pass `NOMINSIZE` to `nanobind_add_module`. Without it nanobind adds `-Os` to the module target, which would slow kernel code
    compiled into it. Keep `STABLE_ABI NB_STATIC NB_DOMAIN painterly`.
  - Linux: `target_link_options(_painterly PRIVATE -static-libstdc++ -static-libgcc -Wl,--exclude-libs,ALL -Wl,--version-script=${CMAKE_CURRENT_SOURCE_DIR}/exports.map)`.
  - macOS: `-Wl,-exported_symbols_list,${CMAKE_CURRENT_SOURCE_DIR}/exports_macos.txt`.
  - Add `.def`-free Windows handling (nanobind already exports only `PyInit`).
- `src/blender/python.cpp`: bind `selftest() -> dict` with keys `embree_version`, `hit`, `t`, `prim_id`.
- `tests/core/test_import.py`: add `test_selftest_embree_unnormalized_direction`.
  - Assert `hit`, `prim_id == 0` and `t == pytest.approx(0.5, rel=4 * 2**-23)`.
  - Comment: float32 round-off, a few ulps. The distance is 1 along `|d| = 2`, so the parametric t is 0.5. SPEC §4 depends on this parametric convention.
