# T5.3 — Lights, world and constant materials (pre-SVM)
Milestone: M5 · Depends on: T5.2 · Parallel-safe: no

## Read first
`docs/spec.md` §5 and §6 (lobes, Blender extras); `src/blender/_painterly.pyi`.

## Create
- `src/blender/addon/sync/light.py`, `sync_lights(scene_core, depsgraph, settings, stats: SyncStats) -> None`
  (`SyncStats` and `object_key` from `sync/geometry.py`, T5.2). It iterates `depsgraph.object_instances` as T5.2 does and syncs
  the `LIGHT` instances:
  - **Point** → `m = add_material([("diffuse", (0.0, 0.0, 0.0), 0.0)], emission = color·energy·emission_scale)`, then
    `add_sphere(center, radius = light.shadow_soft_size, material = m, intersection = intersection)` with
    `intersection = "ghost" if settings.ghost_lights and light.painterly.ghost else "exact"`.
    `light.painterly.ghost` is a bool, default True, in `PainterlyLightSettings` on `bpy.types.Light.painterly` (see Modify).
  - **Spot**: as point, plus `spot = (axis = normalize(−Z of matrix_world), cos(spot_size/2), spot_blend)`.
    The caller normalizes the axis (`_painterly.pyi`).
  - **Area**: an emissive quad mesh (2 triangles; square/rectangle with size/size_y) at `matrix_world`, with
    `m = add_material([("diffuse", (0.0, 0.0, 0.0), 0.0)], emission = color·energy·emission_scale)`, the same emission mapping as
    point lights (SPEC §6). The quad emits from both faces: the core adds emission on every hit (SPEC §6) and `add_material` has no
    sidedness (`_painterly.pyi`). Blender's one-sided area emission needs a contract change.
    **Disk/ellipse** use a polygon fan of `settings.area_light_segments` triangles (a knob, default 32).
  - **Sun** → `add_sun(direction = +Z of matrix_world, angle = light.angle, radiance = color·energy·emission_scale)`.
  - Point, spot and area lights continue T5.2's object-id counter: each passes `object_id = len(stats.object_ids)` explicitly, then
    records it as `stats.object_ids[object_key(inst)] = object_id`, which is the light's object name for a real object (T5.2).
    Because `build_scene` calls `sync_lights` after `sync_geometry` with the same `stats`, light ids never repeat a geometry id.
    Suns have no object id.
- `src/blender/addon/sync/world.py`, `sync_world(scene_core, scene)`:
  - If the world's node tree has a Background node linked to the World Output: `color·strength` (unlinked inputs only).
  - Otherwise `world.color`.
  - Linked inputs warn and use the default value until M6.
- `src/blender/addon/sync/material.py`, `MaterialTable` with a `material_index_of(material)` cache that creates materials on demand.
  Constant mapping from the node tree's surface shader (unlinked inputs only, until M6):
  - **Principled**, writing b = Base Color, m = Metallic, t = Transmission Weight:
    - lobes `diffuse: b·(1−m)·(1−t)`, `mirror: b·m`, `glass: b·(1−m)·t` with `ior = IOR`;
    - emission = Emission Color · Emission Strength (`emission_scale` applies to lights only, SPEC §6, §8);
    - zero-weight lobes are dropped, but at least one lobe is kept.
  - **Diffuse BSDF** → diffuse(color). **Glossy/Metallic BSDF** → mirror(color). **Glass/Refraction BSDF** → glass(color, IOR).
    **Transparent** → transparent(color). **Emission** → diffuse(0) plus emission.
  - Anything else → diffuse(0.8 grey), with a one-time warning naming the node. Blender's default material is grey 0.8.
  - No material → diffuse(0.8).

## Modify
- `src/blender/addon/sync/__init__.py`: `build_scene` creates a `MaterialTable`, passes its `material_index_of` to `sync_geometry`
  in place of T5.2's provisional mapper, then calls `sync_lights(scene_core, depsgraph, settings, stats)` with the same `stats`
  (T5.2's out-parameter) and `sync_world`.
- `properties.py`: `area_light_segments` (int, default 32, min 3) and `PainterlyLightSettings`.

## Create `tests/blender/test_sync_lights_materials.py`
The tests pass a recording fake `scene_core` that logs every call and its arguments, because `_painterly.Scene` has no getters.
- A point light becomes one ghost sphere with the expected centre, radius and emission.
- With a `SyncStats` that already holds n object ids, a point light gets `object_id = n` and is recorded under its object name.
- A spot carries its cone.
- An area light gives 2 triangles, with emission `color·energy·emission_scale`.
- `add_sun` receives +Z of `matrix_world`.
- Principled mapping on 4 hand cases, including metallic 1 (a single mirror lobe) and transmission 1.
- The unsupported-node warning appears once.
