## Create `src/blender/addon/sync/geometry.py`
`sync_geometry(scene_core, depsgraph, material_index_of) -> SyncStats`:
1. Iterate `depsgraph.object_instances` **as an iterator**. Copy `inst.matrix_world` immediately; it is only valid during the iteration.
2. Skip objects with `visible_get` false for render, and non-geometry types.
   - For `MESH`, use `inst.object.data`.
   - For other geometry types (curves, text, …), use `obj.to_mesh()` and then `obj.to_mesh_clear()`.
3. **Deduplicate meshes** by `(inst.object.original.name, id of the evaluated data)`, so instances share one `add_mesh`.
4. Export with `foreach_get` into preallocated numpy arrays, using **exact dtypes** (a wrong dtype silently falls back to the slow path):
   - vertices `co` → `np.float32`, shape (V·3);
   - `loop_triangles` `vertices` → `np.uint32`;
   - `loop_triangles` `loops` → `np.uint32`;
   - `loop_triangles` `material_index` → `np.uint32`, mapped through the object's material slots to scene material indices with `material_index_of(material) -> int`;
   - `corner_normals` `vector` → `np.float32`, gathered per triangle corner via `loops`.
   Call `mesh.calc_loop_triangles()` first if needed.
5. `add_object(mesh_id, matrix_world as float32 (4,4), object_id = per-object stable index)`.
6. Return stats: objects, meshes, triangles and seconds.

`tests/blender/test_sync_geometry.py`:
- A cube and two linked duplicates give 3 objects and 1 mesh.
- A modifier-evaluated mesh exports its evaluated triangle count.
- Materials map per slot.
- **Performance:** a 1M-triangle grid exports in less than 2 s. Record the time; this is the plan's target.
