## Create `src/blender/addon/sync/geometry.py`
- `@dataclass class SyncStats`, defined here; T5.3 and T5.4 import it from `sync/geometry.py`. Fields: `objects: int = 0`,
  `meshes: int = 0`, `triangles: int = 0`, `seconds: float = 0.0` (wall time of `sync_geometry`) and
  `object_ids: dict[ObjectKey, int] = field(default_factory=dict)` (object key → core object_id).
- `ObjectKey = str | tuple[str, str, tuple[int, ...]]` and `object_key(inst) -> ObjectKey`:
  - a real object (`inst.is_instance` false): `inst.object.name`, unique among objects;
  - an instanced duplicate (`inst.is_instance` true; collection, particle or geometry-nodes instances share one object name):
    `(inst.parent.name, inst.object.name, tuple(inst.persistent_id))`, as Cycles keys objects by parent, persistent id and object
    (`ObjectKey`, `blender/id_map.h`). A `str` never equals a `tuple`, so the two kinds never collide.

`sync_geometry(scene_core, depsgraph, material_index_of, stats: SyncStats) -> None` fills `stats`:
1. Iterate `depsgraph.object_instances` **as an iterator**. Copy `inst.matrix_world` immediately; it is only valid during the iteration.
2. Skip objects with `visible_get` false for render, and non-geometry types.
   - For `MESH`, use `inst.object.data`.
   - For other geometry types (curves, text, …), use `obj.to_mesh()` and then `obj.to_mesh_clear()`.
3. **Deduplicate meshes** by `(inst.object.original.name, id of the evaluated data)`, so instances share one `add_mesh`.
4. Export with `foreach_get` into preallocated numpy arrays, using **exact dtypes** (a wrong dtype silently falls back to the slow path):
   - vertices `co` → `np.float32`, shape (V·3);
   - `loop_triangles` `vertices` → `np.uint32`;
   - `loop_triangles` `loops` → `np.uint32`;
   - `loop_triangles` `material_index` → `np.int32` (a signed int property, so int32 is also its fast `foreach_get` path), mapped
     through the object's material slots to scene material indices with `material_index_of(material) -> int`, into an int32 (T,) array;
   - `corner_normals` `vector` → `np.float32`, gathered per triangle corner via `loops`.
   Call `mesh.calc_loop_triangles()` first if needed. Reshape vertices, triangles and corner normals to (V,3), (T,3) and (T,3,3)
   for `add_mesh`.
5. `add_object(mesh_id, matrix_world as float32 (4,4), object_id = len(stats.object_ids))`, then
   `stats.object_ids[object_key(inst)] = object_id`. The counter starts at 0 (for an empty `stats`) and counts the synced instances
   in `depsgraph.object_instances` order. Every object_id is passed explicitly. Assert that the key is new.
6. Add the objects, meshes, triangles and seconds to `stats`. T5.3 continues the same counter for the lights.

`tests/blender/test_sync_geometry.py`:
- A cube and two linked duplicates give 3 objects and 1 mesh, and `stats.object_ids` maps their three names to 0, 1 and 2 in
  instance order.
- A collection instanced twice gives two distinct instance keys.
- A modifier-evaluated mesh exports its evaluated triangle count.
- Materials map per slot.
- **Performance** (`@pytest.mark.slow`): export a 1M-triangle grid and assert only its triangle count. Record and report the time
  (plan target < 2 s, `docs/plan.md` M5 table); it is not a pass/fail threshold.
