## Create `src/blender/addon/sync/camera.py` (needs `bpy`; keep the pure-numpy math in `sync/camera_math.py`)
- `raster_to_camera(projection: np.ndarray(4,4), width, height) -> np.ndarray(4,4)`, pure:
  - Raster `(x, y)` with y down from the top row (SPEC §0) → NDC `(2x/w − 1, 1 − 2y/h, −1, 1)` → camera space through `inverse(projection)`.
  - Return the composed 4×4 matrix.
- `camera_fit(sensor_fit: str, width: int, height: int) -> str`, pure: `'AUTO'` → `'horizontal'` if width ≥ height else `'vertical'`;
  `'HORIZONTAL'` → `'horizontal'`; `'VERTICAL'` → `'vertical'` (Cycles `blender/camera.cpp` sensor-fit rules).
- `sync_camera(scene_core, depsgraph, width, height) -> None`:
  - `cam_obj = depsgraph.scene.camera` (evaluated).
  - `P = cam_obj.calc_matrix_camera(depsgraph, x=width, y=height, scale_x=render.pixel_aspect_x, scale_y=render.pixel_aspect_y)`.
  - `camera_to_world = cam_obj.matrix_world.normalized()`, using translation and rotation only.
  - Perspective → `set_camera_perspective(..., fit=camera_fit(cam.data.sensor_fit, width, height))`. Orthographic → `set_camera_orthographic` likewise.
    Panoramic → raise `NotImplementedError` with a clear message.
  - The core converts the integrator's `jitter` (a fraction of the fitted side, SPEC §7) itself. The add-on passes no jitter.
- The core computes the spiral frame F from the integrator sockets `spiral_frame`/`spiral_rotation` and the camera (T3.13).
  When `spiral_frame == "object"`, `sync_camera` calls `scene_core.set_spiral_object(rotation)` with
  `settings.spiral_object.matrix_world.to_quaternion().to_matrix()` as a (3, 3) float64 array. With no object, it raises
  a clear error before rendering.
- `tests/core/test_camera_math.py` (pure numpy):
  - For a 90° FOV 400×400 perspective matrix built analytically, the centre raster point maps to direction (0,0,−1).
  - The corners map to (±1, ±1, −1) up to scale.
  - Shift moves the principal point by the expected number of pixels.
  - Tolerance: float64 round-off, justified.
- `tests/blender/test_sync_camera.py` (bpy):
  - For a scene camera with lens 18 mm on a 36 mm sensor, shift_x 0.1 and render 320×240, the core's unjittered primary ray through
    each corner pixel centre hits the same point as `cam.data.view_frame(scene=scene)` projected onto the camera plane.
  - Also: `camera_fit` for each sensor-fit mode, and `set_spiral_object` receives an orthonormal matrix for a scaled, rotated object.
